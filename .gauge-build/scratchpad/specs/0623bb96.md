## Spec (from the manifest)

type: theorem; source items: (foundation for the compact-perturbation part of A-X5.2.1 / A-I7.1.10 and for A-T7.1.20; no numbered item); prereqs: [Def - Compact Operator, Thm - Basic Properties of Compact Operators, Def - Fredholm Operator and Index, Thm - Orthogonal Decomposition]; statement: Let $X$ be a Hilbert space and $K:X\to X$ compact. Then: (i) (Riesz's lemma) a normed space whose closed unit ball is compact is finite-dimensional; (ii) $\ker(1+K)$ is finite-dimensional; (iii) $\operatorname{Im}(1+K)$ is closed; (iv) $\operatorname{Im}(1+K)^\perp = \ker(1+K^*)$ is finite-dimensional; hence $1+K$ is Fredholm; (v) $\operatorname{index}(1+K) = 0$; proof: (i) the standard almost-orthogonality argument (or in Hilbert spaces: an orthonormal sequence has no convergent subsequence); (ii) on $\ker(1+K)$, $K = -1$, so the unit ball is compact; (iii) if $(1+K)x_j\to y$, replace $x_j$ by its component orthogonal to $\ker(1+K)$; if $\|x_j\|$ were unbounded, normalise and extract a convergent subsequence of $Kx_j/\|x_j\|$, giving $x_j/\|x_j\|\to z$ with $(1+K)z = 0$ and $z\perp\ker(1+K)$, $\|z\| = 1$ — contradiction; so $x_j$ bounded, $Kx_j$ has a convergent subsequence, hence $x_j = (1+K)x_j - Kx_j$ converges to some $x$ with $(1+K)x = y$; (iv) $K^*$ compact by the basic-properties page, apply (ii); (v) via finite-rank approximation: $K = K_0 + K_1$ with $K_0$ finite rank and $\|K_1\|<1$; $1+K_1$ invertible (Neumann), so $1+K = (1+K_1)(1+(1+K_1)^{-1}K_0)$ and it suffices to treat $1+F$ with $F$ finite rank: both kernel and cokernel are computed inside $\operatorname{Im}F + $ (a finite-dimensional space containing it), where the index is $0$ by the finite-dimensional formula — the writer does the bookkeeping (Brezis Thm 6.6); spec: reference Brezis *Functional Analysis* Thm 6.6 (Fredholm alternative); mechanism: **a compact operator is small on all but finitely many dimensions, so $1+K$ is invertible up to a finite-dimensional defect of dimension zero**.
