## Spec (from the manifest)

type: definition (compound: reducible self-dual connection via a splitting $P \cong L \oplus L^*$, the counting function $n(Q)$); source items: D5.3.4, D5.3.5; prereqs: [Def - The Instanton Moduli Space and its Compactification, Def - Reduction and Extension of the Structure Group, Def - Unimodular Symmetric Bilinear Form, Parity, and Signature, Def - Intersection Form of a Four-Manifold]; spec: a self-dual connection on $P$ is *reducible* if it is induced from a self-dual connection on a $U(1)$-bundle $L$ under a reduction $P \cong L \oplus L^*$ (`Def - Reduction and Extension of the Structure Group`, chapter III); the counting function $n(Q) := \tfrac12 \#\{\alpha \in H^2(X;\mathbb{Z}) : Q(\alpha, \alpha) = 1\}$ (finite because $Q$ is positive definite, so $\{Q(\alpha,\alpha)=1\}$ is the intersection of a lattice with an ellipsoid); the factor $\tfrac12$ pairs $\alpha$ with $-\alpha$. Examples: for $Q = \operatorname{diag}(1,\dots,1)$ of rank $r$, the classes of self-intersection $1$ are exactly $\pm e_i$, so $n(Q) = r$; for $E_8$, $n(E_8) = 0$ (no vector of norm $1$ in an even lattice); non-example: $H$ is indefinite, so $n$ is not defined by this finite count.
