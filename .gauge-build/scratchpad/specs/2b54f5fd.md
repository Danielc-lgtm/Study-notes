T4.1.5 proved on the page (identification $\{f \in C(S^0, X) \mid f(NP) = x\} \cong X$ via $f \mapsto f(SP)$ and $f \simeq f'$ rel $NP$ iff $f(SP)$, $f'(SP)$ lie in the same path component; so $\pi_0(X,x)$ is the set of path components, pointed by the component of $x$, with no canonical group structure). Convention callout: Bär's $S^n$-model versus Hatcher's $I^n$-model; both used.
