## Spec (from the manifest)

type: theorem (anchor); source items: A-T6.1.3 (Theorem 164), A-I6.1.3, A-I6.3.3, A-I7.1.14 (partial); prereqs: [Thm - Sard's Theorem for Smooth Maps, Thm - Kuranishi Model for a Fredholm Map, Def - Residual Set and Generic Property, Def - Fredholm Map and Its Index, Thm - Regular Value and Transversality Theorems for Fredholm Maps, Thm - Proper Maps are Closed and Fredholm Maps are Locally Proper]; statement: Let $F:X\to Y$ be a smooth Fredholm map between (second countable) Banach manifolds. Then the set of regular values of $F$ is residual in $Y$, in particular dense; proof: Smale, *An infinite dimensional version of Sard's theorem*, Amer. J. Math. 87 (1965), Thm 1.3; Abraham–Robbin, *Transversal Mappings and Flows*, §16: **Step 1** (local properness): each $p\in X$ has an open neighbourhood $U_p$, a Kuranishi chart around it, such that $F|_{\overline{U_p}}$ is proper (in the chart $F\phi(x_0,x_1) = Tx_1 + f(x_0,x_1)$, the preimage of a compact set $K$ within a closed bounded neighbourhood is $\{(x_0,x_1) : Tx_1\in\pi_{Y_0}K, f(x_0,x_1)\in\pi_{Y_1}K\}$, whose $x_1$-component lies in the compact $T^{-1}\pi_{Y_0}K$ and whose $x_0$-component lies in a closed bounded subset of the finite-dimensional $X_0$; a closed subset of a product of two compact sets is compact — written out with the shrinking of $U_p$ to make the model hold on $\overline{U_p}$); **Step 2** (critical values of $F|_{\overline{U_p}}$ are closed: $\operatorname{Crit}(F)$ is closed in $X$ because surjectivity of Fredholm operators is an open condition (`Thm - Stabilisation of Fredholm Operators and Continuity of the Kernel` (ii)); a proper continuous map to a metrisable space is closed (next Thm page); so $F(\operatorname{Crit}(F)\cap\overline{U_p})$ is closed); **Step 3** (critical values of $F|_{U_p}$ have empty interior: in the chart, $(y_0,y_1)$ is a critical value of $F\phi$ iff $y_1$ is a critical value of the finite-dimensional map $x_0\mapsto f(x_0,T^{-1}y_0)$ — proved by the surjectivity computation: $d(F\phi)(v_0,v_1) = Tv_1 + d_{x_0}f\,v_0 + d_{x_1}f\,v_1$ is onto $Y_0\oplus Y_1$ iff $d_{x_0}f$ is onto $Y_1$ — so by Sard's theorem each slice $\{y_0\}\times Y_1$ meets the critical-value set in a null set, hence the critical-value set contains no open set (an open set would contain a product of open sets, whose $Y_1$-slice has positive measure)); **Step 4** (assemble: $R_p := Y\setminus F(\operatorname{Crit}(F)\cap\overline{U_p})$ is open and dense; $X$ is second countable hence Lindelöf, so countably many $U_{p_i}$ cover $X$; the regular values of $F$ are exactly $\bigcap_iR_{p_i}$, a residual set; dense by Baire); spec: Haydys cites [BT03] for Sard and omits the proof; mechanism: **a Fredholm map is, in Kuranishi charts, a finite-dimensional map in the kernel–cokernel directions plus an isomorphism; Sard's theorem applies slice by slice, and local properness makes the critical values closed so that "null in every slice" becomes "nowhere dense"**; What Makes This Hard: null sets have no meaning in a Banach space — one needs closedness (properness) to convert measure-zero slices into a topological statement.
