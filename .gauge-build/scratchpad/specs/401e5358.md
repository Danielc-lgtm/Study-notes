## Spec (from the manifest)

type: theorem (helper 3, homogeneity); source items: A-T6.2.1 (Steps 4–5), A-R6.2.1, A-I6.2.3; prereqs: [Def - Banach Manifold and Smooth Maps between Banach Spaces, Def - Path-Connected Space, Thm - Fundamental Theorem on Flows, Def - Bump Function and Smooth Cutoff]; statement: (i) (Isotopy lemma) For a Banach space $B$ and $x$ in the open unit ball there is a diffeomorphism $\phi$ of $B$ with $\phi(0) = x$, $\phi = \mathrm{id}$ outside the ball of radius $2$, and a smooth isotopy $\phi_t$ ($\phi_0 = \mathrm{id}$, $\phi_1 = \phi$) fixing that exterior. (ii) For a connected Banach manifold $Y$ and $y_1,y_2\in Y$ there is a diffeomorphism $\phi\in\operatorname{Diff}_0(Y)$ (isotopic to the identity, compactly supported) with $\phi(y_1) = y_2$; proof: (i) Bär's explicit construction reduced to finite dimensions: write $B = V\oplus V'$ with $V$ finite-dimensional containing $x$; the finite-dimensional isotopy $\psi_t:V\to V$ moving $0$ to $x$ inside the unit ball (Milnor, *Topology from the Differentiable Viewpoint*, p. 22 — proved here as Lemma 1 via the flow of a compactly supported vector field $Z$ with $Z(0) = x$, `Thm - Fundamental Theorem on Flows`, cut off by a bump function, `Def - Bump Function and Smooth Cutoff`); then $\phi_t(v,v') := \psi_{t\chi(|v'|)}(v) + v'$ with $\chi(0) = 1$, $\chi = 0$ for $r\ge1$; the writer verifies $\|\phi_t(v,v')\|\le 2$ on the unit ball and $\phi_t = \mathrm{id}$ where $\|v\|+\|v'\|\ge2$; (ii) the relation "$\exists\phi\in\operatorname{Diff}_0(Y)$ with $\phi(y_1) = y_2$" is open (by (i) in a chart) and its classes partition $Y$; each class is open, so by connectedness there is one class; spec: helper 3; **the vault has no `Def - Brouwer Degree of a Map` isotopy machinery in a form usable here; the isotopy lemma is proved from scratch**; mechanism: **any point of the unit ball can be reached from the centre by a compactly supported flow, and a connected manifold is homogeneous under such flows**.
