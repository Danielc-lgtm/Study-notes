## Spec (from the manifest)

type: definition (anchor); source items: A-D6.1.1 (Definition 161), A-R6.1.1; prereqs: [Def - Banach Manifold and Smooth Maps between Banach Spaces, Def - Fredholm Operator and Index, Thm - Stability of the Fredholm Property under Small and Compact Perturbations]; spec: $F\in C^\infty(X;Y)$ is a *Fredholm map* if $d_xF:T_xX\to T_{F(x)}Y$ is a Fredholm operator for every $x$; $\operatorname{index}d_xF$ is locally constant in $x$ (stability theorem, IX) hence constant on each component; for connected $X$, $\operatorname{index}F$; Convention callout: "smooth" throughout, though $C^{q}$ with $q>\max(\operatorname{index},0)$ suffices for Sard–Smale (Smale's hypothesis — recorded); examples: any smooth map between finite-dimensional manifolds (index $\dim X-\dim Y$); $u\mapsto Lu + N(u)$ for $L$ elliptic and $N$ a lower-order nonlinearity (exercise); the Seiberg–Witten map (XI); non-example: the inclusion $H_1\to H_0$.
