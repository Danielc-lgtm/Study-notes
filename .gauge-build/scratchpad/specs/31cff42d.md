## Spec (from the manifest)

type: theorem (two parts); source items: A-T5.2.2 (Theorem 148; source typo: Haydys prints "$t\in\ker L^*$" for "$t\perp\ker L^*$"), A-T5.2.3 (Remark 149, with the caveat that the dichotomy as printed presupposes $\dim\ker L = \dim\ker L^*$, e.g. index zero — the corrected statement below), A-I5.2.3; prereqs: [Thm - Elliptic Operators on Closed Manifolds are Fredholm]; statement: Let $L$ be elliptic on a closed manifold and $t\in C^\infty(M;F)$. (i) $Ls = t$ has a smooth solution $s$ if and only if $t\perp\ker L^*$ in $L^2$; the solution is unique modulo $\ker L$, and there is a unique solution $L^2$-orthogonal to $\ker L$, depending linearly and continuously (in every Sobolev norm) on $t$. (ii) If $\operatorname{index}L = 0$ (in particular if $L$ is formally self-adjoint), exactly one of the following holds: $L^*s = 0$ has a non-trivial solution, or $Ls = t$ has a unique smooth solution for every smooth $t$; proof: (i) from (iv) of the previous page and regularity; the continuous dependence from the bounded-below estimate on $(\ker L)^\perp$; (ii) $\dim\ker L = \dim\ker L^*$ when the index is $0$, so $\ker L^* = 0$ iff $\ker L = 0$ iff $L$ is bijective; spec: mechanism: the Fredholm alternative is the finite-dimensional rank–nullity theorem transplanted by the Fredholm property; targets: the Hodge theorem (§9.6), the Coulomb gauge (XI).
