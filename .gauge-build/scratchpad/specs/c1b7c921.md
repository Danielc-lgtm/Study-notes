## Spec (from the manifest)

type: theorem (three parts: inverse function theorem, implicit function theorem, regular value theorem for maps with complemented kernel); source items: A-I6.2.1; prereqs: [Def - Banach Manifold and Smooth Maps between Banach Spaces, Thm - The Contraction Mapping Principle, Thm - Banach–Steinhaus and Open Mapping (Application of Baire)]; statement: (i) Let $F:U\subset X\to Y$ be $C^k$ ($k\ge1$) with $d_{x_0}F$ a bounded linear isomorphism. Then there are open $x_0\in U'\subset U$, $F(x_0)\in V'\subset Y$ with $F:U'\to V'$ a $C^k$ diffeomorphism. (ii) (Implicit function theorem) If $F:X_1\times X_2\to Y$ is $C^k$ with $\partial_2F(a,b)$ an isomorphism and $F(a,b) = 0$, then near $(a,b)$ the zero set is the graph of a $C^k$ map $g$ with $g(a) = b$. (iii) If $F:X\to Y$ is $C^k$ between Banach manifolds, $y$ a regular value, and $\ker d_xF$ is complemented for every $x\in F^{-1}(y)$ (automatic when $d_xF$ is Fredholm), then $F^{-1}(y)$ is a $C^k$ embedded submanifold with $T_xF^{-1}(y) = \ker d_xF$; proof: (i) Lang, *Real and Functional Analysis*, XIV §1 / Dieudonné (10.2.5): reduce to $X = Y$, $d_{x_0}F = \mathrm{id}$; the writer writes the standard contraction argument: $G_y(x) := x - L^{-1}(F(x)-y)$ with $L = d_{x_0}F$ is a contraction on a small ball for $y$ near $F(x_0)$, giving a continuous inverse; differentiability of the inverse via the Neumann series (`Thm - Stabilisation of Fredholm Operators and Continuity of the Kernel`, Lemma 1) and $C^k$ by induction; (ii) apply (i) to $(x_1,x_2)\mapsto(x_1,F(x_1,x_2))$; (iii) local submersion form: with $X = \ker d_xF\oplus X_1$, the map $(k,x_1)\mapsto(k,F(x))$ is a local diffeomorphism by (i); spec: the vault's `Thm - The Inverse Function Theorem` (finite-dimensional) is the model; mechanism: **a map whose linearisation is invertible is invertible near the point, because the nonlinear error is a contraction relative to the linear part**.
