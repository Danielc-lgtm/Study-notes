## Spec (from the manifest)

type: theorem (replaces the flagged `Thm - Sard's Theorem`); source items: A-I6.1.2; prereqs: [Def - Set of Measure Zero on a Manifold, Def - Regular and Critical Points, Def - Smooth Manifold, Thm - Heine–Borel Theorem]; statement: Let $f:U\to\mathbb R^n$ be smooth, $U\subset\mathbb R^m$ open. Then the set of critical values $f(\operatorname{Crit}(f))$ has Lebesgue measure zero in $\mathbb R^n$. Consequently, for a smooth map $f:M\to N$ between manifolds ($M$ second countable), the critical values have measure zero in $N$ and the regular values are dense; proof: Milnor, *Topology from the Differentiable Viewpoint*, §3 (following Pontryagin), every step written out: **Step 0** (measure zero in $\mathbb R^n$ is defined via countable covers by cubes; countable unions of null sets are null; smooth maps between open subsets of $\mathbb R^n$ carry null sets to null sets — Lemma 1, via the mean value inequality on compact subsets and Lindelöf); **Step 1** (Fubini-type lemma, used in Milnor's proof that $f(C\setminus C_1)$ is null: a compact set $A\subset\mathbb R^n$ meeting every hyperplane $\{x_1 = c\}$ in a set of $(n-1)$-measure zero has measure zero — Lemma 2, proved for compact sets by uniform covering; for the induction on $m$); **Step 2** (induction on $m$; $m = 0$ trivial); **Step 3** ($f(C\setminus C_1)$ null, $C_1$ = points where all first partials vanish: near $x\in C\setminus C_1$ some $\partial_if_j\ne0$; following Milnor, take $h(x) = (f_1(x),x_2,\dots,x_m)$ a local diffeomorphism, then $g = f\circ h^{-1}$ maps hyperplanes $\{t\}\times\mathbb R^{m-1}$ into $\{t\}\times\mathbb R^{n-1}$ and the critical points of $g$ in a hyperplane are critical points of the restriction $g^t$, so by induction each slice of the critical-value set is null, and Lemma 2 applies); **Step 4** ($f(C_k\setminus C_{k+1})$ null: similar with a $(k+1)$-st derivative as the new coordinate); **Step 5** ($f(C_k)$ null for $k\ge m/n - 1$: Taylor's theorem with remainder gives $|f(x+h)-f(x)|\le c|h|^{k+1}$ for $x\in C_k$, so a cube of side $\delta$ containing points of $C_k$ maps into a cube of side $\le c'\delta^{k+1}$; subdividing a unit cube into $r^m$ subcubes gives total image volume $\le r^m(c'/r)^{(k+1)n}\to0$ when $(k+1)n>m$); the manifold statement via countable charts (Lindelöf); density of regular values from "null ⇒ empty interior"; spec: reference also Lee, *Introduction to Smooth Manifolds*, 2nd ed., Thm 6.10 and Sternberg *Lectures on Differential Geometry* II.3; mechanism: **at a critical point the map crushes at least one direction; iterated Taylor expansion shows the image of the deeply-critical set is thin, and induction on dimension handles the rest**; targets: Sard–Smale, transversality, degree theory, $\pi_k(S^m)$ for $k<m$ (XII).
