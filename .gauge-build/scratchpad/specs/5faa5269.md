Then the deduction is proved in full: write $K3 = X_1 \cup_\Sigma X_2$ along a topologically embedded $S^3 = \Sigma$ with $X_1 \cong 2\overline{M_{E_8}}\setminus B^4$, and give $X_2$ the smooth structure it inherits from $K3$; set $V := 3(S^2\times S^2)\setminus j(X_2\setminus A)$ for a collar $A$; then $\pi_1(V) = 0$ by `Thm - Seifert-van Kampen Theorem for Two Open Sets` and $H_2(V;\mathbb{Z}) = 0$ by `Thm - Mayer-Vietoris Sequence for Singular Homology (Gauge Theory)`, and $V$ has one end $\cong S^3\times(0,\infty)$, so $V \approx \mathbb{R}^4$ by Import 1(b); the compact set $K := 3(S^2\times S^2)\setminus j(X_2) \subset V$ cannot be surrounded by a smoothly embedded $3$-sphere, for such a sphere would (transporting through $j$ and the smooth embedding $X_2\hookrightarrow K3$) give a smoothly embedded $S^3 = \Sigma' \subset K3$ splitting off a closed smooth simply connected $Z$ with $Q_Z \cong E_8 \oplus E_8$, contradicting `Thm - E8 Plus E8 is Not Smoothable`; since in standard $\mathbb{R}^4$ every compact set is surrounded by the boundary of a large ball, $V \not\cong_{\mathrm{diffeo}} \mathbb{R}^4$.
