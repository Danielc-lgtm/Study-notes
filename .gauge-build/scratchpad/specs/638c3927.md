## Spec (from the manifest)

type: theorem; source items: B-T2.6.7, B-E2.6.3, B-I2.6.2; prereqs: [Def - Holonomy Group of a Connection, Def - Path-Ordered Exponential, Thm - Stokes' Theorem on Manifolds, Thm - Transformation of Local Connection and Curvature Forms]; statement: Let $G$ be abelian, $c$ a piecewise smooth loop in a trivialising set $U_\alpha$ bounding a compact oriented surface $S\subset U_\alpha$ with $\partial S=c$. Then $\operatorname{hol}(c)=\exp\big(-\int_c A_\alpha\big)=\exp\big(-\int_S F\big)$, where $F=dA_\alpha$ is the global curvature; more generally, for any loop $c$ in $U_\alpha$, $\operatorname{hol}(c)=\exp(-\int_cA_\alpha)$; in particular if $F\ne0$ then some loop has nontrivial holonomy; proof: B full: commuting case of the ODE (Def page corollary) and Stokes; write the independence of the trivialisation ($\int_c$ of $g^*\theta$ over a loop is in the kernel of $\exp$ — for $U(1)$ it is $2\pi i\cdot w(g)$, III's winding-number theorem); reference: Kobayashi–Nomizu I Ch. II §7 (abelian case) ; spec: Targets: Dirac quantisation (VII), the Hopf holonomy, RG IV's spherical-cap exercise (bridge).
