## Spec (from the manifest)

type: theorem (three parts); source items: A-T6.1.2 (Corollary 163), A-T6.1.4 (Theorem 165), A-I6.1.5; prereqs: [Thm - Kuranishi Model for a Fredholm Map, Thm - Inverse Function Theorem on Banach Spaces, Def - Regular Value and Transversality for Fredholm Maps, Def - Smooth Manifold with Boundary]; statement: Let $F:X\to Y$ be a smooth Fredholm map between Banach manifolds. (i) If $y$ is a regular value then $F^{-1}(y)$ is a smooth embedded submanifold of $X$ of dimension $\operatorname{index}F$ (on each component), with $T_xF^{-1}(y) = \ker d_xF$. (ii) If $Z\subset Y$ is a finite-dimensional embedded submanifold and $F\pitchfork Z$, then $F^{-1}(Z)$ is a smooth submanifold of dimension $\operatorname{index}F + \dim Z$. (iii) (Boundary version) If $X$ is a Banach manifold with boundary (modelled on half-spaces $X'\times[0,\infty)$) and $y$ is a regular value of both $F$ and $F|_{\partial X}$, then $F^{-1}(y)$ is a manifold with boundary $\partial F^{-1}(y) = F^{-1}(y)\cap\partial X$; in particular for a smooth homotopy $H:X\times[0,1]\to Y$ with $y$ regular for $H$, $H_0$, $H_1$, $H^{-1}(y)$ is a manifold with boundary $H_0^{-1}(y)\times\{0\}\sqcup H_1^{-1}(y)\times\{1\}$; proof: (i) Haydys's argument: $Y_1 = 0$, so $f = 0$ and $F^{-1}(0)$ is locally $\phi(X_0\times0)$; (ii) reduce to (i) by composing with a local submersion $Y\supset U\to\mathbb R^{\operatorname{codim}}$ cutting out $Z$ (Lemma: a finite-dimensional embedded submanifold is locally the zero set of a submersion to a finite-dimensional space — from the submanifold chart) and using that $F\pitchfork Z$ makes $0$ a regular value of the composite; the dimension count is the direct argument of Guillemin–Pollack: $F^{-1}(Z)$ near $x$ is $(g\circ F)^{-1}(0)$ where $g$ is the local defining submersion of $Z$; $\ker d_x(g\circ F) = d_xF^{-1}(T_zZ)$ has dimension $\dim\ker d_xF + \dim(T_zZ\cap\operatorname{Im}d_xF)$, and transversality gives $\dim(T_zZ\cap\operatorname{Im}d_xF) = \dim Z - \operatorname{codim}\operatorname{Im}d_xF$; so $\dim = \operatorname{index}F + \dim Z$; (iii) the Kuranishi model relative to the boundary (Guillemin–Pollack §2.1 argument transplanted); spec: Haydys: "just as in the finite-dimensional case" ([GP10]); mechanism: the Kuranishi model with zero cokernel is a chart.
