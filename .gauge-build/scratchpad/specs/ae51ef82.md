## Spec (from the manifest)

type: definition (anchor; compound: Dirac bundle (Haydys's three conditions), Dirac operator, the spin Dirac operator as the special case with $E = \slashed S$ forward-referenced to §8.3); source items: A-D4.2.2 (second half: the Dirac bundle conditions), A-D4.2.3; prereqs: [Def - Clifford Bundle and Bundle of Clifford Modules, Def - Connection on a Vector Bundle, Def - Metric-Compatible Connection, Def - Induced Connection on Tensor Bundles]; spec: a *Dirac bundle* is a bundle of Clifford modules $E$ with a Euclidean (or Hermitian) metric and a connection $\nabla$ such that (1) $\nabla$ is metric, (2) $\langle v\cdot e_1,v\cdot e_2\rangle = |v|^2\langle e_1,e_2\rangle$ (equivalently Clifford multiplication by a unit vector is orthogonal, equivalently $v\cdot$ is skew-adjoint — proved), (3) $\nabla(\phi\cdot s) = (\nabla^{LC}\phi)\cdot s + \phi\cdot\nabla s$ for $\phi\in\Gamma(\mathrm{Cl}(M))$, $s\in\Gamma(E)$; the *Dirac operator* $D := \mathrm{Cl}\circ\nabla:\Gamma(E)\to\Gamma(T^*M\otimes E)\to\Gamma(E)$, i.e. $Ds = \sum_ie_i\cdot\nabla_{e_i}s$ in a local orthonormal frame (independence of the frame proved: the contraction $T^*M\otimes E\to E$ is tensorial); the *spinor bundle* $\slashed S := P\times_{Spin(n),\rho}\slashed S$ over a spin manifold and the *spin Dirac operator* $\slashed D$ are named here and constructed in §8.3 (`Def - Spin Structure and Spin-c Structure`, `Def - Spin-c Dirac Operator Twisted by a Connection`), so that this anchor page is the front door; first-order, formally self-adjoint (next page), elliptic (chapter IX, `Thm - Dirac Operators are Elliptic`); Convention callout: Haydys $D = \sum e_i\cdot\nabla_{e_i}$; Lawson–Michelsohn the same; some physics texts use $i\gamma^\mu\partial_\mu$ (Hermitian convention); the vault's `Def - Spin Connection and the Dirac Operator` defines $\slashed D$ via the spin connection in a frame — recorded as the same operator; examples: $\mathbb R^n$ with $E$ trivial and constant Clifford matrices ($D = \sum\gamma_i\partial_i$), verified conditions (1)–(3); non-example: $\Lambda T^*M$ with a non-metric connection fails (1).
