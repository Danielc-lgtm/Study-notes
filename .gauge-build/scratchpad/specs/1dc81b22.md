type: definition (compound: standard simplex and its sides, singular simplex, singular chains with coefficients in a commutative ring $R$ with unit, boundary operator, cycles, boundaries, $H_n(X;R)$, induced maps); source items: D4.2.3, D4.2.4, D4.2.5, D4.2.6, E4.2.1, R4.2.1, T4.2.2 (→ link `Thm - d-Squared-is-Zero for Singular Boundaries`), T4.2.3, T4.2.4(1), T4.2.6; prereqs: [Def - Chain Complex and Its Homology, Def - The Standard p-Simplex, Def - Singular Simplex, Def - Singular Chain, Def - The Boundary Operator, Thm - d-Squared-is-Zero for Singular Boundaries, Def - Singular Homology, Def - Free Module]; spec: $\Delta^n = \{(t_0, \dots, t_n) \in \mathbb{R}^{n+1} \mid t_i \ge 0, \sum t_i = 1\}$, sides $\iota^n_k : \Delta^{n-1} \to \Delta^n$ inserting $0$ in position $k$, $C_n(X;R)$ the free $R$-module on $C(\Delta^n, X)$, $\partial_n \sigma = \sum_{k=0}^n (-1)^k \sigma \circ \iota^n_k$ (E4.2.1 pictures of $\Delta^0, \Delta^1, \Delta^2$ and the five side maps written as formulas), $Z_n$, $B_n$, $H_n(X;R)$. $\partial \circ \partial = 0$ is wikilinked to the proof-complete AT I page (its statement restated). Proved on the page: T4.2.3 ($f_* \partial = \partial f_*$, since $f \circ (\sigma \circ \iota^n_k) = (f \circ \sigma) \circ \iota^n_k$), so $f_*$ is a chain map and $f_*[z] := [f_* z]$ is well defined (R4.2.1); T4.2.4(1) functoriality; T4.2.6 ($C_n(\emptyset; R) = 0$). Convention callout: Bär allows any commutative ring with unit; the page fixes the same and notes that $H_n(X;\mathbb{Z}) \otimes R \to H_n(X;R)$ is not in general an isomorphism (example $\mathbb{RP}^2$ with $R = \mathbb{Z}/2$, stated as a warning with a forward link to the universal coefficient page, not as a proved claim). Relation to `Def - Singular Homology` (AT I, integer coefficients): same complex tensored with $R$. Examples: singular $0$-simplices are points and $H_0$ counts path components (forward link); a non-example: a map $\Delta^n \to X$ that is not continuous is not a simplex. Calibration check: write $\partial$ of a singular $2$-simplex, verify $\partial \partial \sigma = 0$ for $n = 2$ by hand, check $f_*$ on a $1$-cycle.
