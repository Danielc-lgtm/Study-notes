## Spec (from the manifest)

type: definition; source items: A-D5.2.5; prereqs: [Def - Elliptic Differential Operator and Principal Symbol, Def - The L2 Inner Product on Differential Forms, Def - Riemannian Volume Form]; spec: given fibre metrics on $E,F$ and a Riemannian metric on $M$, $L^*:\Gamma(F)\to\Gamma(E)$ is a formal adjoint of $L$ if $\int_M\langle Ls,t\rangle\,\mathrm{vol} = \int_M\langle s,L^*t\rangle\,\mathrm{vol}$ for all $s\in\Gamma_c(E)$, $t\in\Gamma_c(F)$; uniqueness (Lemma, proved: the fundamental lemma for sections — if $\int\langle s,w\rangle = 0$ for all compactly supported smooth $s$ then $w = 0$); examples: $d^*$ (`Thm - Codifferential is the Adjoint of d`), $\nabla^*$, $D^* = D$ for Dirac operators (`Thm - Dirac Operators are Formally Self-Adjoint`); $(\partial_j)^* = -\partial_j$ on $\mathbb R^n$; non-example: the Hilbert-space adjoint of the unbounded operator $L$ on $L^2$ is a different (larger-domain) object — remark only.
