## Spec (from the manifest)

type: definition (anchor; compound: linear differential operator of order $\ell$ locally and on bundles; principal symbol; ellipticity); source items: A-D5.2.1, A-D5.2.2, A-D5.2.3, A-D5.2.4; prereqs: [Def - Vector Bundle, Def - Local Trivialization, Def - Section of a Vector Bundle, Def - Cotangent Space and Cotangent Bundle]; spec: on $\Omega\subset\mathbb R^n$: $Lf = \sum_{|\alpha|\le\ell}A_\alpha(x)\partial^\alpha f$, $A_\alpha\in C^\infty(\Omega;\operatorname{Hom}(\mathbb R^r,\mathbb R^s))$ (Haydys (140); the $\ell = 2$, $n = 2$ example written out); principal symbol $\sigma_L(x,\xi) := \sum_{|\alpha|=\ell}A_\alpha(x)\xi^\alpha$, homogeneous of degree $\ell$ in $\xi\in(\mathbb R^n)^*$ — **no factor of $i$** (Convention callout: many texts use $\sigma_L(\xi) = \sum A_\alpha(i\xi)^\alpha$, so that the Laplacian's symbol is $+|\xi|^2$; Haydys's convention gives $\sigma_\Delta(\xi) = -|\xi|^2$ for the non-negative Laplacian; the two differ by $i^\ell$, which does not affect ellipticity); on bundles: $L:\Gamma(E)\to\Gamma(F)$ is a differential operator of order $\ell$ if it has the local form (140) in every chart and trivialisation; the symbol as a map $\sigma_L:\pi^*E\to\pi^*F$ over $T^*M$ (well-definedness is the next Thm page); $L$ is *elliptic* if $\sigma_L(x,\xi)$ is invertible for all $\xi\ne0$ (so necessarily $r = s$); order is well defined (the minimal $\ell$); examples: $d$ on forms (symbol $\xi\wedge$, not elliptic for $n\ge2$ as $\Lambda^k\to\Lambda^{k+1}$ but injective — leads to elliptic complexes), $\Delta$, Dirac (next Thm page); non-examples: $\partial_t - \Delta$ (heat, symbol $-|\xi|^2$ on the space part only — degenerate), $\partial_t^2-\Delta_x$ (wave, symbol vanishes on the light cone), $\bar\partial:C^\infty(\mathbb C)\to C^\infty(\mathbb C)$ (symbol $\tfrac12(\xi_1+i\xi_2)$, elliptic as a complex operator $\mathbb C\to\mathbb C$ — instance).
