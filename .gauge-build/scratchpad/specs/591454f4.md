type: definition (anchor); source items: A-D5.2.6 (Definition 150), A-E5.2.4 (→ inside, Examples: a linear map between finite-dimensional spaces is Fredholm with index $\dim X - \dim Y$; source typo: Haydys p. 48 prints $\dim Y - \dim X$), A-R5.2.4 (→ inside, Axiom Motivation: Fredholm operators are the infinite-dimensional operators that behave like finite-dimensional ones); prereqs: [Def - Cauchy Sequence and Complete Metric Space, Def - Quotient Space, Thm - Fundamental Theorem of Linear Maps]; spec: a bounded linear $B:X\to Y$ between Banach spaces is *Fredholm* if (a) $\dim\ker B<\infty$, (b) $\operatorname{Im}B$ is closed, (c) $\dim\operatorname{coker}B<\infty$ with $\operatorname{coker}B := Y/\operatorname{Im}B$; $\operatorname{index}B := \dim\ker B - \dim\operatorname{coker}B$; (b) is redundant (next page) but kept in the definition as Haydys does; $\operatorname{Fred}(X,Y)$ with the operator-norm topology; examples: finite-dimensional maps (index $\dim X-\dim Y$, verified), the identity (index 0), the unilateral shift on $\ell^2$ (index $-1$; its adjoint index $+1$; verified), $d/d\theta:H_1(S^1)\to H_0(S^1)$ (index $0$, kernel and cokernel the constants — verified by Fourier); non-examples: the inclusion $H_1\subset H_0$ (infinite cokernel), multiplication by $x$ on $L^2[0,1]$ (dense non-closed range); Convention callout: Haydys's cokernel is the algebraic quotient; in Hilbert spaces $\operatorname{coker}B\cong(\operatorname{Im}B)^\perp$ once the range is closed.
