type: theorem; source items: (needed for I5.1.4, the cup-product identification; Milnor–Stasheff Thm 10.4); prereqs: [Def - Singular Cohomology with Coefficients and the Kronecker Pairing, Def - Cup Product, Thm - Properties of the Cup Product, Thm - Excision Theorem for Singular Homology, Thm - Universal Coefficient Theorem for Cohomology, Thm - Homology of Spheres, Def - Local Homology and Local Orientation, Def - Vector Bundle, Def - Orientation of a Vector Space]; statement: Let $\pi : E \to B$ be an oriented real vector bundle of rank $n$ over a compact base $B$ (or any base admitting a finite trivialising cover), $E_0 := E \setminus (\text{zero section})$. Reference: Milnor–Stasheff, *Characteristic Classes*, §10 (Thm 10.4) for the structure of the argument, followed as specified here; Bredon VI.11 for the alternative via Leray–Hirsch. spec: Why-true: "a bundle is locally a product, the Thom class is locally the fundamental cohomology class of the fibre, and Mayer–Vietoris glues the local identifications because the fibre-generator is unique"; Targets: the Poincaré dual of a submanifold, the Euler class, self-intersection numbers.
