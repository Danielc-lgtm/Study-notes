## Spec (from the manifest)

type: theorem (two parts); source items: A-T7.1.2 (Lemma 190), A-T7.1.3, A-R7.1.2; prereqs: [Def - Seiberg-Witten Equations, Def - Seiberg-Witten Moduli Space, Thm - Variation of the Twisted and Spin-c Dirac Operators with the Connection, Def - The Quadratic Map on Positive Spinors]; statement: (i) The Seiberg–Witten map is $\mathcal G$-equivariant: $SW((\psi,A)\cdot g) = \bar g\cdot SW(\psi,A)$, where $\mathcal G$ acts on $\Gamma(\slashed S^-)\times\Omega^2_+(M;i\mathbb R)$ by $\bar g$ on the spinor factor and trivially on the form factor; in particular $SW^{-1}(0)$ is $\mathcal G$-invariant. (ii) The stabiliser of $(\psi,A)$ is non-trivial if and only if $\psi\equiv0$, and every stabilising $g$ is a constant map; proof: (i) the writer verifies each component: $\slashed D^+_{A+2g^{-1}dg}(\bar g\psi) = \bar g\,\slashed D_A^+\psi + \tfrac12(2g^{-1}dg)\cdot(\bar g\psi) + (d\bar g)\cdot\psi = \bar g\,\slashed D_A^+\psi$ (using `Thm - Variation of the Twisted and Spin-c Dirac Operators with the Connection` and $d\bar g = -\bar g\,g^{-1}dg$, since $|g| = 1$), $F_{A + 2g^{-1}dg}^+ = F_A^+$ (because $d(g^{-1}dg) = 0$ for abelian $G$), and $\mu(\bar g\psi) = \mu(\psi)$ (since $|\bar g| = 1$); (ii) from $A\cdot g = A$ iff $g^{-1}dg = 0$ iff $g$ constant, and then $\bar g\psi = \psi$ with $g\ne1$ forces $\psi\equiv0$; spec: **Haydys omits the computation (Lemma 190); it is written out**; mechanism: **the abelian gauge action rotates the spinor by $\bar g$ and shifts the connection by an exact imaginary form that the Dirac operator exactly absorbs, so the equations are gauge-natural**; targets: the moduli space is the quotient by a free action on irreducibles (§11.4 slice).
