type: definition (compound: the mod-two reduction $\bar H = H/2H$ with $\bar Q$, characteristic element, characteristic surface); source items: D5.2.4, (the $\bar H$, $\bar Q$ setup); prereqs: [Def - Unimodular Symmetric Bilinear Form, Parity, and Signature, Def - Quotient Group, Def - Intersection Form of a Four-Manifold]; spec: $w \in H$ is characteristic for $Q$ iff $Q(x,x) \equiv Q(w,x) \pmod 2$ for all $x \in H$; $\bar H := H/2H$ `(source: Bär writes $H/2\mathbb{Z}$)`, a vector space over $\mathbb{Z}/2$ of dimension $\operatorname{rk} H$, with the induced symmetric bilinear form $\bar Q$ (well defined, verified); the map $\bar f : \bar H \to \mathbb{Z}/2$, $\bar f(\xi) := \bar Q(\xi, \xi)$, is $\mathbb{Z}/2$-linear (verified: $\bar Q(\xi + \eta, \xi + \eta) = \bar f(\xi) + \bar f(\eta) + 2\bar Q(\xi,\eta)$); for $H = H_2(X;\mathbb{Z})$ an embedded oriented surface representing a characteristic element is a characteristic surface. Corollaries proved: $w$ characteristic iff $\bar w$ represents $\bar f$ under $\bar Q$; the set of characteristic elements is a coset of $2H$ (forward link to the existence theorem for non-emptiness); $0$ is characteristic iff $Q$ is even; for a diagonal form $\operatorname{diag}(\pm 1)$ the characteristic elements are exactly the vectors with all coordinates odd (verified). Examples: $H$ (hyperbolic): $w = 0$ and all of $2\mathbb{Z}^2$; $\langle 1 \rangle$: odd integers; non-example: $(1, 0)$ is not characteristic for $\langle 1 \rangle \oplus \langle 1 \rangle$.
