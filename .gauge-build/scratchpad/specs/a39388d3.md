## Spec (from the manifest)

type: definition (anchor; compound: regular value, critical point/value, transversality to a finite-dimensional submanifold); source items: A-D6.1.2, A-D6.1.4, A-R6.1.2; prereqs: [Def - Fredholm Map and Its Index, Def - Regular and Critical Points, Def - Embedded Submanifold]; spec: $y\in Y$ is a *regular value* of $F$ if $d_xF$ is surjective for every $x\in F^{-1}(y)$ (vacuously if $F^{-1}(y) = \varnothing$); $\operatorname{Crit}(F)$ := points where $d_xF$ is not surjective, critical values $F(\operatorname{Crit}(F))$; for $Z\subset Y$ a finite-dimensional embedded submanifold, $F\pitchfork Z$ if $\operatorname{Im}d_xF + T_zZ = T_zY$ for all $z\in Z$, $x\in F^{-1}(z)$; $Z = \{z\}$ recovers regular values; examples: finite-dimensional examples ($x\mapsto x^2$ on $\mathbb R$: $0$ critical value; $F\pitchfork Z$ for a curve and a line); non-example: a point in the image where $d_xF$ has cokernel $\ne0$.
