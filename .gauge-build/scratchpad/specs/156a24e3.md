type: theorem (helper 2); source items: A-T6.2.1 (Step 2); prereqs: [Def - Mod-2 Degree of a Proper Fredholm Map, Thm - Inverse Function Theorem on Banach Spaces, Thm - Proper Maps are Closed and Fredholm Maps are Locally Proper]; statement: Let $F:X\to Y$ be a proper Fredholm map of index $0$ and $y$ a regular value with $F^{-1}(y) = \{x_1,\dots,x_k\}$. Then there are disjoint open $V_j\ni x_j$ and an open $U\ni y$ with $F^{-1}(U)\subset\bigsqcup_jV_j$, $F:V_j\to U$ a diffeomorphism; hence every $y'\in U$ is regular with $\#F^{-1}(y') = k$; the count $y\mapsto\#F^{-1}(y)$ is locally constant on the open set of regular values; proof: at each $x_j$, $d_{x_j}F$ is a Fredholm isomorphism (index $0$, surjective ⇒ injective), so the inverse function theorem (Banach version) gives a local diffeomorphism $F:V_j\to U_j$; **the properness step Bär leaves implicit is written out**: shrink $U\subset\bigcap_jF(V_j)$ so that $F^{-1}(U)\subset\bigsqcup V_j$ — if not, there are $y_n\to y$ and $x_n\in F^{-1}(y_n)\setminus\bigsqcup V_j$; $\{y_n\}\cup\{y\}$ is compact, so by properness $\{x_n\}$ has a convergent subsequence $x_n\to x_\infty$ with $F(x_\infty) = y$, so $x_\infty = x_j$ for some $j$, contradicting $x_n\notin V_j$ eventually; spec: helper 2; mechanism: **near a regular value a proper index-zero Fredholm map is a finite covering, so the number of sheets is locally constant**.
