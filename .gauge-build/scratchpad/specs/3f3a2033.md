## Spec (from the manifest)

type: theorem; source items: A-T7.1.13 (Lemma 202), A-I7.1.5; prereqs: [Def - Sobolev Configuration Space and Gauge Group, Thm - The de Rham Complex is Elliptic and Harmonic Forms Represent de Rham Cohomology, Thm - Hodge Theorem for Elliptic Complexes, Thm - Elliptic Regularity and the Elliptic Estimate, Thm - Composition with Analytic Functions on the Sobolev Algebra]; statement: Let $A_0$ be a smooth reference connection on $L_{\det}$. For every $k\ge1$ there are constants $C_1,C_2$ (depending on the metric, $A_0$, $k$) such that: for every $W^{k,2}$-connection $A$ there is a gauge transformation $g\in\mathcal G^{k+1,2}$ with $A\cdot g = A_0 + \alpha$, $\alpha\in W^{k,2}(T^*M\otimes i\mathbb R)$, satisfying the Coulomb condition $d^*\alpha = 0$ and the estimate $\|\alpha\|_{W^{k,2}}\le C_1\|F_A^+\|_{W^{k-1,2}} + C_2$; the harmonic component $\alpha_h$ of $\alpha$ (in $\mathcal H^1$) can be taken bounded in $L^2$ independently of $k$; proof: **Haydys cites Morgan, *The Seiberg–Witten Equations*, Lemma 5.3.1; the series proves it in full** (it is not on the pre-approved import list): write $A = A_0 + b$, $b\in W^{k,2}(T^*M\otimes i\mathbb R)$; solve for $g = e^{i\chi}$ with $d^*(b - d\chi\cdot 2/?)$... precisely, since $A\cdot g = A + 2g^{-1}dg = A_0 + b + 2i\,d\chi$ (for $g = e^{i\chi}$), require $d^*(b + 2i\,d\chi) = 0$, i.e. $2i\,d^*d\chi = -d^*b$; this Laplace equation $\Delta\chi = -\tfrac{1}{2i}d^*b$ on functions is solvable modulo constants iff the right side is $L^2$-orthogonal to the harmonic functions (the constants) — automatic since $d^*b\perp\ker\Delta$ (`Thm - Fredholm Alternative for Elliptic Operators`, IX), giving $\chi\in W^{k+1,2}$ with the elliptic estimate $\|\chi\|_{W^{k+1,2}}\le C\|d^*b\|_{W^{k-1,2}}$; set $\alpha = b + 2i\,d\chi$, so $d^*\alpha = 0$; the estimate $\|\alpha\|_{W^{k,2}}\le C_1\|F_A^+\|_{W^{k-1,2}} + C_2$ comes from the Hodge decomposition $\alpha = \alpha_h + d^*\beta$ (no $d$-part since $d^*\alpha = 0$ forces the exact part to vanish — $\alpha$ is coclosed, so $\alpha\in\mathcal H^1\oplus d^*\Omega^2$, `Thm - The de Rham Complex is Elliptic and Harmonic Forms Represent de Rham Cohomology`), the identity $d^+\alpha = F_A^+ - F_{A_0}^+$, and the elliptic estimate for the folded operator $(d^+,d^*)$ (`Thm - Elliptic Regularity and the Elliptic Estimate`, applied to the elliptic $(d^+,d^*)$: $\|\alpha - \alpha_h\|_{W^{k,2}}\le C\|(d^+\alpha, d^*\alpha)\|_{W^{k-1,2}} = C\|F_A^+ - F_{A_0}^+\|_{W^{k-1,2}}$), with $\alpha_h$ chosen in the fixed finite-dimensional $\mathcal H^1$ (its $L^2$ bound absorbed into $C_2$; the residual gauge freedom of harmonic gauge transformations $H^1(M;\mathbb Z)$ used to reduce $\alpha_h$ to a bounded fundamental domain); spec: mechanism: **a connection can be put in Coulomb gauge by solving a Laplace equation for the gauge parameter, and the elliptic estimate for the Atiyah operator then controls the coclosed remainder by the self-dual curvature**; targets: the bootstrap giving uniform $W^{k,2}$ bounds.
