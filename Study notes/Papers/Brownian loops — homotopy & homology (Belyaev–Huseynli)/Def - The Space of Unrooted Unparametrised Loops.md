# Definition

> **Definition (rooted loop space).**
> $$\mathcal{C}^*_E := \big\{(t,\omega)\ :\ t\geq0,\ \omega\in D([0,t];E),\ \omega(0)=\omega(t)\big\}.$$
> Before §2.2 the same set is used with $C([0,t];E)$ in place of $D([0,t];E)$; from §2.2 on, $\mathcal{C}^*_E$ denotes the càdlàg version, which contains the continuous one.

> **Definition (the equivalence, and $\mathcal{C}_E$).** For $(t,\omega),(s,\tilde\omega)\in\mathcal{C}^*_E$ write $(t,\omega)\sim(s,\tilde\omega)$ iff
> $$\exists\,i:[0,t]/{0\sim t}\to[0,s]/{0\sim s}\ \text{ increasing continuous bijection with }\ \tilde\omega\circ i=\omega .$$
> Set $\mathcal{C}_E:=\mathcal{C}^*_E/\!\sim$, with the quotient $\sigma$-algebra.

**Gloss.** $\sim$ forgets the root and the time parametrisation and **keeps the orientation**, because $i$ is required increasing.

> **(F1) Generators.** $\sim$ is generated by the circular shifts $\mathrm{shift}_{s_0}$ ($t>0$, $s_0\in[0,t)$) together with increasing continuous reparametrisations. Both preserve the càdlàg property, so the same quotient is available in the jump setting.
>
> **(F2) The slice $t=0$.** $\{t=0\}\subseteq\mathcal{C}^*_E$ is the set of constant point-loops, in bijection with $E$. It carries no mass in any construction of the paper.
>
> **(F3) Orientation is not forgotten.** With $\bar\omega(r):=\omega(t-r)$, one has $(t,\bar\omega)\not\sim(t,\omega)$ in general: any $i$ carrying one to the other is decreasing.
>
> **(F4) What $\mathcal{C}_E$ does *not* carry.** For $\omega\in D\setminus C$, the class $q(t,\omega)$ has **no** free homotopy class and admits no lift, because unique path lifting requires continuity. See [[Constr - Loop Mass in a Homotopy Class for Jump Processes]].

# Type card

> [!abstract] Type card — the loop spaces
> **Given.** **(H1)** $E$ a metric space carrying $D([0,t];E)$ for each $t>0$.
>
> **Produces.** A measurable space $\mathcal{C}^*_E$ fibred over $[0,\infty)$; an equivalence $\sim$; the quotient measurable space $\mathcal{C}_E$ and the measurable map $q:\mathcal{C}^*_E\to\mathcal{C}_E$.
>
> **Lets you.** Push a measure on rooted parametrised loops forward to a measure on *geometric* loops — provided that measure is $\sim$-invariant, which is [[Ext - Le Jan Shift-Invariance of the Parametrised Loop Measure|(LJ)]].

# Checks

**Instance.** $E=S^1=\mathbb{R}/2\pi\mathbb{Z}$, $\omega(r)=r$ on $[0,2\pi]$. Its $\sim$-class contains every rotation of the root, $\omega^{s_0}(r)=r+s_0$, and every increasing reparametrisation, e.g. $(1,\omega')$ with $\omega'(r)=2\pi r$. So $q(2\pi,\omega)$ is "once around, anticlockwise" — the geometric object.

**Non-instance (fails the increasing clause).** $\tilde\omega(r)=-r$ on $[0,2\pi]$ satisfies $\tilde\omega(0)=\tilde\omega(2\pi)$ and traverses the same point set, but $(2\pi,\tilde\omega)\not\sim(2\pi,\omega)$: the only $i$ with $\tilde\omega\circ i=\omega$ is $r\mapsto-r$, which is decreasing. Consequence, used twice: free homotopy classes of **oriented** curves correspond to conjugacy classes in $\Gamma$; and $N_{\mathrm{sys}}\geq2$ in [[Thm - Concentration on Systolic Classes]], because $\gamma$ and $\bar\gamma$ are distinct.

# Commentary

> [!note]- Commentary (skippable)
> A loop as a stochastic process hands it to you comes with two artefacts — a starting point and a clock — and neither belongs to the geometric object. $\mathcal{C}^*_E$ is loops-with-artefacts; $\mathcal{C}_E$ is loops. Integrating out the basepoint costs an integral against $\operatorname{vol}_g$; integrating out the duration forces the weight $\mathrm{d}t/t$, the multiplicative Haar measure on $(0,\infty)$, as the unique (up to scale) measure invariant under the rescalings $t\mapsto\lambda t$ that a duration should be indifferent to.
>
> (F4) is the one clause with downstream teeth. It is not a technicality about regularity of paths: it says the topological invariant that the whole paper computes simply does not exist as a function on $\mathcal{C}_X$ once jumps are allowed, and §3 has to define it on a larger marked space instead.
