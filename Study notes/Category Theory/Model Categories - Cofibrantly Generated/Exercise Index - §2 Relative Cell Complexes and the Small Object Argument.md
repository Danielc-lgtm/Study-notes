## §2 Relative Cell Complexes and the Small Object Argument — Exercises

These exercises drill the engine of the chapter: the small object argument and the closure identities that surround it. The first carries out the small object argument in full — building the transfinite tower, proving the left factor is a cell complex and the right factor is injective via smallness, and verifying functoriality — so the construction underlying every factorization becomes reconstructible from scratch. The second proves the structural payoff $I\text{-cof} =$ retracts of $I\text{-cell}$, the identity that reconciles the abstract lifting definition of cofibrations with the constructive cellular one, via the signature factor-lift-retract move. The third proves the saturation of $I\text{-cof}$ — closure under pushout, coproduct, transfinite composition, and retract — the smallness-free backbone that lets a set generate a class. The thread is that the small object argument (needing smallness) plus saturation (needing nothing) together pin down exactly what the cofibrations generated by $I$ are.
