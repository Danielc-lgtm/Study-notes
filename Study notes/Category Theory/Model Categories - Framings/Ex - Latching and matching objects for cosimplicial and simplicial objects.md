# Problem Statement

Compute the [[Def - Reedy Category and the Reedy Model Structure|latching and matching objects]] explicitly for the Reedy categories $\Delta$ and $\Delta^{op}$.

(a) For a cosimplicial object $X^{\bullet} : \Delta \to \mathcal{M}$, describe the latching object $L_n X^{\bullet}$ and the latching map $L_n X^{\bullet} \to X^n$, and identify the matching object $M_n X^{\bullet}$.

(b) For a simplicial object $Y_{\bullet} : \Delta^{op} \to \mathcal{M}$, describe the matching object $M_n Y_{\bullet}$ and the matching map $Y_n \to M_n Y_{\bullet}$. Specialize to a [[Def - Simplicial Set|simplicial set]] $Y_{\bullet}$ in $\mathcal{M} = \mathbf{Set}$ and show that the *latching* object $L_n Y_{\bullet}$ is the set of **degenerate** $n$-simplices, with latching map the inclusion of degeneracies.

(c) Conclude that, in $\mathbf{sSet}$ with cofibrations the monomorphisms, *every* simplicial set is Reedy cofibrant, and identify what Reedy fibrancy of a simplicial set says.

**Recall:**

For a Reedy category $\mathcal{R}$ and a diagram $X$, the **latching object** at $r$ is $L_r X = \operatorname*{colim}_{(s \to r) \in \partial(\mathcal{R}^{+}\downarrow r)} X_s$, the colimit over non-identity *direct* maps into $r$ from strictly lower degree, with the universal cocone giving the latching map $L_r X \to X_r$. The **matching object** is $M_r X = \lim_{(r \to t) \in \partial(r\downarrow\mathcal{R}^{-})} X_t$, the limit over non-identity *inverse* maps out of $r$, with the matching map $X_r \to M_r X$.

For $\Delta$: direct = injections (cofaces $d^i$), inverse = surjections (codegeneracies $s^i$). For $\Delta^{op}$ the roles swap.

# Convergent Strategy

**Problem class:** This is a "compute a latching/matching object as a (co)limit" problem (Legal Operation 2 from the topic page): unwind the abstract colimit/limit into a concrete object by enumerating the indexing maps. The routine is to list the non-identity direct (resp. inverse) maps into (resp. out of) the object, then recognize the resulting colimit (resp. limit) as a familiar construction.

**Assumption pattern:** The asset is the explicit description of $\Delta$'s morphisms as cofaces and codegeneracies, and the fact that, in a Reedy category, only the maps from *strictly lower degree* appear in the latching diagram. For $\Delta$, the direct maps into $[n]$ from lower degree are the cofaces $d^i : [n-1] \to [n]$ (and their composites), so the latching colimit is built from the $X^{n-1}$'s glued along the coface relations.

**Theorem routing:** This uses the [[Def - Reedy Category and the Reedy Model Structure|definitions]] directly and feeds [[Thm - Diagrams over a Reedy Category Form a Model Category]]: the explicit latching/matching objects are what one checks to certify Reedy (co)fibrancy and hence frames. The $\mathbf{Set}$ computation in (b) is the bridge to the classical fact that simplicial-set cofibrations are monomorphisms.

**Key decision point:** The non-obvious move is recognizing the latching object of a simplicial set as the *degenerate simplices*. The latching colimit over codegeneracies $s^i : [n] \to [n-1]$ — read contravariantly for a simplicial set $Y$, these are the degeneracy maps $s_i : Y_{n-1} \to Y_n$ — assembles exactly the simplices in the image of some degeneracy, which is the definition of a degenerate simplex. Seeing the colimit as "the union of degeneracy images" is the key identification.

# Hints

> [!note]- Hint 1
> The direct maps into $[n]$ from strictly lower degree, in $\Delta$, are generated by the cofaces $d^i : [n-1] \to [n]$, $0 \le i \le n$. So the latching diagram for $X^{\bullet}$ at $n$ involves the $n+1$ copies of $X^{n-1}$ (and lower), glued along the cosimplicial identities among the cofaces.

> [!note]- Hint 2
> For a simplicial set $Y$ (a functor $\Delta^{op} \to \mathbf{Set}$), the *inverse* maps of $\Delta^{op}$ are the (opposites of the) codegeneracies, which act on $Y$ as the degeneracy maps $s_i : Y_{n-1} \to Y_n$. The latching object $L_n Y$ is the colimit over these — i.e. the union of the images of all degeneracies.

> [!note]- Hint 3
> An $n$-simplex is **degenerate** if it equals $s_i(\sigma)$ for some $(n-1)$-simplex $\sigma$ and some $i$. The colimit $L_n Y$ is exactly the set of degenerate $n$-simplices, sitting inside $Y_n$ via the latching map. The Eilenberg–Zilber lemma guarantees this is an injection (every simplex is uniquely a degeneracy of a non-degenerate one).

# Solution

The plan: in Step 1 we unwind the latching colimit for a cosimplicial object over the cofaces; in Step 2 we dualize to get the matching object and specialize a simplicial set's latching object to the degenerate simplices; in Step 3 we read off Reedy (co)fibrancy in $\mathbf{sSet}$.

**Step 1: The latching object $L_n X^{\bullet}$ is the colimit of the cofaces.**

> [!note]- Derivation
> Fix a cosimplicial object $X^{\bullet} : \Delta \to \mathcal{M}$ and $n \ge 1$. The latching category $\partial(\Delta^{+}\downarrow [n])$ has objects the non-identity injections $[m] \to [n]$ with $m < n$. Every such injection factors through some coface $d^i : [n-1] \to [n]$, so the colimit is generated by the $n+1$ objects $X^{n-1}$ indexed by the cofaces $d^0, \dots, d^n$, with identifications coming from the cosimplicial identities $d^j d^i = d^i d^{j-1}$ ($i<j$) among the codimension-$2$ injections $[n-2]\to[n]$. Concretely,
> $$L_n X^{\bullet} = \operatorname*{colim}_{(s\to[n])\in\partial(\Delta^{+}\downarrow[n])} X^s,$$
> which one may present as the coequalizer
> $$\coprod_{i<j} X^{n-2} \rightrightarrows \coprod_{i=0}^{n} X^{n-1} \;\longrightarrow\; L_n X^{\bullet},$$
> the two arrows being the two ways $[n-2] \to [n]$ factors through a coface. The latching map $L_n X^{\bullet} \to X^n$ is induced by the cofaces $X^{n-1} = X(d^i)\text{'s sources}$ mapping into $X^n$. For $n = 0$ the latching category is empty, so $L_0 X^{\bullet} = \varnothing$ (initial object) and the latching map is $\varnothing \to X^0$.
>
> The matching object $M_n X^{\bullet}$ is the *limit* over the codegeneracies $s^i : [n] \to [n-1]$; for a cosimplicial object these go *down* in degree, so $M_n X^{\bullet} = \lim$ over the codegeneracies, the "compatible codegeneracy data."

**Step 2: Dualize, and identify a simplicial set's latching object with the degenerate simplices.**

> [!note]- Derivation
> A simplicial object $Y_{\bullet} : \Delta^{op} \to \mathcal{M}$ is a cosimplicial object in $\mathcal{M}^{op}$, so its matching object is the latching object of Step 1 read in $\mathcal{M}^{op}$:
> $$M_n Y_{\bullet} = \lim \big( \text{over the face maps } d_i : Y_n \to Y_{n-1} \big),$$
> presented dually as the equalizer
> $$M_n Y_{\bullet} \;\longrightarrow\; \prod_{i=0}^{n} Y_{n-1} \rightrightarrows \prod_{i<j} Y_{n-2},$$
> the "tuples of $(n-1)$-faces that agree on overlaps," i.e. the compatible boundary data. The matching map $Y_n \to M_n Y_{\bullet}$ sends an $n$-simplex to its tuple of faces $(d_0\sigma, \dots, d_n\sigma)$.
>
> Now the *latching* object of a simplicial set. The direct maps of $\Delta^{op}$ are the opposites of the codegeneracies, which act on $Y$ as the degeneracy maps $s_i : Y_{n-1} \to Y_n$. So
> $$L_n Y_{\bullet} = \operatorname*{colim}\big(\text{over the degeneracies } s_i : Y_{n-1} \to Y_n\big) \;=\; \bigcup_{i=0}^{n-1} s_i(Y_{n-1}) \;\subseteq\; Y_n,$$
> the union of the images of all degeneracy maps — that is, the set of **degenerate** $n$-simplices. By the Eilenberg–Zilber lemma each degenerate simplex is uniquely $s_{i_1}\cdots s_{i_k}\sigma$ for a unique non-degenerate $\sigma$, so the colimit is exactly this subset and the latching map $L_n Y_{\bullet} \hookrightarrow Y_n$ is the inclusion of degenerate simplices, a monomorphism.

**Step 3: Every simplicial set is Reedy cofibrant; Reedy fibrancy is the Kan condition's source.**

> [!note]- Derivation
> In $\mathbf{sSet} = \mathbf{Set}^{\Delta^{op}}$ the standard cofibrations are the monomorphisms. By Step 2 the latching map $L_n Y_{\bullet} \hookrightarrow Y_n$ is the inclusion of degenerate simplices, which is injective, hence a monomorphism, hence a cofibration — for *every* $n$ and *every* simplicial set $Y$. Therefore every object of $\mathbf{sSet}$ is **Reedy cofibrant**. (This is why frames and homotopy colimits over $\Delta^{op}$ are so well-behaved in simplicial sets: cofibrancy is automatic.)
>
> Reedy *fibrancy* of $Y_{\bullet}$ requires each matching map $Y_n \to M_n Y_{\bullet}$ to be a fibration; in $\mathbf{sSet}$ this is a Kan fibration condition, and the absolute version (matching maps are fibrations to the point) is closely tied to $Y$ being a **Kan complex** — the matching object packages exactly the boundary data a horn-filling condition must extend. So Reedy fibrancy of simplicial objects is the structural home of the Kan/horn-filling condition.

> [!note]- Complete formal solution
> **(a)** For $X^{\bullet} : \Delta \to \mathcal{M}$, $L_n X^{\bullet} = \operatorname*{colim}_{(s\to[n])} X^s$ over non-identity cofaces, presented as the coequalizer $\coprod_{i<j} X^{n-2} \rightrightarrows \coprod_i X^{n-1} \to L_n X^{\bullet}$, with latching map induced by the cofaces; $L_0 X^{\bullet} = \varnothing$. The matching object is the limit over codegeneracies.
>
> **(b)** For $Y_{\bullet}:\Delta^{op}\to\mathcal{M}$, $M_n Y_{\bullet} = \lim$ over face maps, the equalizer $M_n Y_{\bullet} \to \prod_i Y_{n-1} \rightrightarrows \prod_{i<j} Y_{n-2}$, with matching map $\sigma \mapsto (d_0\sigma,\dots,d_n\sigma)$. For a simplicial set, $L_n Y_{\bullet} = \bigcup_i s_i(Y_{n-1})$ is the set of degenerate $n$-simplices and the latching map is their inclusion into $Y_n$, injective by Eilenberg–Zilber.
>
> **(c)** Since the latching map of a simplicial set is the injective inclusion of degeneracies and cofibrations in $\mathbf{sSet}$ are monomorphisms, every simplicial set is Reedy cofibrant. Reedy fibrancy demands each matching map $Y_n \to M_n Y_{\bullet}$ be a Kan fibration, the structural form of the horn-filling/Kan condition. $\blacksquare$

# Key Takeaways

**The latching object is "the part already built from below," and for simplicial sets that part is exactly the degenerate simplices.** This is the single most clarifying picture in Reedy theory: the relative latching map measures how much *new* data a given degree contributes beyond what the lower degrees force, and for a simplicial set the lower degrees force precisely the degenerate simplices — the ones obtained by collapsing higher simplices via degeneracies. So "Reedy cofibrant" for a simplicial set means "the degeneracies inject," which is automatic, and "non-degenerate simplices are the genuinely new cells." Carry this dictionary: latching object ↔ degenerate/already-forced part, relative latching map ↔ newly attached non-degenerate cells. It recurs whenever you build a diagram or a frame degree by degree, and it is why frames are "iterated cylinders attached freely."

**Matching objects are the dual — the compatible boundary data — and they are where the Kan condition lives.** Where the latching object collects degeneracies (built from below by colimit), the matching object collects faces (constrained from below by limit): $M_n Y_{\bullet}$ is the object of tuples of $(n-1)$-faces that agree on their common $(n-2)$-faces, the abstract "boundary $\partial$." A matching map being a fibration is the condition that an $n$-simplex can be found extending any compatible boundary — exactly the shape of a horn-filling/Kan condition. This is the trigger to remember: whenever you need a fibrancy or extension condition on a simplicial object, compute the matching object and ask whether the matching map lifts, because that is what Reedy fibrancy and the Kan condition both come down to.

**Automatic Reedy cofibrancy in $\mathbf{sSet}$ is what makes simplicial sets the convenient model.** Because the latching map of any simplicial set is a monomorphism and monomorphisms are the cofibrations, *every* simplicial set is Reedy cofibrant — no replacement needed on the cofibration side. This is a structural luxury: homotopy colimits over $\Delta^{op}$, geometric realizations, and frames in $\mathbf{sSet}$ require no cofibrant replacement of the diagram, only fibrant replacement of the target. The general lesson for choosing a model category to compute in: prefer one where the cofibrancy you need is automatic, because then "resolve, then compute" collapses to "compute." The dual computation for cosimplicial objects, where the *constant* object fails latching cofibrancy, is exactly the subtlety explored in [[Ex - The constant cosimplicial object is rarely a frame]].
