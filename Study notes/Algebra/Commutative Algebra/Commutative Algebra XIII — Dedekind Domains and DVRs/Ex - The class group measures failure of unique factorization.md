# Problem Statement

Let $A$ be a [[Def - Dedekind Domain|Dedekind domain]]. Prove that the [[Def - Fractional Ideal and the Ideal Class Group|ideal class group]] $\operatorname{Cl}(A)$ exactly measures the failure of unique factorization, in the precise sense:

$$\operatorname{Cl}(A) \text{ is trivial} \iff A \text{ is a PID} \iff A \text{ is a UFD}.$$

Then compute a nontrivial example: show that for $A = \mathbb{Z}[\sqrt{-5}]$, the class of the prime $\mathfrak{p} = (2, 1+\sqrt{-5})$ has order exactly $2$ in $\operatorname{Cl}(A)$, and (granting that $\operatorname{Cl}(A)$ is generated by classes of small primes) conclude $\operatorname{Cl}(\mathbb{Z}[\sqrt{-5}]) \cong \mathbb{Z}/2\mathbb{Z}$ — so $\mathbb{Z}[\sqrt{-5}]$ fails unique factorization, and its class number is $2$.

**Recall:**

![[Def - Fractional Ideal and the Ideal Class Group#The Definition]]

$\operatorname{Cl}(A) = \mathcal{I}(A)/\mathcal{P}(A)$, the group of nonzero [[Def - Fractional Ideal and the Ideal Class Group|fractional ideals]] modulo the principal ones; two ideals are in the same class iff $\mathfrak{a} = x\mathfrak{b}$ for some $x \in K^\times$. By [[Thm - A Dedekind Domain has Unique Factorization of Ideals|unique factorization of ideals]], $\mathcal{I}(A)$ is free abelian on the primes.

For a [[Def - Principal Ideal Domain|PID]], every ideal is principal; for a [[Def - Unique Factorization Domain|UFD]], every element factors uniquely into irreducibles. The norm $N(a + b\sqrt{-5}) = a^2 + 5b^2$ is multiplicative.

# Convergent Strategy

**Problem class.** This has two halves: an *equivalence of structural conditions* (class group trivial $\iff$ PID $\iff$ UFD), and a *concrete class-group computation* exhibiting a nontrivial class. The first is the conceptual payoff of the chapter; the second is the canonical nontrivial example, where the [[Commutative Algebra XIII — Dedekind Domains and DVRs#Insights|norm-obstruction reflex]] does the work.

**Assumption pattern.** For the equivalence, the key facts are: (i) "$\operatorname{Cl}(A)$ trivial" means every ideal is principal, which is literally "PID"; (ii) the subtle direction is "Dedekind $+$ UFD $\Rightarrow$ PID", which uses that in a UFD a minimal nonzero prime is principal, and in a one-dimensional ring every nonzero prime is minimal. For the computation, the pattern is: a class has finite order, and to find the order of $[\mathfrak{p}]$, find the smallest $n$ with $\mathfrak{p}^n$ principal — here $\mathfrak{p}^2 = (2)$ is principal but $\mathfrak{p}$ is not, so the order is $2$.

**Theorem routing.** *Equivalence:* "trivial $\Rightarrow$ PID" is immediate; "PID $\Rightarrow$ UFD" is a standard ring-theory fact; "UFD $\Rightarrow$ trivial" routes through "in a UFD every height-one prime is principal" plus "dimension $1$ makes every nonzero prime height-one", giving all primes principal, hence (by unique factorization) all ideals principal, hence $\operatorname{Cl}(A) = 0$. *Computation:* show $\mathfrak{p}^2 = (2)$ (from [[Ex - Unique factorization of ideals in Z[sqrt -5] into primes|the ℤ[\sqrt{-5}] factorization]]) so $[\mathfrak{p}]^2 = 1$; show $\mathfrak{p}$ non-principal by the norm ($a^2 + 5b^2 = 2$ unsolvable) so $[\mathfrak{p}] \neq 1$; conclude order $2$.

**Key decision point.** The genuinely tricky direction is **UFD $\Rightarrow$ PID for a Dedekind domain** — most people know "PID $\Rightarrow$ UFD" but the converse needs the dimension-one structure. The decisive fact is: *in a UFD, a minimal nonzero prime is principal* (it contains an irreducible $\pi$, and $(\pi) \subseteq \mathfrak{p}$ is a nonzero prime contained in $\mathfrak{p}$, so minimality forces $(\pi) = \mathfrak{p}$); and *in a one-dimensional domain, every nonzero prime is minimal among nonzero primes*. Together: every nonzero prime is principal, so by unique factorization every ideal is principal. The non-obvious recognition is that "UFD" alone does not give "PID" in general (e.g. $k[x,y]$ is a UFD but not a PID) — it is the *dimension-one* hypothesis that closes the gap, and spotting that is the crux.

This solution deploys the following legal operations from [[Commutative Algebra XIII — Dedekind Domains and DVRs#Legal Operations|the topic page's Legal Operations]]:

1. **Invert a fractional ideal / work in the class group (operation 5).** Classes multiply: $[\mathfrak{a}\mathfrak{b}] = [\mathfrak{a}][\mathfrak{b}]$, so $\mathfrak{p}^2$ principal gives $[\mathfrak{p}]^2 = 1$.

2. **Use a norm to obstruct principality (insights trigger).** $\mathfrak{p}$ non-principal because no element has norm $2$.

3. **Translate "contains" into "divides" (operation 6) and certify Dedekind (operation 8).** Used in the UFD $\Rightarrow$ PID argument: a height-one prime contains an irreducible, and divisibility of ideals pins the containment.

# Hints

> [!note]- Hint 1
> The equivalence has an easy part and a hard part. "$\operatorname{Cl}(A)$ trivial $\iff$ PID" is almost a definition (trivial class group means every ideal is principal). "PID $\Rightarrow$ UFD" is standard. The work is "UFD $\Rightarrow$ PID" — and this is where the *dimension-one* hypothesis is essential.

> [!note]- Hint 2
> In a UFD, take a minimal nonzero prime $\mathfrak{p}$. It contains some nonzero element, which factors into irreducibles, so $\mathfrak{p}$ contains an irreducible $\pi$. Then $(\pi)$ is a nonzero prime (irreducibles are prime in a UFD) contained in $\mathfrak{p}$. What does minimality of $\mathfrak{p}$ force?

> [!note]- Hint 3
> Minimality forces $(\pi) = \mathfrak{p}$, so $\mathfrak{p}$ is principal. In a Dedekind domain *every* nonzero prime is minimal (dimension $1$), so every nonzero prime is principal. By unique factorization, every ideal is a product of (principal) primes, hence principal — so $A$ is a PID.

> [!note]- Hint 4
> For the computation: from the $\mathbb{Z}[\sqrt{-5}]$ factorization, $\mathfrak{p}^2 = (2)$ is principal, so $[\mathfrak{p}]^2 = [(2)] = 1$ in $\operatorname{Cl}(A)$ — the class has order $1$ or $2$. To rule out order $1$, show $\mathfrak{p}$ is *not* principal: a generator would have norm $N(\mathfrak{p}) = 2$, but $a^2 + 5b^2 = 2$ has no solution. So the order is exactly $2$.

# Solution

The proof splits into the equivalence and the computation. The equivalence's only hard arrow is UFD $\Rightarrow$ PID, where dimension one makes every nonzero prime minimal, hence (in a UFD) principal. The computation shows $[\mathfrak{p}]$ has order $2$: $\mathfrak{p}^2 = (2)$ is principal but $\mathfrak{p}$ is not, by a norm obstruction.

**Step 1: $\operatorname{Cl}(A)$ trivial $\iff$ PID.**

> [!note]- Derivation
> If $\operatorname{Cl}(A) = \mathcal{I}(A)/\mathcal{P}(A)$ is trivial, then every fractional ideal is principal; in particular every integral ideal is principal, so $A$ is a PID. Conversely, if $A$ is a PID, every fractional ideal $\mathfrak{a} = \tfrac1d\mathfrak{b}$ with $\mathfrak{b} = (b)$ principal is $(\tfrac bd)$, principal, so $\mathcal{I}(A) = \mathcal{P}(A)$ and $\operatorname{Cl}(A) = 0$. Hence triviality of the class group is *exactly* the PID condition.

**Step 2: PID $\Rightarrow$ UFD.**

> [!note]- Derivation
> This is the standard implication: every PID is a UFD. (In a PID the ascending chain condition gives existence of irreducible factorizations, and "irreducible $\Rightarrow$ prime" — proved via Bézout — gives uniqueness. See [[Thm - Principal Ideal Domains are Unique Factorization Domains]].) So a Dedekind domain with trivial class group, being a PID, is a UFD.

**Step 3: UFD $\Rightarrow$ PID (the hard direction; uses dimension $1$).**

A Dedekind domain that is a UFD is a PID.

> [!note]- Derivation
> Let $A$ be Dedekind and a UFD. We show every nonzero prime $\mathfrak{p}$ is principal; unique factorization of ideals then makes every ideal a product of principal primes, hence principal.
>
> Take a nonzero prime $\mathfrak{p}$. Since $\dim A = 1$, $\mathfrak{p}$ is maximal, hence **minimal among nonzero primes** (there is no nonzero prime strictly inside it: such a prime would give a chain $(0) \subsetneq \mathfrak{p}' \subsetneq \mathfrak{p}$ of length $2$, contradicting $\dim A = 1$). Now $\mathfrak{p} \neq 0$, so pick $0 \neq a \in \mathfrak{p}$; in the UFD $A$, $a$ factors as a unit times irreducibles, $a = u\pi_1\cdots\pi_r$. Since $\mathfrak{p}$ is prime and $a \in \mathfrak{p}$, some $\pi_i \in \mathfrak{p}$. In a UFD irreducibles are prime, so $(\pi_i)$ is a nonzero prime ideal, and $(\pi_i) \subseteq \mathfrak{p}$. By minimality of $\mathfrak{p}$ among nonzero primes, $(\pi_i) = \mathfrak{p}$. So $\mathfrak{p}$ is principal.
>
> Thus every nonzero prime is principal. By [[Thm - A Dedekind Domain has Unique Factorization of Ideals|unique factorization of ideals]], every nonzero ideal $\mathfrak{a} = \prod\mathfrak{p}_i^{e_i} = \prod(\pi_i)^{e_i} = (\prod\pi_i^{e_i})$ is principal. Hence $A$ is a PID, so $\operatorname{Cl}(A) = 0$ by Step 1. This closes the cycle trivial $\Rightarrow$ PID $\Rightarrow$ UFD $\Rightarrow$ trivial.

**Step 4: compute $[\mathfrak{p}]$ has order $2$ in $\operatorname{Cl}(\mathbb{Z}[\sqrt{-5}])$.**

For $A = \mathbb{Z}[\sqrt{-5}]$ and $\mathfrak{p} = (2, 1+\sqrt{-5})$, the class $[\mathfrak{p}]$ has order exactly $2$.

> [!note]- Derivation
> From the [[Ex - Unique factorization of ideals in Z[sqrt -5] into primes|ℤ[\sqrt{-5}] factorization]], $\mathfrak{p}^2 = (2)$, a principal ideal. So in $\operatorname{Cl}(A)$,
> $$[\mathfrak{p}]^2 = [\mathfrak{p}^2] = [(2)] = 1,$$
> meaning $[\mathfrak{p}]$ has order dividing $2$ — order $1$ or $2$.
>
> **Order is not $1$.** Suppose $[\mathfrak{p}] = 1$, i.e. $\mathfrak{p}$ is principal, $\mathfrak{p} = (\alpha)$ for some $\alpha = a + b\sqrt{-5}$. Then the ideal norm gives $N(\mathfrak{p}) = |N(\alpha)| = a^2 + 5b^2$. But $N(\mathfrak{p}) = |A/\mathfrak{p}| = 2$ (Step 2 of the factorization exercise), so we would need
> $$a^2 + 5b^2 = 2,$$
> which has no integer solution: $b = 0$ forces $a^2 = 2$ (impossible), and $|b| \geq 1$ forces $a^2 + 5b^2 \geq 5 > 2$. So $\mathfrak{p}$ is *not* principal, $[\mathfrak{p}] \neq 1$.
>
> Therefore $[\mathfrak{p}]$ has order exactly $2$.

**Step 5: conclude $\operatorname{Cl}(\mathbb{Z}[\sqrt{-5}]) \cong \mathbb{Z}/2\mathbb{Z}$.**

> [!note]- Derivation
> The Minkowski bound for $\mathbb{Q}(\sqrt{-5})$ (discriminant $-20$) is $\tfrac{2}{\pi}\sqrt{20} \approx 2.85$, so every ideal class contains an integral ideal of norm $\leq 2$, hence is represented by a prime above $2$. The only prime above $2$ is $\mathfrak{p}$ (with $\mathfrak{p}^2 = (2)$), and primes above $1$ are trivial. So $\operatorname{Cl}(A)$ is generated by $[\mathfrak{p}]$, which has order $2$. Therefore
> $$\operatorname{Cl}(\mathbb{Z}[\sqrt{-5}]) = \langle [\mathfrak{p}]\rangle \cong \mathbb{Z}/2\mathbb{Z}, \qquad h = 2.$$
> Since $\operatorname{Cl}(A) \neq 0$, $\mathbb{Z}[\sqrt{-5}]$ is not a PID, hence (by the equivalence) not a UFD — consistent with $6 = 2\cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5})$.

> [!note]- Complete formal solution
> **Equivalence.** $\operatorname{Cl}(A) = 0 \iff$ every ideal principal $\iff A$ is a PID. PID $\Rightarrow$ UFD is standard. For UFD $\Rightarrow$ PID: a nonzero prime $\mathfrak{p}$ is maximal (dimension $1$), hence minimal among nonzero primes; picking $0 \neq a \in \mathfrak{p}$ and factoring $a$ into irreducibles, some irreducible $\pi \in \mathfrak{p}$, and $(\pi)$ is a nonzero prime $\subseteq \mathfrak{p}$, so $(\pi) = \mathfrak{p}$ by minimality. All primes principal $\Rightarrow$ (unique factorization) all ideals principal $\Rightarrow$ PID. So all three conditions are equivalent.
>
> **Computation.** In $A = \mathbb{Z}[\sqrt{-5}]$, $\mathfrak{p} = (2, 1+\sqrt{-5})$ satisfies $\mathfrak{p}^2 = (2)$, so $[\mathfrak{p}]^2 = 1$. If $\mathfrak{p} = (\alpha)$ then $a^2 + 5b^2 = N(\mathfrak{p}) = 2$, impossible; so $\mathfrak{p}$ is non-principal and $[\mathfrak{p}]$ has order $2$. By the Minkowski bound $\approx 2.85$, $\operatorname{Cl}(A)$ is generated by primes of norm $\leq 2$, i.e. by $[\mathfrak{p}]$, so $\operatorname{Cl}(A) \cong \mathbb{Z}/2$, $h = 2$. Hence $\mathbb{Z}[\sqrt{-5}]$ is not a UFD. $\blacksquare$

> [!warning] Illegal but tempting: concluding UFD from "ideals factor uniquely"
> Unique factorization of *ideals* always holds in a Dedekind domain, so it is tempting to conclude the ring is a UFD. It is not: $\mathbb{Z}[\sqrt{-5}]$ has unique ideal factorization but is not a UFD. The gap is exactly $\operatorname{Cl}(A)$: ideals factor into primes uniquely, but the primes need not be *principal*, and only when they all are (trivial class group) do you recover unique factorization of elements. The class group is the precise obstruction, and its order $h = 2$ is the quantitative measure of how badly $\mathbb{Z}[\sqrt{-5}]$ fails to be a UFD.

# Key Takeaways

**The class group is the exact obstruction to unique factorization, and "UFD $\Rightarrow$ PID" needs dimension one.** The headline equivalence — trivial class group $\iff$ PID $\iff$ UFD — holds only for Dedekind domains, and the subtle arrow is UFD $\Rightarrow$ PID. In general a UFD need not be a PID ($k[x,y]$, $\mathbb{Z}[x]$ are UFDs but not PIDs), and what closes the gap is dimension one: it makes every nonzero prime *minimal*, and in a UFD a minimal nonzero prime is principal (it contains an irreducible $\pi$, and $(\pi) \subseteq \mathfrak{p}$ being a nonzero prime forces equality). The transferable principle: when proving "UFD $\Rightarrow$ PID" or recognizing when a UFD is a PID, the question is always whether the primes are forced to be height-one and hence principal — for Dedekind domains they always are. This is why "Dedekind UFD" is a strong condition: it collapses all the way to PID, while "UFD" alone is much weaker.

**To find the order of an ideal class, find the smallest power that becomes principal, and use the norm to prove non-principality.** The computation of $[\mathfrak{p}]$'s order is the model: $\mathfrak{p}^2 = (2)$ is principal so the order divides $2$, and $\mathfrak{p}$ itself is non-principal so the order is exactly $2$. The non-principality is established by the **norm obstruction** — a principal ideal $(\alpha)$ has ideal norm $|N(\alpha)|$, so if $N(\mathfrak{p}) = 2$ is not a value of the norm form $a^2 + 5b^2$, then $\mathfrak{p}$ cannot be principal. The trigger to deploy this whenever you must compute a class group: factor small primes into ideals, find the relations $\mathfrak{p}^n = (\text{element})$, and use norms to detect which ideals are genuinely non-principal. The class group is generated by primes below the Minkowski bound, so only finitely many primes need checking — this makes class numbers explicitly computable.

**$\mathbb{Z}[\sqrt{-5}]$ with $h = 2$ is the prototype of "ideal factorization works, element factorization does not, and the class group says by how much".** This example crystallizes the entire chapter. The ring is Dedekind (so ideals factor uniquely), it is not a UFD (so elements do not), and the precise discrepancy is $\operatorname{Cl}(A) = \mathbb{Z}/2$ — a single nontrivial class, generated by the prime $\mathfrak{p}$ that you cannot see as an element. The two factorizations of $6$ are the two ways of pairing $\{\mathfrak{p}, \mathfrak{p}, \mathfrak{q}, \bar{\mathfrak{q}}\}$ into principal products, and the obstruction to a *unique* element factorization is exactly that $\mathfrak{p}, \mathfrak{q}$ are non-principal — that $[\mathfrak{p}] \neq 1$. Carry this as the canonical picture: the class group counts the "phantom" prime ideals that have no element generator, and a nontrivial class is a line bundle on the arithmetic curve $\operatorname{Spec}\mathbb{Z}[\sqrt{-5}]$ with no global trivialization. The deeper development — finiteness of $\operatorname{Cl}(\mathcal{O}_K)$, the class number formula, Kummer's theorem on regular primes — all begins here, with the recognition that the class group *is* the failure of unique factorization, made into a group.
