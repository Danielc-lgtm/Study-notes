# Notation

$\varphi : G \to H$ is a [[Def - Homomorphism|group homomorphism]], with $e_G, e_H$ the identities of $G$ and $H$. The **kernel** is written $\ker\varphi$ and lives inside $G$; the **image** is written $\operatorname{im}\varphi$ (or $\varphi(G)$) and lives inside $H$. We write $N \trianglelefteq G$ for a [[Def - Normal Subgroup|normal subgroup]] and $K \leq H$ for a [[Def - Subgroup|subgroup]]. The full symbol registry is on [[Group Theory I — §1.1–1.2]].

---

# Axiom Motivation

A [[Def - Homomorphism|homomorphism]] $\varphi : G \to H$ is a comparison between two groups, but a homomorphism on its own is a hard thing to grasp — it is a function, an infinite table of input–output pairs. To *understand* a homomorphism we want to extract from it a few finite, structural invariants that summarise its behaviour. There are exactly two natural questions to ask of any function, and the kernel and the image are the answers.

The first question is: **how much does $\varphi$ collapse?** A homomorphism need not be injective; it may send many elements of $G$ to the same element of $H$. We want to measure this failure of injectivity. The cleanest measurement, given that $\varphi$ is a homomorphism, is to look at *which elements get sent to the identity* $e_H$ — to look at $\ker\varphi := \{g \in G : \varphi(g) = e_H\}$. Why is this the right thing, rather than, say, recording the full equivalence relation "$\varphi(g) = \varphi(g')$"? Because for a homomorphism that whole relation is determined by the kernel alone: $\varphi(g) = \varphi(g')$ if and only if $\varphi(g^{-1}g') = e_H$, i.e. if and only if $g^{-1}g' \in \ker\varphi$. So two elements have the same image exactly when they differ by an element of the kernel. The single set $\ker\varphi$ encodes the *entire* collapsing behaviour. This is special to homomorphisms; for an arbitrary function the preimage of one point tells you nothing about the preimages of others. The desideratum "measure the collapse with one finite gadget" is met, and met uniquely, by the kernel.

The second question is: **what does $\varphi$ actually reach?** A homomorphism into $H$ need not be surjective; it lands in some part of $H$. That part is $\operatorname{im}\varphi := \{\varphi(g) : g \in G\}$, the set of values actually attained. The desideratum here is just "record the reachable elements", and the image is the literal answer.

What makes these two definitions *good* — and not arbitrary set-theoretic bookkeeping — is that each turns out to be a subgroup, and moreover the kernel is a *normal* subgroup. That is not built into the definitions; it is a theorem (proved below), and it is the whole reason the kernel and image matter. If the kernel were merely a subset, it would be inert. Because it is automatically [[Def - Normal Subgroup|normal]], it can be quotiented by, and the [[Thm - First Isomorphism Theorem|first isomorphism theorem]] can fire. The motivation for *defining* the kernel is the structural payoff: it converts a homomorphism into a normal subgroup, and normal subgroups are the objects we know how to take apart.

One could imagine *weakening* — measuring injectivity by some coarser invariant, like "the number of elements mapping to $e_H$" rather than the set itself. That number tells you the *size* of every fibre but loses which elements differ by what; you could no longer form a quotient. One could imagine *strengthening* the image to "the subgroup generated by the values" — but the values already form a subgroup, so the strengthening is vacuous. The kernel-as-a-set and the image-as-a-set are exactly the right invariants: any less and the [[Thm - First Isomorphism Theorem|first isomorphism theorem]] cannot be stated; any more and there is nothing further to add.

# The Definition

This is a compound definition: two notions attached to every [[Def - Homomorphism|homomorphism]] $\varphi : G \to H$.

### The Kernel

The **kernel** of $\varphi$ is the set of elements of $G$ sent to the identity of $H$:
$$\ker\varphi := \{g \in G : \varphi(g) = e_H\}.$$

**The kernel is a normal subgroup of $G$**, $\ker\varphi \trianglelefteq G$.

*It is a subgroup.* It is nonempty: $\varphi(e_G) = e_H$, so $e_G \in \ker\varphi$. It is closed under "product with an inverse", which by the subgroup criterion suffices: if $g, h \in \ker\varphi$ then
$$\varphi(g h^{-1}) = \varphi(g)\,\varphi(h)^{-1} = e_H \cdot e_H^{-1} = e_H,$$
so $gh^{-1} \in \ker\varphi$.

*It is normal.* Take $g \in \ker\varphi$ and any $x \in G$. Then
$$\varphi(x^{-1} g x) = \varphi(x^{-1})\,\varphi(g)\,\varphi(x) = \varphi(x^{-1})\,e_H\,\varphi(x) = \varphi(x^{-1})\,\varphi(x) = \varphi(x^{-1}x) = \varphi(e_G) = e_H,$$
so $x^{-1} g x \in \ker\varphi$. Conjugation never leaves the kernel, which is exactly [[Def - Normal Subgroup|normality]].

### The Image

The **image** of $\varphi$ is the set of values $\varphi$ attains:
$$\operatorname{im}\varphi := \{h \in H : h = \varphi(g) \text{ for some } g \in G\} = \varphi(G).$$

**The image is a subgroup of $H$**, $\operatorname{im}\varphi \leq H$.

It is nonempty: $e_H = \varphi(e_G) \in \operatorname{im}\varphi$. It is closed under product-with-inverse: if $\varphi(g), \varphi(h) \in \operatorname{im}\varphi$ then
$$\varphi(g)\,\varphi(h)^{-1} = \varphi(g)\,\varphi(h^{-1}) = \varphi(gh^{-1}) \in \operatorname{im}\varphi,$$
so by the subgroup criterion $\operatorname{im}\varphi \leq H$. Note the image is **not** in general normal in $H$ — only the kernel carries automatic normality.

### Injectivity criterion

$$\varphi \text{ is injective} \iff \ker\varphi = \{e_G\}.$$
A homomorphism with trivial kernel collapses nothing, hence is injective; conversely an injective $\varphi$ can send only $e_G$ to $e_H$. *Proof:* if $\ker\varphi = \{e_G\}$ and $\varphi(g) = \varphi(g')$, then $\varphi(g^{-1}g') = e_H$, so $g^{-1}g' \in \ker\varphi = \{e_G\}$, giving $g = g'$. Conversely if $\varphi$ is injective then $\varphi(g) = e_H = \varphi(e_G)$ forces $g = e_G$. This is a major economy: to check injectivity of a homomorphism you need only inspect *one* fibre, the kernel — never the whole function.

# Categorical Definition

The kernel has a clean universal-property description. First, the vocabulary: a **universal property** characterises an object by the maps relating to it, declaring it the most efficient object of its kind, through which every competitor factors uniquely. "Factors through $X$" means: any qualifying map equals (the canonical map of $X$) followed by exactly one further map.

The kernel of $\varphi : G \to H$ is the universal subgroup of $G$ on which $\varphi$ becomes trivial. Precisely: write $\iota : \ker\varphi \hookrightarrow G$ for the inclusion. Then $\varphi \circ \iota$ is the trivial homomorphism (everything in $\ker\varphi$ maps to $e_H$), and $\ker\varphi$ is *terminal* among groups with that feature — for any group $A$ and any homomorphism $f : A \to G$ with $\varphi \circ f$ trivial, there is a unique homomorphism $\tilde f : A \to \ker\varphi$ with $f = \iota \circ \tilde f$:
$$\begin{array}{ccc} A & \xrightarrow{\ f\ } & G \xrightarrow{\ \varphi\ } H \\ {\scriptstyle\tilde f}\big\downarrow & \nearrow_{\scriptstyle\iota} & \\ \ker\varphi & & \end{array}$$
The map $\tilde f$ is forced: $f$ sends every element of $A$ into $\{g : \varphi(g) = e_H\} = \ker\varphi$, so $\tilde f$ is just $f$ with codomain restricted, and uniqueness is automatic because $\iota$ is injective. The content is that $\ker\varphi$ is the *largest* subgroup of $G$ killed by $\varphi$ — every $\varphi$-killed map factors through it. In categorical language $\ker\varphi$ is the **equaliser** of the pair $(\varphi,\ \text{trivial map}) : G \rightrightarrows H$ — the universal subobject of $G$ on which the two maps agree. This is the exact dual of the [[Def - Quotient Group|quotient group]], which is the *coequaliser*: the kernel is the universal way to *restrict the domain so $\varphi$ vanishes*, the quotient is the universal way to *collapse the codomain so a chosen subgroup vanishes*. The [[Thm - First Isomorphism Theorem|first isomorphism theorem]] is precisely the statement that these two operations, applied to the same homomorphism, fit together as $G/\ker\varphi \cong \operatorname{im}\varphi$.

The image has a (less essential) universal description as the smallest subgroup of $H$ through which $\varphi$ factors — $\varphi$ corestricts to $G \to \operatorname{im}\varphi$, and any subgroup $K \leq H$ with $\varphi(G) \subseteq K$ admits a unique factoring — making $\operatorname{im}\varphi$ the image in the categorical sense (the smallest subobject containing the range).

# Relate to Other Fields / Compression

Kernel and image are the group instance of a universal pair attached to every morphism in every algebraic category. For a *linear map* $T : V \to W$, the kernel is the **null space** and the image is the **column space (range)**; the rank–nullity theorem $\dim V = \dim\ker T + \dim\operatorname{im} T$ is the linear-algebra shadow of the [[Thm - First Isomorphism Theorem|first isomorphism theorem]] ($V/\ker T \cong \operatorname{im} T$, then take dimensions). For a *ring homomorphism* the kernel is a two-sided [[Def - Ideal|ideal]] — and this is the origin of the very word "ideal", which began as "ideal number", a kernel-like object. For a *module homomorphism* the kernel is a submodule. In each case the kernel is automatically the "quotientable" substructure of the source, and the image is a substructure of the target — the same division of labour as for groups. The single feature special to groups is that the kernel's automatic property is *normality* (a non-trivial condition) rather than being just-any-subobject; in the abelian worlds of rings, modules, and vector spaces every subobject is quotientable, so the distinction vanishes.

The deepest compression — the "true name" of normality — is the equivalence: **the normal subgroups of $G$ are exactly the kernels of homomorphisms out of $G$.** One direction is the theorem above (every kernel is normal); the other is that every [[Def - Normal Subgroup|normal subgroup]] $N$ is $\ker(\pi)$ for the [[Def - Quotient Group|quotient map]] $\pi : G \to G/N$. So "normal subgroup" and "kernel" are two names for one class of objects. Conjugation-invariance is the *verification criterion*; being a kernel is the *meaning*. Whenever a normal subgroup appears, the productive mental image is not a conjugation calculation but the homomorphism it is the kernel of.

# Examples / Corollaries

**Kernel and image of $\det : \mathrm{GL}_n(\mathbb{R}) \to \mathbb{R}^\times$.** The kernel is $\{A : \det A = 1\} = \mathrm{SL}_n(\mathbb{R})$, the special linear group — automatically a *normal* subgroup of $\mathrm{GL}_n(\mathbb{R})$, which is the cleanest proof that $\mathrm{SL}_n \trianglelefteq \mathrm{GL}_n$. The image is all of $\mathbb{R}^\times$, since every nonzero real is a determinant (scale one diagonal entry). The [[Thm - First Isomorphism Theorem|first isomorphism theorem]] then reads $\mathrm{GL}_n(\mathbb{R})/\mathrm{SL}_n(\mathbb{R}) \cong \mathbb{R}^\times$.

**Kernel and image of $\operatorname{sgn} : S_n \to \{\pm 1\}$.** The kernel is the alternating group $A_n$ of even permutations — automatically normal in $S_n$. The image is all of $\{\pm 1\}$ for $n \geq 2$. Hence $S_n/A_n \cong \{\pm 1\} \cong C_2$.

**Kernel and image of the quotient map $\pi : G \to G/N$.** The kernel is exactly $N$: $\pi(g) = gN$ equals the identity coset $N$ iff $g \in N$. The image is all of $G/N$, since $\pi$ is surjective. This is the example proving the converse half of "normal = kernel": every normal subgroup *is* a kernel.

**Is NOT a kernel — a non-normal subgroup.** The subgroup $\langle(1\,2)\rangle \leq S_3$ is *not* the kernel of any homomorphism out of $S_3$, because it is not [[Def - Normal Subgroup|normal]] and every kernel is normal. This is a sharp non-example: it shows kernels are a strict subclass of subgroups, and the deficiency is precisely the failure of normality.

**Is NOT necessarily normal — an image.** The image need not be normal in the target. The inclusion $\langle(1\,2)\rangle \hookrightarrow S_3$ is an injective homomorphism whose image is $\langle(1\,2)\rangle$, and that image is *not* normal in $S_3$. So the asymmetry is genuine: kernels are always normal, images are merely subgroups.

**Corollary — trivial kernel detects embeddings.** A homomorphism is an embedding (injective) precisely when $\ker\varphi = \{e_G\}$. For instance any homomorphism from a [[Def - Simple Group|simple group]] $G$ is either trivial or injective: $\ker\varphi$ is a normal subgroup of $G$, hence $\{e\}$ or $G$, so $\varphi$ is either injective or constant. This dichotomy is a workhorse in simplicity arguments.

**Corollary — order constraints from kernel and image.** If $G$ is finite, $|G| = |\ker\varphi|\cdot|\operatorname{im}\varphi|$, because $|\operatorname{im}\varphi| = |G/\ker\varphi| = |G:\ker\varphi|$ by the [[Thm - First Isomorphism Theorem|first isomorphism theorem]] and [[Thm - Lagrange's Theorem|Lagrange]]. Consequently $|\operatorname{im}\varphi|$ divides both $|G|$ and $|H|$ — a divisibility obstruction that rules out many would-be homomorphisms (e.g. no non-trivial homomorphism from a group of order $7$ to one of order $10$).

**Calibration check.** Reproduce the proofs that $\ker\varphi$ is normal and $\operatorname{im}\varphi$ is a subgroup, and the proof that $\varphi$ is injective iff $\ker\varphi = \{e_G\}$. If you can also explain why $\operatorname{im}\varphi$ fails to be normal in general while $\ker\varphi$ never does, you have understood the asymmetry at the heart of this definition.

# Unlocked by This

> [!tip] First Isomorphism Theorem *(from this topic)*
> The kernel and image are exactly the two objects the [[Thm - First Isomorphism Theorem|first isomorphism theorem]] ties together: $G/\ker\varphi \cong \operatorname{im}\varphi$. Defining them is the last step before stating the master theorem of §1.2.

> [!tip] Exact Sequences and Homological Algebra *(from Module Theory and Algebraic Topology)*
> An exact sequence is a chain of homomorphisms in which each image equals the next kernel. Once kernel and image are in hand, exact sequences — and with them homology, cohomology, and the whole language of homological algebra — become available.

> [!tip] Rank–Nullity Theorem *(from Linear Algebra)*
> For a linear map, kernel and image are the null space and range, and $\dim\ker + \dim\operatorname{im} = \dim V$ is the [[Thm - First Isomorphism Theorem|first isomorphism theorem]] read through dimension.
