# Notation

This page defines two distinct but related uses of the word **order**. The **order of a group** $G$ is written $|G|$ — the same bars used for cardinality of a set. The **order of an element** $g \in G$ is written $\operatorname{ord}(g)$ (some texts write $|g|$ or $o(g)$). For an element, $g^n$ denotes the $n$-fold product, $g^0 = e$, $g^{-n} = (g^{-1})^n$; the cyclic subgroup generated by $g$ is $\langle g \rangle = \{g^k : k \in \mathbb{Z}\}$. The two notions are linked by the identity $\operatorname{ord}(g) = |\langle g \rangle|$. See [[Group Theory I — §1.1–1.2]] for the full registry.

# Axiom Motivation

The word "order" carries two meanings in group theory, and although they look unrelated at first — one counts elements of a group, the other measures a single element — the second is *defined so as to reduce to the first*. This page motivates both, and the punchline is the identity that ties them together.

**Why measure a group by its element count.** A [[Def - Group|group]] is an abstract object, and the very first question one asks of any finite structure is "how big is it". For [[Def - Group|groups]] this number is not a crude size measurement — it is astonishingly informative. A central theme of the whole subject is **how much the integer $|G|$ alone forces upon $G$**: a group of prime order is forced to be cyclic; a group of order $15$ is forced to be cyclic; the order constrains, via [[Thm - Lagrange's Theorem|Lagrange's theorem]], every [[Def - Subgroup|subgroup]] and every element. So we want a name for the element count, and "order of the group", $|G|$, is it. The only design subtlety is that for infinite [[Def - Group|groups]] $|G|$ is an infinite cardinal; most of the theory where order does heavy lifting is the **finite** theory, where $|G|$ is an honest natural number.

**Why an element should have an "order" at all.** Now fix a single element $g$. We want a numerical invariant of $g$ that captures its "rotational period" — how many times you must apply $g$ before it cycles back to doing nothing. Think of a rotation of a square by $90^\circ$: apply it four times and you are back to the identity, and four is the smallest such count. That number, $4$, is the order of the rotation. The desideratum is: $\operatorname{ord}(g)$ should be **the period of $g$**, the number of distinct elements you pass through as you take powers $g, g^2, g^3, \ldots$ before returning to $e$.

How to define it precisely? Consider the sequence of powers $e = g^0, g^1, g^2, g^3, \ldots$. Two things can happen. Either some power $g^n$ with $n > 0$ equals $e$, or none does. If some positive power equals $e$, define $\operatorname{ord}(g)$ to be the **least** such $n$. If no positive power equals $e$, declare $\operatorname{ord}(g) = \infty$.

Several design decisions are packed into that sentence; weaken or strengthen each and something breaks.

*Why "least"?* We must take the *smallest* positive $n$ with $g^n = e$, not just any. If $g^n = e$, then also $g^{2n} = e$, $g^{3n} = e$, and so on — the set of exponents killing $g$ is infinite. Only the *least* one is an invariant; it is the genuine period, and (as a corollary below) every other exponent that kills $g$ is a multiple of it. Take "some $n$" instead of "the least $n$" and "order" would not be well-defined — it would not be a function of $g$.

*Why $n > 0$ and not $n \geq 0$?* If we allowed $n = 0$, then $g^0 = e$ always, and every element would have order $0$ — a useless invariant. The exponent must be **strictly positive** for the definition to distinguish anything. Excluding $0$ is what makes the identity element, and only the identity, have order $1$: $\operatorname{ord}(g) = 1$ means $g^1 = e$, i.e. $g = e$.

*Why a separate case for infinite order?* In an infinite group a non-identity element may never return to $e$ — the element $1$ in $(\mathbb{Z}, +)$ has powers $1, 2, 3, \ldots$ (additively, "powers" are multiples) that are all distinct and never $0$. If we *insisted* every element have a finite order, we would simply have no value to assign such elements, and the definition would be incomplete. Declaring $\operatorname{ord}(g) = \infty$ in that case is the honest completion. Note that in a *finite* group infinite order is impossible — there are only finitely many elements, so the powers $g, g^2, g^3, \ldots$ must eventually repeat, and a repeat $g^i = g^j$ with $i > j$ gives $g^{i-j} = e$ with $i - j > 0$. So in a finite group every element has finite order, automatically.

**The identity that fuses the two notions.** Here is the reason the same word is used for both. Look at the cyclic [[Def - Subgroup|subgroup]] $\langle g \rangle = \{g^k : k \in \mathbb{Z}\}$ generated by $g$ — the set of all powers of $g$. If $\operatorname{ord}(g) = n$ is finite, then the powers $e, g, g^2, \ldots, g^{n-1}$ are **all distinct** (if $g^i = g^j$ with $0 \le j < i \le n-1$ then $g^{i-j} = e$ with $0 < i - j < n$, contradicting minimality of $n$), and every power $g^k$ reduces to one of these $n$ by subtracting multiples of $n$ from the exponent. So $\langle g \rangle$ has exactly $n$ elements. If $\operatorname{ord}(g) = \infty$, all powers $g^k$ are distinct and $\langle g \rangle$ is infinite. In every case:

$$\operatorname{ord}(g) = |\langle g \rangle|.$$

The order of an *element* is the order of the *group* it generates. This is not a coincidence to memorize — it is the structural reason the two definitions share a name, and it is what makes "order of an element" useful: it converts a question about one element into a question about a [[Def - Subgroup|subgroup]], where [[Thm - Lagrange's Theorem|Lagrange's theorem]] applies. The immediate dividend is that, in a finite group, $\operatorname{ord}(g) = |\langle g \rangle|$ divides $|G|$ — the source lecture notes prove exactly this as a corollary of Lagrange. So an element's period is always a divisor of the group's size; this single divisibility fact does an enormous amount of work in finite group theory.

# The Definition

Let $G$ be a [[Def - Group|group]] with identity $e$.

**Order of a group.** The **order of $G$**, written $|G|$, is the number of elements of $G$ — its cardinality as a set. If $G$ has finitely many elements it is a **finite group** and $|G|$ is a natural number; otherwise $G$ is **infinite** and $|G| = \infty$ (or the appropriate infinite cardinal).

**Order of an element.** The **order of an element** $g \in G$, written $\operatorname{ord}(g)$, is

$$\operatorname{ord}(g) := \min\{\, n \in \mathbb{Z} : n > 0 \text{ and } g^n = e \,\},$$

the least *positive* integer $n$ with $g^n = e$. If no positive power of $g$ equals $e$ — that is, if the set above is empty — then $g$ has **infinite order**, $\operatorname{ord}(g) = \infty$.

**Link between the two.** For every $g \in G$,

$$\operatorname{ord}(g) = |\langle g \rangle|,$$

where $\langle g \rangle = \{g^k : k \in \mathbb{Z}\}$ is the cyclic [[Def - Subgroup|subgroup]] generated by $g$: the order of an element equals the order of the subgroup it generates. In particular $\operatorname{ord}(g) = 1$ if and only if $g = e$.

# Relate to Other Fields / Compression

The order of an element is the group-theoretic name for a **period**, the same notion that appears as the period of a periodic function or the period of an orbit in a dynamical system. An element $g$ of finite order $n$ generates a cyclic subgroup that is an exact algebraic model of the integers modulo $n$: iterating $g$ is iterating "add $1$ mod $n$", and $n$ is the length of the cycle. From the perspective of dynamical systems, $g$ acting by left multiplication is a map of the group, and $\operatorname{ord}(g)$ is the period of the identity element under that map. In number theory the order of an element specializes to the **multiplicative order modulo $n$**: the order of $a$ in the group of units $(\mathbb{Z}/n\mathbb{Z})^\times$ is the least $k$ with $a^k \equiv 1 \pmod n$, the quantity at the heart of primitive roots, Fermat's and Euler's theorems, and the discrete logarithm problem underlying much of public-key cryptography. The order of a *group*, by contrast, is simply set cardinality wearing a group-theory label — its content is not the counting but the theorems (Lagrange, Cauchy, Sylow) that turn the count into structure.

# Examples / Corollaries

**Group order — is an instance: finite groups.** $|S_n| = n!$, $|D_{2n}| = 2n$, $|C_n| = n$, $|Q_8| = 8$, and the Klein four-group has order $4$. The order of $\mathrm{GL}_n(\mathbb{F}_q)$ over a finite field is a concrete polynomial in $q$. Each of these integers is the first invariant one records about the group.

**Group order — is NOT a finite instance: $(\mathbb{Z}, +)$, $\mathrm{GL}_n(\mathbb{R})$.** The integers under addition and the real invertible matrices are infinite groups; $|\mathbb{Z}| = \infty$. For these, $|G|$ is not a natural number, and the finite-group machinery — Lagrange's divisibility, in particular — does not directly apply. This probes the finiteness clause of the definition.

**Element order — is an instance: the identity and a rotation.** In any group $\operatorname{ord}(e) = 1$, and $e$ is the *only* element of order $1$. In the cyclic group $C_n = \{e, g, \ldots, g^{n-1}\}$ the generator has $\operatorname{ord}(g) = n$, while $\operatorname{ord}(g^2) = n/\gcd(n,2)$ — for instance in $C_6$, $\operatorname{ord}(g^2) = 3$. In $S_3$ a transposition like $(1\,2)$ has order $2$ and a $3$-cycle like $(1\,2\,3)$ has order $3$.

**Element order — is an instance: every element of $S_n$.** The order of a permutation is the **least common multiple of its cycle lengths**. The permutation $(1\,2)(3\,4\,5) \in S_5$ has order $\operatorname{lcm}(2,3) = 6$. This probes the link $\operatorname{ord}(g) = |\langle g\rangle|$ in a non-cyclic ambient group: the element still has finite order, equal to the size of the cyclic subgroup it spans.

**Element order — is NOT a finite instance: $1 \in (\mathbb{Z}, +)$.** In the additive group of integers, "powers" of $1$ are its multiples $1, 2, 3, \ldots$ (and $-1, -2, \ldots$), none of which is the identity $0$. So $\operatorname{ord}(1) = \infty$. In fact every non-zero element of $(\mathbb{Z}, +)$ has infinite order. This is the canonical example of the infinite-order case and shows why that clause of the definition is necessary — without it $\operatorname{ord}(1)$ would be undefined.

**Element order — is NOT: confusing the two orders.** It is a definitional error to think $\operatorname{ord}(g)$ and $|G|$ are the same thing. In $S_3$, $|S_3| = 6$ but no element has order $6$ — the element orders are $1$, $2$, $3$. An element of order equal to $|G|$ exists if and only if $G$ is cyclic. This non-example calibrates that the two "orders" are genuinely different invariants, merely sharing a name through the identity $\operatorname{ord}(g) = |\langle g\rangle|$.

**Corollary ($\operatorname{ord}(g) = |\langle g \rangle|$, hence Lagrange applies to elements).** Since $\langle g \rangle$ is a [[Def - Subgroup|subgroup]] of order $\operatorname{ord}(g)$, [[Thm - Lagrange's Theorem|Lagrange's theorem]] forces $\operatorname{ord}(g)$ to **divide $|G|$** whenever $G$ is finite. This is the corollary the source lecture notes prove explicitly: build $H = \{e, g, \ldots, g^{n-1}\}$, verify it is a subgroup with no repeats so $|H| = n = \operatorname{ord}(g)$, and Lagrange gives $n \mid |G|$. *Calibration check:* if you can run this argument you understand both the link identity and Lagrange.

**Corollary (which powers of $g$ are the identity).** If $\operatorname{ord}(g) = n$, then $g^k = e$ **if and only if** $n \mid k$. The set of exponents killing $g$ is exactly the subgroup $n\mathbb{Z}$ of $\mathbb{Z}$ — which is why "least" in the definition is the right choice, the least positive element being the generator of that subgroup. *Calibration check:* this is the formal reason "least" matters; any non-minimal exponent is just a multiple.

**Corollary (consequence of Lagrange for prime order).** If $|G| = p$ is prime, then every non-identity element $g$ has $\operatorname{ord}(g)$ dividing $p$ and exceeding $1$, hence $\operatorname{ord}(g) = p$, so $\langle g \rangle = G$ and **$G$ is cyclic**. This shows how the two orders interlock to produce structure: a constraint on $|G|$ becomes, through element orders, a complete description of $G$.

**Corollary (order under inverses and conjugation).** $\operatorname{ord}(g^{-1}) = \operatorname{ord}(g)$, since $(g^{-1})^n = (g^n)^{-1} = e \iff g^n = e$; and $\operatorname{ord}(hgh^{-1}) = \operatorname{ord}(g)$ for any $h$, since $(hgh^{-1})^n = hg^nh^{-1}$. So order is invariant under inversion and under conjugation — meaning order is a **conjugacy-class invariant**, a fact used constantly when analysing [[Def - Normal Subgroup|normal subgroups]] and conjugacy classes.
