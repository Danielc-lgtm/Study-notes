# Notation

$R$ is a commutative ring with $1_R$ and $M$ is an [[Def - Module|$R$-module]]. A finite list of elements is written $m_1, \ldots, m_k \in M$. The submodule they **generate** is $Rm_1 + \cdots + Rm_k = \{r_1 m_1 + \cdots + r_k m_k : r_i \in R\}$, the set of $R$-**linear combinations**; the single-element case $Rm = \{rm : r \in R\}$ is the **cyclic** submodule generated by $m$. The module $R^k = R \times \cdots \times R$ is the [[Def - Free Module|free module]] of rank $k$, with **standard generators** $e_i = (0, \ldots, 0, 1_R, 0, \ldots, 0)$ ($1_R$ in position $i$). A surjection is written $R^k \twoheadrightarrow M$. See [[Modules I — §3.1–3.2]] for the full notation registry.

# Axiom Motivation

The concept to invent is a **finiteness condition** on [[Def - Module|modules]] — the module-theoretic counterpart of "finite-dimensional" for vector spaces. The motivation is that completely arbitrary modules are unmanageably large, and almost every structural theorem needs *some* hypothesis bounding the size of the module. For vector spaces the bounding hypothesis is "has a finite basis"; finitely generated is the right generalisation, and seeing *why* it is not simply "has a finite basis" is the heart of the matter.

Start from what "small" should mean. A module is built from its elements by two operations: adding them, and scaling them by ring elements. So the natural way to say "$M$ is not too big" is: there is a *finite* list of elements $m_1, \ldots, m_k$ from which every element of $M$ can be manufactured using only addition and scaling. Manufacturing $m$ from the list means writing $m = r_1 m_1 + \cdots + r_k m_k$ for some scalars $r_i \in R$ — an $R$-**linear combination**. Demanding that *every* $m \in M$ arises this way is exactly the statement $M = Rm_1 + \cdots + Rm_k$. That is the definition, and it is forced by the principle "small = built from finitely much data".

Now here is the crucial design decision, the one separating modules from vector spaces. We require only that the $m_i$ **span** — that every element is *some* linear combination of them. We do **not** require the $m_i$ to be *linearly independent*, and we do **not** require the expression to be *unique*. A spanning list that is also independent is a **basis**, and "has a finite basis" is a *strictly stronger* condition. Why do we deliberately drop independence? Because over a general ring, demanding a basis is too much — most modules do not have one. The module $\mathbb{Z}/6\mathbb{Z}$ over $\mathbb{Z}$ is generated by the single element $\bar 1$, so it is as small as can be; but $\{\bar 1\}$ is *not* a basis, because $\bar 1$ is not linearly independent — the nonzero scalar $6$ satisfies $6 \cdot \bar 1 = \bar 0$, an [[Def - Annihilator|annihilation]] relation. If "finitely generated" meant "finite basis", then $\mathbb{Z}/6\mathbb{Z}$ — a six-element module! — would fail to be finite-type, which is absurd. The lesson: over a ring, torsion makes independence impossible for many small modules, so the workable finiteness condition must ask only for *spanning*. Modules with a finite basis get their own name, [[Def - Free Module|free of finite rank]]; finitely generated is the larger, more robust class.

What breaks if we *weaken* the condition instead — say, drop "finite" and allow an infinite generating list? Then *every* module qualifies (it is generated by all of its elements), and the condition is vacuous. Finiteness of the list is exactly the content. And what breaks if we *strengthen* to "finite basis"? As just seen, $\mathbb{Z}/6\mathbb{Z}$, every nonzero finite abelian group, and every nontrivial cyclic module $R/I$ get wrongly excluded. So "finite spanning set, independence not required" is the unique sweet spot.

There is a second, equivalent formulation, and it is the one that actually does the work in proofs. To say $m_1, \ldots, m_k$ generate $M$ is to give a recipe taking a tuple of scalars $(r_1, \ldots, r_k)$ to the element $r_1 m_1 + \cdots + r_k m_k$. That recipe is a map $R^k \to M$, and it is a [[Def - Module Homomorphism|module homomorphism]] — it respects addition and scaling because linear combinations do. Saying the $m_i$ generate *all* of $M$ is saying this map is **surjective**. So: **$M$ is finitely generated if and only if there is a surjective module homomorphism $R^k \twoheadrightarrow M$ from some finite [[Def - Free Module|free module]].** This is not a different concept, just a different costume — but it is the useful costume, because it expresses "finitely generated" without naming the generators, turning a statement about elements into a statement about a map. With it, facts like "a quotient of a finitely generated module is finitely generated" become one-line diagram chases (compose the surjection $R^k \twoheadrightarrow M$ with the quotient map $M \twoheadrightarrow M/N$ — a composite of surjections is a surjection). The element-level definition tells you *what* finite generation means; the surjection characterisation tells you how to *use* it.

One warning the definition should make you anticipate, because it is the sharpest contrast with linear algebra: finite generation is **not inherited by submodules**. A subspace of a finite-dimensional vector space is finite-dimensional; but a submodule of a finitely generated module need *not* be finitely generated. The standard witness is $R = \mathbb{C}[X_1, X_2, \ldots]$ in countably many variables, with $M = R$ — finitely generated, by $1$ — containing the [[Def - Ideal|ideal]] $I = (X_1, X_2, \ldots)$, a submodule that needs infinitely many generators. So "finitely generated" is a real, non-trivial hypothesis: it does not propagate downward for free, and the rings where it *does* propagate (the Noetherian rings) are singled out precisely because that propagation is so useful.

# The Definition

Let $M$ be an [[Def - Module|$R$-module]].

**Primary definition (finite generating set).** $M$ is **finitely generated** if there is a *finite* list of elements $m_1, \ldots, m_k \in M$ with
$$M = Rm_1 + Rm_2 + \cdots + Rm_k = \{r_1 m_1 + r_2 m_2 + \cdots + r_k m_k : r_1, \ldots, r_k \in R\}.$$
The list $m_1, \ldots, m_k$ is then a **generating set** for $M$, and every element of $M$ is an $R$-**linear combination** of it. The generators are **not** required to be linearly independent and the linear combination is **not** required to be unique.

**Equivalent characterisation (surjection from a free module).** $M$ is finitely generated if and only if there exists a surjective [[Def - Module Homomorphism|$R$-module homomorphism]]
$$f : R^k \twoheadrightarrow M$$
for some finite $k \geq 0$. The two formulations correspond as follows. Given generators $m_1, \ldots, m_k$, define $f(r_1, \ldots, r_k) = r_1 m_1 + \cdots + r_k m_k$; this is a module homomorphism, and surjective exactly because the $m_i$ generate. Conversely, given a surjection $f : R^k \twoheadrightarrow M$, set $m_i = f(e_i)$ where $e_i$ is the $i$-th standard generator of $R^k$; then $m_1, \ldots, m_k$ generate $M$, since for any $m = f(r_1, \ldots, r_k)$ one has $f(r_1, \ldots, r_k) = \sum_i r_i f(e_i) = \sum_i r_i m_i$. (See [[Thm - Finitely Generated Modules and Surjections from a Free Module]] for the proof.)

A module generated by a *single* element, $M = Rm$, is called **cyclic**. The least size $k$ of a generating set is the **minimal number of generators**; there is no reason it should be unique-expression data, and over a general ring it is not an isomorphism invariant in the way dimension is for vector spaces.

# Categorical Definition

The surjection characterisation is the categorical face of the definition. In the category $R\text{-}\mathbf{Mod}$, the [[Def - Free Module|free modules]] $R^k$ ($k$ finite) are distinguished objects: a homomorphism out of $R^k$ is the same as a free choice of $k$ elements of the target (the images of the standard generators). To say $M$ is finitely generated is to say $M$ is a **quotient object** of some finite free module — there is an epimorphism $R^k \twoheadrightarrow M$. Composing with the inclusion of $\ker f$, one obtains a presentation: $M \cong R^k/\ker f$, exhibiting $M$ as a finite free module modulo a submodule of relations. When that submodule of relations is *itself* finitely generated, $M$ is **finitely presented**, $R^a \to R^b \to M \to 0$ — see [[Def - Finitely Presented Module]]. The finiteness condition thus has a clean diagrammatic statement: $M$ receives an epimorphism from a finitely generated free object.

# Relate to Other Fields / Compression

Finitely generated is **"finite-dimensional" with the independence requirement deleted**. For a vector space over a [[Def - Unit and Field|field]], finitely generated *is* finite-dimensional: a finite spanning set can always be thinned to a basis, because over a field independence is achievable. Over a general [[Def - Ring|ring]] the thinning fails — torsion blocks it — so finite generation is the strictly weaker, strictly more useful condition, and it is the one that survives the move from fields to rings. Reading the gap between "finitely generated" and "finite free": that gap is exactly torsion plus the failure of bases.

It is the [[Def - Module|module]] instance of a finiteness condition appearing across algebra. For rings: a ring is *of finite type* over a subring when finitely many elements generate it. For [[Def - Ideal|ideals]]: an ideal is finitely generated when finitely many elements generate it as an ideal — and a ring all of whose ideals are finitely generated is **Noetherian**. For [[Def - Abelian Group|abelian groups]]: a finitely generated $\mathbb{Z}$-module is a finitely generated abelian group, the objects classified by the structure theorem as $\mathbb{Z}^r \oplus \mathbb{Z}/d_1 \oplus \cdots \oplus \mathbb{Z}/d_s$. In each setting the move is the same — bound the object by finitely much generating data — and module theory is the common frame.

Via the surjection characterisation it is also literally a statement about **quotients**: $M$ is finitely generated exactly when $M \cong R^k/K$ for some submodule $K$. So "finitely generated module" and "[[Def - Quotient Module|quotient]] of a finite [[Def - Free Module|free module]]" are the same class of objects under two descriptions.

# Examples / Corollaries

**Is an instance: $R^n$.** The [[Def - Free Module|free module]] $R^n$ is finitely generated, by the $n$ standard generators $e_1, \ldots, e_n$: every $(r_1, \ldots, r_n) = \sum_i r_i e_i$. The identity map $R^n \twoheadrightarrow R^n$ is the witnessing surjection. Here the generators happen to be independent — $R^n$ is finitely generated *and* free — but that is a bonus, not part of the finite-generation requirement.

**Is an instance: any cyclic module $Rm$, and $Rm \cong R/\operatorname{Ann}(m)$.** A module generated by one element, $M = Rm$, is finitely generated with $k = 1$; the surjection is $\varphi_m : R \to M$, $r \mapsto rm$. By the [[Thm - Isomorphism Theorems for Modules|first isomorphism theorem]] applied to $\varphi_m$, whose kernel is the [[Def - Annihilator|annihilator]] $\operatorname{Ann}(m)$, every cyclic module is a quotient of the ring: $Rm \cong R/\operatorname{Ann}(m)$. For example $\mathbb{Z}/6\mathbb{Z}$ is cyclic over $\mathbb{Z}$, generated by $\bar 1$, with $\operatorname{Ann}(\bar 1) = (6)$ — finitely generated but, note, *not* free, since $\{\bar 1\}$ is not independent.

**Is an instance: any finite abelian group, as a $\mathbb{Z}$-module.** A finite abelian group $A$ has finitely many elements, and the (finite) list of all of them generates $A$. So every finite abelian group is a finitely generated $\mathbb{Z}$-module. More efficiently, the structure theorem writes $A$ as a direct sum of finitely many cyclic groups, exhibiting a small generating set. None of these (if $A \neq 0$) is free over $\mathbb{Z}$.

**Is an instance: a quotient of a finitely generated module.** If $M$ is finitely generated and $N \leq M$ is any [[Def - Submodule|submodule]], the [[Def - Quotient Module|quotient]] $M/N$ is finitely generated — see the corollary below. So finitely generated modules are closed under passing to quotients (and, separately, under finite direct sums and homomorphic images).

**Is NOT an instance: $\mathbb{Q}$ as a $\mathbb{Z}$-module.** The additive group $\mathbb{Q}$ is **not** finitely generated over $\mathbb{Z}$. Suppose it were, generated by $\tfrac{a_1}{b_1}, \ldots, \tfrac{a_k}{b_k}$ in lowest terms. Every $\mathbb{Z}$-linear combination $\sum n_i \tfrac{a_i}{b_i}$ has denominator dividing $b := b_1 b_2 \cdots b_k$. But $\tfrac{1}{2b} \in \mathbb{Q}$ has denominator $2b$, which does not divide $b$, so $\tfrac{1}{2b}$ is not a $\mathbb{Z}$-linear combination of the generators — contradiction. The intuition: $\mathbb{Q}$ needs *unboundedly* fine denominators, so no finite list of fractions can reach all of it. This non-example shows finite generation genuinely excludes things; $\mathbb{Q}$ is "infinite-dimensional" as a $\mathbb{Z}$-module.

**Is NOT an instance: a submodule of a finitely generated module.** Finite generation does **not** pass to submodules. Let $R = \mathbb{C}[X_1, X_2, X_3, \ldots]$, the polynomial ring in countably many variables, and let $M = R$ as a module over itself — finitely generated, indeed cyclic, by $1$. The [[Def - Ideal|ideal]] $I = (X_1, X_2, X_3, \ldots)$ is a submodule of $M$ (submodules of $R$ are ideals). It is **not** finitely generated: any finite subset of $I$ involves only finitely many of the variables, say $X_1, \ldots, X_n$, and the elements they generate cannot produce $X_{n+1}$. So $M$ is finitely generated while its submodule $I$ is not — the decisive contrast with subspaces of finite-dimensional vector spaces, and the reason Noetherian rings are singled out.

**Corollary (quotients stay finitely generated).** If $M$ is finitely generated and $N \leq M$, then $M/N$ is finitely generated. *Calibration check:* take a surjection $f : R^k \twoheadrightarrow M$ and compose with the quotient map $q : M \twoheadrightarrow M/N$; the composite $q \circ f : R^k \twoheadrightarrow M/N$ is a surjection of modules (a composite of surjections), so $M/N$ is finitely generated. Equivalently, the images $m_i + N$ of generators of $M$ generate $M/N$.

**Corollary (homomorphic images stay finitely generated).** If $M$ is finitely generated and $g : M \to P$ is any [[Def - Module Homomorphism|module homomorphism]], then $\operatorname{im} g$ is finitely generated. *Calibration check:* if $m_1, \ldots, m_k$ generate $M$, then for any $g(m) = g(\sum r_i m_i) = \sum r_i g(m_i)$, so $g(m_1), \ldots, g(m_k)$ generate $\operatorname{im} g$. (The previous corollary is the special case $P = M/N$, $g = q$.)

**Corollary (finite direct sums stay finitely generated).** If $M$ and $M'$ are finitely generated, so is $M \oplus M'$. *Calibration check:* if $m_1, \ldots, m_k$ generate $M$ and $m_1', \ldots, m_\ell'$ generate $M'$, then the elements $(m_i, 0)$ and $(0, m_j')$ — a list of length $k + \ell$ — generate $M \oplus M'$, since $(m, m') = \sum r_i(m_i,0) + \sum s_j(0, m_j')$. So finitely generated modules form a class closed under $\oplus$ and quotients, though *not* under submodules.

# Unlocked by This

> [!tip] Surjections from a free module *(from this chapter)*
> The equivalence "finitely generated $\iff$ image of a surjection $R^k \twoheadrightarrow M$" is itself a named result, [[Thm - Finitely Generated Modules and Surjections from a Free Module]] — the bridge from the concrete element-level definition to the proof-friendly mapping description.

> [!tip] Finitely presented modules *(from Commutative Algebra)*
> Writing $M \cong R^k/K$ via a surjection from a free module, one may ask that the relations submodule $K$ also be finitely generated; then $M$ is [[Def - Finitely Presented Module|finitely presented]], described by a finite exact sequence $R^a \to R^b \to M \to 0$. Over a Noetherian ring, finitely generated and finitely presented coincide.

> [!tip] Structure theorem for finitely generated modules over a PID *(from Commutative Algebra)*
> When $R$ is a principal ideal domain, every finitely generated $R$-module is a direct sum of cyclic modules $R^r \oplus R/(d_1) \oplus \cdots \oplus R/(d_s)$. This single theorem yields the classification of finitely generated abelian groups and the Jordan / rational canonical forms for a linear operator — it is the central goal of the modules course, and finite generation is its standing hypothesis.
