# Problem Statement

Construct a finitely generated module possessing a submodule that is **not** finitely generated. Concretely:

Let $R=\mathbb{C}[X_1,X_2,X_3,\dots]$ be the polynomial ring in **countably many** indeterminates over $\mathbb{C}$ — each element is a $\mathbb{C}$-linear combination of finitely many monomials, so any given polynomial involves only finitely many of the variables, but the supply of variables is infinite. Regard $R$ as a module over itself.

1. Show that $M=R$, as an $R$-module, is **finitely generated** — indeed generated by the *single* element $1$.

2. Let $I=(X_1,X_2,X_3,\dots)\trianglelefteq R$ be the ideal generated by all the indeterminates. Observe that $I$, being an ideal, is an $R$-**submodule** of $M=R$. Prove that $I$ is **not finitely generated** as an $R$-module.

Conclude: "finitely generated" is **not inherited by submodules** — in pointed contrast to vector spaces, where every subspace of a finite-dimensional space is finite-dimensional.

**Recall:**

The objects in play are the polynomial ring in infinitely many variables, the module $R$ over itself, an ideal of $R$, and the notion of a finitely generated module.

![[Def - Finitely Generated Module#The Definition]]

An $R$-module $M$ is **finitely generated** if there is a finite list $m_1,\dots,m_k\in M$ with $M=Rm_1+\cdots+Rm_k=\{r_1m_1+\cdots+r_km_k:r_i\in R\}$ — every element is an $R$-linear combination of the $m_i$. To prove a module is *not* finitely generated, one must show that *no* finite list generates it.

![[Def - Submodule#The Definition]]

When the module is $R$ itself (scalars acting by ring multiplication), a subset is an $R$-submodule if and only if it is an [[Def - Ideal|ideal]] of $R$: the submodule axioms (additive subgroup, closed under scalar multiplication) are exactly the ideal axioms.

![[Def - Polynomial Ring#The Definition]]

The ring $R=\mathbb{C}[X_1,X_2,\dots]$ consists of all polynomials in the variables $X_1,X_2,\dots$ with complex coefficients. A single polynomial is a finite sum of monomials, hence mentions only finitely many variables; but the variable set is infinite. There is a useful **total-degree** grading: write $f=\sum_d f_d$ where $f_d$ is the sum of the degree-$d$ monomials of $f$ (the *degree-$d$ homogeneous component*); $f_0$ is the constant term. Multiplication respects degree: a degree-$d$ homogeneous polynomial times a degree-$e$ homogeneous polynomial is degree-$d+e$ homogeneous.

For elements $a_1,\dots,a_k$ (or infinitely many) of a ring, the ideal they **generate** is the set of all finite $R$-linear combinations $\sum r_i a_i$. So $I=(X_1,X_2,\dots)=\{\,\text{finite sums }\sum r_i X_i:r_i\in R\,\}$ — concretely, $I$ is exactly the set of polynomials with **zero constant term**.

# Convergent Strategy

**Problem class.** This is a *prove a negative — exhibit a counterexample to a plausible inheritance principle* problem. As the [[Modules I — §3.1–3.2#Problem-Solving Strategy|topic page's strategy]] records, to refute "property $P$ passes to submodules" one designs a *single, finitely generated $M$* together with a submodule $N$ for which "$N$ finitely generated" can be *disproved*; and disproving "$N$ is finitely generated" is itself a negative statement, attacked by *assuming a finite generating set exists and deriving a contradiction*.

**Assumption pattern.** Two design hypotheses do the work. First, $M=R$ is generated by $1$ — automatic for *any* ring, since $r=r\cdot 1$; this gives the "finitely generated" half for free. Second, the ambient ring is chosen *infinitely generated*: $R=\mathbb{C}[X_1,X_2,\dots]$ has the ideal $I=(X_1,X_2,\dots)$ which "obviously" needs infinitely many generators. The pattern is "a tiny (cyclic, even) module containing a submodule built from infinitely many independent pieces" — the contrast between a *single* generator upstairs and *infinitely many independent* elements downstairs is the whole engine.

**Theorem routing.** Part 1 is one line: $1$ generates $R$. Part 2 is the substance and routes through a **degree argument**. Suppose $I$ were generated by finitely many polynomials $f_1,\dots,f_k$. Each $f_j$ mentions only finitely many variables, so *together* they mention only finitely many — say none beyond $X_N$. Pick an unused variable, $X_{N+1}\in I$. Express it as $X_{N+1}=\sum_j r_jf_j$ and extract the **degree-$1$ homogeneous component** of both sides: on the left, $X_{N+1}$ itself; on the right, a $\mathbb{C}$-linear combination of the degree-$1$ parts of the $f_j$ — which involve only $X_1,\dots,X_N$. A degree-$1$ polynomial in $X_1,\dots,X_N$ cannot equal $X_{N+1}$. Contradiction.

**Key decision point.** Two non-obvious moves elevate this to ⭐⭐⭐. First, the choice of ring: a *finite*-variable polynomial ring will not work — $\mathbb{C}[X_1,\dots,X_n]$ is Noetherian, so *every* ideal there is finitely generated; the counterexample genuinely *requires* infinitely many variables, and recognising this is the crux of the construction. Second, the proof that $I$ is not finitely generated is not a counting argument ("infinitely many generators") — that is a *non sequitur*, since a set can have an infinite generating set yet also a finite one. The correct argument *isolates* a single witness $X_{N+1}$ that no finite set reaching only up to $X_N$ can produce, and the *degree-1 component projection* is the device that makes "reaching only up to $X_N$" into a rigorous obstruction.

# Legal Operations Used

This solution deploys the following legal operations from [[Modules I — §3.1–3.2#Legal Operations|the topic page's Legal Operations]]:

1. **Generate a module by an element via the unital axiom.** Since $1_R\cdot r=r$ for every $r$ (module axiom (d)), the single element $1$ generates $R$ as a module over itself — the operation that establishes finite generation for free.

2. **Identify submodules of $R$ with ideals.** A subset of the module $R$ is a submodule iff it is an ideal; this lets the ideal $I=(X_1,X_2,\dots)$ be deployed as a *submodule* counterexample.

3. **Assume a finite generating set and derive a contradiction.** To disprove "$I$ is finitely generated," posit generators $f_1,\dots,f_k$ — the standard proof-by-contradiction opening for a negative statement.

4. **Bound the variables appearing in a finite set of polynomials.** Each polynomial mentions finitely many variables; a finite set mentions finitely many in total — the operation that produces an "unused" variable $X_{N+1}$.

5. **Project onto a homogeneous degree component.** Extracting the degree-$1$ part of an identity $X_{N+1}=\sum r_jf_j$ is a $\mathbb{C}$-linear operation that respects products by degree-tracking; it converts the identity into a constraint among degree-$1$ polynomials, where the contradiction becomes visible.

6. **Compare which variables can occur on each side of an equation.** The final blow: the right side's degree-$1$ part lives in $\operatorname{span}_{\mathbb{C}}(X_1,\dots,X_N)$ while the left side is $X_{N+1}$ — and $X_{N+1}$ is not in that span.

# Hints

> [!note]- Hint 1
> Part 1 is immediate: in *any* ring $R$, every element $r$ satisfies $r=r\cdot 1$, so the single element $1$ generates $R$ as an $R$-module. The whole interest is Part 2 — showing the submodule $I=(X_1,X_2,\dots)$ resists *every* finite generating set. This is a negative statement: assume a finite generating set exists, and break it.

> [!note]- Hint 2
> Why must the ring have *infinitely* many variables? Suppose $I$ were generated by finitely many polynomials $f_1,\dots,f_k$. Each $f_j$ is a finite sum of monomials, so it mentions only finitely many variables. How many variables, in total, do *all* the $f_j$ together mention? Finitely many. So there is a variable they never mention — call it $X_{N+1}$.

> [!note]- Hint 3
> The variable $X_{N+1}$ has zero constant term, so $X_{N+1}\in I$. If $f_1,\dots,f_k$ generate $I$, then $X_{N+1}=\sum_{j=1}^k r_jf_j$ for some $r_j\in R$. You want a contradiction from the fact that the $f_j$ only involve $X_1,\dots,X_N$. The right tool: look at the part of each side that is **homogeneous of degree $1$** — the sum of its degree-one monomials.

> [!note]- Hint 4
> Take the degree-$1$ homogeneous component of $X_{N+1}=\sum_j r_jf_j$. The left side *is* degree-$1$, so its degree-$1$ part is $X_{N+1}$ itself. On the right, the degree-$1$ part of $r_jf_j$ is (constant term of $r_j$)$\times$(degree-$1$ part of $f_j$) — higher-degree pieces of $r_j$ raise the degree past $1$. So the right side's degree-$1$ part is a $\mathbb{C}$-linear combination of the degree-$1$ parts of $f_1,\dots,f_k$, each of which only involves $X_1,\dots,X_N$. Conclusion: $X_{N+1}$ would be a $\mathbb{C}$-linear combination of $X_1,\dots,X_N$ — impossible, since the variables are linearly independent over $\mathbb{C}$.

# Solution

The strategy is: $M=R$ is generated by $1$, hence finitely generated, for free; and the submodule $I=(X_1,X_2,\dots)$ is shown not finitely generated by a degree argument — any finite generating set involves only finitely many variables, so it cannot produce a variable beyond that range, which the degree-$1$ projection makes rigorous.

**Step 1: $M=R$ is generated as an $R$-module by the single element $1$.**

The module $R$ over itself is cyclic, hence finitely generated.

> [!note]- Derivation
> $R$ is an $R$-module with scalars acting by ring multiplication. For any $r\in R$, module axiom (d) (the unital axiom) gives $r=1_R\cdot r=r\cdot 1$ (commutativity). Hence every element of $R$ is a scalar multiple of $1$:
> $$R=\{r\cdot 1:r\in R\}=R\cdot 1.$$
> So $R$ is generated by the single element $1$ — it is a [[Def - Finitely Generated Module|finitely generated]] (indeed cyclic) $R$-module. This holds for *every* ring; nothing special about $\mathbb{C}[X_1,X_2,\dots]$ is used here.

**Step 2: $I=(X_1,X_2,\dots)$ is an $R$-submodule of $M=R$, equal to the polynomials with zero constant term.**

The ideal $I$ is a submodule, and it consists exactly of the polynomials whose constant term is $0$.

> [!note]- Derivation
> *Submodule.* A subset $N\subseteq R$ is an $R$-[[Def - Submodule|submodule]] of the module $R$ iff $N$ is an additive subgroup closed under multiplication by every element of $R$ — and those are precisely the defining conditions of an [[Def - Ideal|ideal]]. The set $I=(X_1,X_2,\dots)$ is an ideal by construction, so it is an $R$-submodule of $M=R$.
>
> *Description.* By definition, $I$ is the set of finite $R$-linear combinations $\sum_i r_iX_i$. Every such combination has constant term $0$, since each $X_i$ does and constant terms add and multiply. Conversely, if $f\in R$ has zero constant term, then every monomial of $f$ has positive degree, hence is divisible by some variable; collecting monomials by a variable each is divisible by writes $f=\sum_i r_iX_i$ (a finite sum). So
> $$I=\{f\in R:\text{constant term of }f\text{ is }0\}.$$
> In particular each individual variable $X_{i}$ lies in $I$.

**Step 3: Assume $I$ is finitely generated; the generators involve only finitely many variables.**

Suppose $I=(f_1,\dots,f_k)$ for finitely many $f_j\in R$. Then there is an $N$ such that no $f_j$ mentions any variable beyond $X_N$.

> [!note]- Derivation
> Suppose, for contradiction, that $I$ is finitely generated as an $R$-module: there exist $f_1,\dots,f_k\in I$ with $I=Rf_1+\cdots+Rf_k$.
>
> Each $f_j$ is a polynomial — a *finite* $\mathbb{C}$-linear combination of monomials. A single monomial involves finitely many variables, so $f_j$ involves finitely many variables; denote by $V_j$ the (finite) set of indices $i$ such that $X_i$ appears in $f_j$. The union $V_1\cup\cdots\cup V_k$ is a finite union of finite sets, hence finite. Let $N$ be an integer exceeding every index in this union. Then **none of $f_1,\dots,f_k$ mentions any variable $X_i$ with $i>N$** — collectively, the generators "see" only $X_1,\dots,X_N$.

**Step 4: The unused variable $X_{N+1}$ lies in $I$ but cannot be an $R$-combination of the $f_j$.**

The variable $X_{N+1}\in I$, yet writing $X_{N+1}=\sum_j r_jf_j$ and projecting to degree $1$ yields a contradiction.

> [!note]- Derivation
> The variable $X_{N+1}$ has zero constant term, so by Step 2, $X_{N+1}\in I$. Since $f_1,\dots,f_k$ generate $I$, there exist scalars $r_1,\dots,r_k\in R$ with
> $$X_{N+1}=\sum_{j=1}^{k}r_jf_j.\tag{$\ast$}$$
> We now apply the **degree-$1$ homogeneous projection** $\pi_1$: for a polynomial $g$, $\pi_1(g)$ is the sum of its degree-$1$ monomials. This map is $\mathbb{C}$-linear, and it interacts with products by degree tracking — for the constant-and-higher decomposition $r_j=c_j+r_j'$ (with $c_j\in\mathbb{C}$ the constant term and $r_j'$ the sum of the positive-degree part) and $f_j=\ell_j+f_j''$ (with $\ell_j=\pi_1(f_j)$ the degree-$1$ part and $f_j''$ the degree-$\geq 2$ part — note $f_j$ has *no* constant term, as $f_j\in I$), the product is
> $$r_jf_j=(c_j+r_j')(\ell_j+f_j'')=c_j\ell_j+\big(c_jf_j''+r_j'\ell_j+r_j'f_j''\big),$$
> and every term in the bracket has total degree $\geq 2$. Hence $\pi_1(r_jf_j)=c_j\ell_j$.
>
> Apply $\pi_1$ to both sides of $(\ast)$. The left side $X_{N+1}$ is already homogeneous of degree $1$, so $\pi_1(X_{N+1})=X_{N+1}$. The right side gives, by $\mathbb{C}$-linearity,
> $$X_{N+1}=\pi_1\Big(\sum_jr_jf_j\Big)=\sum_j\pi_1(r_jf_j)=\sum_{j=1}^kc_j\,\ell_j,$$
> a $\mathbb{C}$-linear combination of $\ell_1,\dots,\ell_k$, where $\ell_j=\pi_1(f_j)$.
>
> But each $\ell_j$ is the degree-$1$ part of $f_j$, and by Step 3 the polynomial $f_j$ mentions only the variables $X_1,\dots,X_N$ — so $\ell_j\in\operatorname{span}_{\mathbb{C}}(X_1,\dots,X_N)$. Therefore $\sum_jc_j\ell_j\in\operatorname{span}_{\mathbb{C}}(X_1,\dots,X_N)$ as well. The equation says
> $$X_{N+1}\in\operatorname{span}_{\mathbb{C}}(X_1,\dots,X_N).$$
> This is false: the distinct indeterminates $X_1,X_2,\dots$ are linearly independent over $\mathbb{C}$ (a non-trivial $\mathbb{C}$-linear relation among distinct degree-$1$ monomials cannot vanish — distinct monomials are a $\mathbb{C}$-basis of the polynomial ring). Contradiction.

**Step 5: Conclude — $I$ is not finitely generated, so finite generation does not pass to submodules.**

The contradiction refutes the assumption; hence $I$ has no finite generating set.

> [!note]- Derivation
> Step 4 derived a contradiction from the sole assumption that $I$ is generated by finitely many elements $f_1,\dots,f_k$. Therefore that assumption is false:
> $$I=(X_1,X_2,X_3,\dots)\text{ is not a finitely generated }R\text{-module.}$$
> Yet $I$ is a submodule of $M=R$, and $M$ *is* finitely generated — generated by the single element $1$ (Step 1). So we have exhibited a finitely generated module with a submodule that is not finitely generated. The property "finitely generated" is therefore **not inherited by submodules**. $\blacksquare$

> [!note]- Derivation — the contrast with vector spaces, and why finite-variable rings fail
> Two remarks complete the picture.
>
> *Why vector spaces behave differently.* If $V$ is a vector space of finite dimension $n$ over a field $F$ and $W\subseteq V$ is a subspace, then $W$ is finite-dimensional with $\dim W\leq n$ — every subspace of a finitely generated $F$-module is finitely generated. The reason is that $F$ is a field, and over a field every module is *free* with a well-defined dimension, and a submodule of a finite-dimensional free module is again free of no greater dimension. The phenomenon in this exercise is impossible over a field precisely because $\mathbb{C}[X_1,X_2,\dots]$ is *not* a field — it has a rich ideal structure, and ideals are the submodules of $R$ that need not be finitely generated.
>
> *Why infinitely many variables are essential.* The counterexample genuinely requires the infinite variable set. Over $\mathbb{C}[X_1,\dots,X_n]$ with *finitely* many variables, the **Hilbert Basis Theorem** asserts that the ring is *Noetherian*: every ideal is finitely generated. So in any finite-variable polynomial ring, *every* submodule of $R$ is finitely generated, and no counterexample of this kind exists. Step 3's argument — "the finite generating set sees only finitely many variables" — has no bite when there are only finitely many variables to begin with. The leap from $n$ variables to countably many is exactly the leap from Noetherian to non-Noetherian, and it is non-Noetherianness that this exercise exhibits.

> [!note]- Complete formal solution
> **Claim.** $M=\mathbb{C}[X_1,X_2,\dots]$ is a finitely generated module over itself, but its submodule $I=(X_1,X_2,\dots)$ is not finitely generated.
>
> *$M$ is finitely generated.* For every $r\in R=M$, $r=r\cdot 1$, so $M=R\cdot 1$ is generated by the single element $1$.
>
> *$I$ is a submodule.* Submodules of the module $R$ are exactly the ideals of $R$; $I$ is an ideal, hence a submodule. Moreover $I$ is exactly the set of polynomials with zero constant term.
>
> *$I$ is not finitely generated.* Suppose $I=Rf_1+\cdots+Rf_k$. Each $f_j$ involves finitely many variables, so all of $f_1,\dots,f_k$ together involve only $X_1,\dots,X_N$ for some $N$. Now $X_{N+1}\in I$ (zero constant term), so $X_{N+1}=\sum_{j=1}^kr_jf_j$ for some $r_j\in R$. Apply the degree-$1$ projection $\pi_1$. Since each $f_j\in I$ has no constant term, $\pi_1(r_jf_j)=c_j\,\pi_1(f_j)$ where $c_j$ is the constant term of $r_j$ (all other contributions have degree $\geq 2$). Hence $X_{N+1}=\pi_1(X_{N+1})=\sum_jc_j\,\pi_1(f_j)$. Each $\pi_1(f_j)$ is a $\mathbb{C}$-linear combination of $X_1,\dots,X_N$, so $X_{N+1}\in\operatorname{span}_{\mathbb{C}}(X_1,\dots,X_N)$ — contradicting the linear independence over $\mathbb{C}$ of the distinct indeterminates. Hence no finite generating set exists.
>
> Thus $I$ is a non-finitely-generated submodule of the finitely generated module $M$. $\blacksquare$

# Key Takeaways

**Finite generation is a one-directional property: it passes to quotients but not to submodules.** This exercise should be filed alongside its positive companion: if $M$ is finitely generated and $N\leq M$, then the *quotient* $M/N$ is always finitely generated — the images of generators of $M$ generate $M/N$ (compose a surjection $R^k\twoheadrightarrow M$ with the quotient map $M\twoheadrightarrow M/N$, using [[Thm - Finitely Generated Modules and Surjections from a Free Module|the surjection-from-a-free-module characterisation]]). But the *submodule* $N$ can fail to be finitely generated, as shown here. The asymmetry is fundamental and worth memorising as a pair: *quotients of finitely generated modules are finitely generated; submodules need not be.* The conceptual reason is that a surjection's image is controlled by the domain's generators, whereas a sub-object can have structure invisible from any generating set of the whole. The modules for which submodules *also* inherit finite generation form a distinguished, named class — the *Noetherian* modules — and the entire point of the Noetherian condition is to restore the inheritance that this exercise shows can fail.

**To prove "no finite generating set exists," do not count — isolate a witness no finite set can reach.** The seductive wrong argument is "$I$ needs infinitely many generators $X_1,X_2,\dots$, therefore it is not finitely generated." This is a *non sequitur*: having one infinite generating set says nothing — $\mathbb{Z}$ is generated by $\{2,3,5,7,\dots\}$ yet also by $\{1\}$. The correct schema for "not finitely generated" is: assume a finite generating set $f_1,\dots,f_k$; extract a *finiteness consequence* of having only $k$ generators (here: collectively they mention only finitely many variables); then *exhibit a specific element of the module* that this consequence forbids them from producing (here: an unused variable $X_{N+1}$). The witness $X_{N+1}$ is chosen *after* and *because of* the bound $N$ — this order is essential. The same "assume finite, derive a bound, build a witness beyond the bound" pattern proves that infinite-dimensional vector spaces have no finite spanning set, that $\mathbb{Q}$ is not finitely generated as a $\mathbb{Z}$-module, and that the ideal of polynomials vanishing on an infinite set can fail to be finitely generated.

**The homogeneous-degree projection turns a polynomial identity into a finite-dimensional linear-algebra constraint.** The decisive technical device is $\pi_1$, the projection onto the degree-$1$ component. A polynomial ring is *graded* — it decomposes as a direct sum $R=\bigoplus_{d\geq 0}R_d$ of homogeneous pieces, and crucially multiplication is *degree-additive*, $R_d\cdot R_e\subseteq R_{d+e}$. Projecting an identity onto a single graded piece is legitimate (each $R_d$ is a $\mathbb{C}$-subspace and the projections are $\mathbb{C}$-linear) and *strips away* all the higher-degree noise, collapsing a complicated polynomial equation into a clean equation inside one finite-dimensional graded component — here, the degree-$1$ space $\operatorname{span}_{\mathbb{C}}(X_1,X_2,\dots)$, where the question becomes plain linear independence of monomials. This "project onto a graded component to linearise" technique is pervasive wherever a graded ring or module appears: it is how one computes in cohomology rings, how one proves facts about symmetric polynomials degree by degree, and how Hilbert-series arguments work. The trigger is any identity in a graded ring; the reaction is "project onto a single degree and read off a linear constraint."

**The example marks the precise boundary between Noetherian and non-Noetherian — and that boundary is crossed by adjoining infinitely many variables.** It is worth being exact about *why* the counterexample needs countably many variables. Over $\mathbb{C}[X_1,\dots,X_n]$ — finitely many variables — the **Hilbert Basis Theorem** guarantees every ideal is finitely generated; the ring is *Noetherian*, and no submodule-of-$R$ counterexample can exist. The phenomenon appears *only* in the infinite-variable ring $\mathbb{C}[X_1,X_2,\dots]$, which is the standard first example of a *non-Noetherian* ring. So this exercise is not merely "a counterexample"; it is *the* counterexample that motivates the Noetherian hypothesis. Whenever a theorem in commutative algebra or algebraic geometry carries the assumption "$R$ Noetherian" or "$M$ a finitely generated module over a Noetherian ring," this exercise is the pathology being excluded — the Noetherian condition is precisely the axiom that buys back "submodules of finitely generated modules are finitely generated," restoring the comfortable behaviour of finite-dimensional vector spaces in a setting where it would otherwise fail.
