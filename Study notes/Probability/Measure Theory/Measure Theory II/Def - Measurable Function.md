# Notation

$(X,\mathcal{A})$ and $(Y,\mathcal{A}')$ are [[Def - Measurable Space|measurable spaces]]. For $f:X\to Y$ and $S\subseteq Y$, $f^{-1}(S)=\{x\in X:f(x)\in S\}$. When $Y=\mathbb{R}$ or $[-\infty,\infty]$ we use the [[Def - Borel σ-Algebra|Borel $\sigma$-algebra]].

---

# Axiom Motivation

A measurable space gives us measurable *sets*. To do analysis we need measurable *functions* — and the right definition is dictated by one demand: a function should be measurable exactly when it transports the measurable structure correctly. The structure on the target is its $\sigma$-algebra; a function respects it if **preimages of measurable sets are measurable**.

Why preimages and not images? Because $\sigma$-algebra operations commute with preimage but not with image: $f^{-1}(\bigcup S_k)=\bigcup f^{-1}(S_k)$ and $f^{-1}(S^c)=f^{-1}(S)^c$, identities with no analogue for direct images. Preimage is the algebraically faithful direction. This is the identical reason continuity is defined by preimages of open sets — measurability is "continuity for $\sigma$-algebras," and the analogy is exact.

The decisive practical fact: one need not check the preimage condition for *all* measurable target sets, only for a *generating* family. The collection $\{S:f^{-1}(S)\in\mathcal{A}\}$ is itself a $\sigma$-algebra (preimage commutes with the operations), so if it contains a generating set it contains the whole $\sigma$-algebra. For real-valued $f$ this means checking only $f^{-1}((-\infty,a))\in\mathcal{A}$ for each $a$ — a one-parameter family. This is the [[Def - Generated σ-Algebra|"minimality of $\sigma(\mathcal{C})$"]] principle cashed out, and it makes measurability cheap to verify.

# The Definition

Let $(X,\mathcal{A})$, $(Y,\mathcal{A}')$ be measurable spaces. A function $f:X\to Y$ is **$\mathcal{A}$–$\mathcal{A}'$ measurable** (or just **measurable**) if
$$f^{-1}(S)\in\mathcal{A}\qquad\text{for every }S\in\mathcal{A}'.$$

**Generating-set criterion.** If $\mathcal{E}'$ generates $\mathcal{A}'$ ($\sigma(\mathcal{E}')=\mathcal{A}'$), then $f$ is measurable iff $f^{-1}(S)\in\mathcal{A}$ for all $S\in\mathcal{E}'$.

For **real-valued** $f:X\to\mathbb{R}$ with $Y=\mathbb{R}$, $\mathcal{A}'=\mathcal{B}(\mathbb{R})$, the rays generate, so $f$ is measurable iff $\{x:f(x)<a\}\in\mathcal{A}$ for every $a\in\mathbb{R}$. For **extended-real** $f:X\to[-\infty,\infty]$ one additionally requires $f^{-1}(\{+\infty\}),f^{-1}(\{-\infty\})\in\mathcal{A}$.

The **$\sigma$-algebra generated by $f$** is $\sigma(f)=\{f^{-1}(S):S\in\mathcal{A}'\}$, the smallest $\sigma$-algebra on $X$ making $f$ measurable.

---

# Categorical Definition

A measurable function is precisely a *morphism* in the category $\mathbf{Meas}$ of [[Def - Measurable Space|measurable spaces]]. The condition "$f^{-1}(\mathcal{A}')\subseteq\mathcal{A}$" makes measurable spaces and measurable maps a category, with the same formal shape as $\mathbf{Top}$ (continuous maps) — preimages of distinguished sets are distinguished. $\sigma(f)$ is the *initial $\sigma$-algebra* induced by $f$: the coarsest making $f$ a morphism, the analogue of the initial topology.

---

# Relate to Other Fields / Compression

Measurability is the literal analogue of **continuity** with "open" replaced by "measurable": continuous $\iff$ preimages of open sets open, measurable $\iff$ preimages of measurable sets measurable. Since Borel sets are generated by open sets, *every continuous function is Borel measurable* — continuity is a special case. In probability a measurable function is a [[Def - Random Variable|random variable]], and $\sigma(f)$ is "the information carried by $f$" — the events one can decide by observing $f$ alone. The coarser $\sigma(f)$, the less the function resolves: this is the information-theoretic reading.

---

# Examples / Corollaries

The identity $X\to X$ is measurable; any continuous $f:\mathbb{R}^n\to\mathbb{R}^m$ is Borel measurable; a composition of measurable maps is measurable ($h^{-1}=f^{-1}\circ g^{-1}$). The **indicator** $\mathbf{1}_A$ is measurable iff $A\in\mathcal{A}$ — its only preimages are $\emptyset,A,A^c,X$. Constant functions are always measurable.

Non-example: with $\mathcal{A}=\{\emptyset,X\}$ the trivial $\sigma$-algebra, a function is measurable iff constant — a coarse $\sigma$-algebra admits few measurable functions.

Calibration: (i) Is $\mathbf{1}_\mathbb{Q}:\mathbb{R}\to\mathbb{R}$ Borel measurable? Yes — $\mathbb{Q}$ is Borel. (ii) Need one check preimages of *all* Borel sets? No — only of the rays $(-\infty,a)$. (iii) Is the image of a measurable set under a measurable map measurable? Not in general — measurability is a preimage condition.
