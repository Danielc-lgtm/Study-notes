## §1.3 The Lebesgue Measure — Exercises

The exercises of §1.3 drill the Lebesgue measure on $\mathbb{R}$ and the strict gaps between measure, cardinality, and topological size. The Cantor set is uncountable yet null (cardinality $\neq$ measure); a fat Cantor set is nowhere dense yet positive-measure (topological smallness $\neq$ measure-smallness); and every Lebesgue set is a Borel set up to a null set, identifying the Lebesgue $\sigma$-algebra as the completion of the Borel one. The unifying observation: Lebesgue measure decouples the three notions of "size."

- [[Ex - The Cantor set has Lebesgue measure zero]] (⭐⭐) — an uncountable null set; measure and cardinality are independent ([[Def - Lebesgue Measure]], [[Thm - Properties of Measures]])
- [[Ex - A fat Cantor set of positive measure]] (⭐⭐⭐) — a compact nowhere-dense set of positive measure; measure and topological size are independent ([[Def - Lebesgue Measure]], [[Thm - Properties of Measures]])
- [[Ex - Lebesgue sets are Borel modulo a null set]] (⭐⭐) — every Lebesgue set is a $G_\delta$ minus a null set; the Lebesgue $\sigma$-algebra is the completion of the Borel one ([[Def - Lebesgue Measure]], [[Def - Null Set and Completion]], [[Thm - Regularity of Lebesgue Measure]])
