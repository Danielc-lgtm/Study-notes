# Notation

$X$ is a set, $2^X$ its power set, $\mathcal{C} \subseteq 2^X$ an arbitrary family of subsets. We write $\sigma(\mathcal{C})$ for the $\sigma$-algebra generated by $\mathcal{C}$. Recall the notion of [[Def - Algebra and σ-Algebra|$\sigma$-algebra]]: a family closed under complement and countable union, containing $X$.

---

# Axiom Motivation

We almost never have a $\sigma$-algebra handed to us directly. What we have is a *list of sets we definitely want to measure* — intervals, open sets, the events generated by a random variable — and we want the smallest $\sigma$-algebra that contains them all. "Smallest" matters: a large $\sigma$-algebra (like the full power set) may admit no useful measure, so we want to add exactly the sets forced on us by closure, and not one set more.

The construction rests on one clean fact: **the intersection of any family of $\sigma$-algebras is again a $\sigma$-algebra**. Check the axioms — if every $\mathcal{A}$ in the family contains $X$, so does the intersection; if every $\mathcal{A}$ is closed under complement, so is the intersection; likewise for countable unions. This is the same "intersection of substructures is a substructure" pattern that produces subgroups generated by a set, spans of vectors, and closures in topology. It is the universal recipe for "smallest structure containing $\mathcal{C}$."

The recipe is non-constructive — it defines $\sigma(\mathcal{C})$ from above, as an intersection, rather than from below by an explicit building process. One *cannot* in general build $\sigma(\mathcal{C})$ by alternately taking countable unions and countable intersections finitely many times: the process must be iterated through the transfinite ordinals (the *Borel hierarchy*). This is why "$A \in \sigma(\mathcal{C})$" is usually proved not by exhibiting $A$ but by the $\sigma(\mathcal{C}) \subseteq \mathcal{A}$ argument below, or by Dynkin's [[Thm - Dynkin's π-λ Theorem|$\pi$–$\lambda$ theorem]].

---

# The Definition

Let $\mathcal{C} \subseteq 2^X$. The **$\sigma$-algebra generated by $\mathcal{C}$** is

$$\sigma(\mathcal{C}) = \bigcap \{ \mathcal{A} \subseteq 2^X : \mathcal{A} \text{ is a } \sigma\text{-algebra and } \mathcal{C} \subseteq \mathcal{A} \}.$$

This intersection is well-defined and nonempty because $2^X$ is itself a $\sigma$-algebra containing $\mathcal{C}$, so the family being intersected is nonempty. By the closure of $\sigma$-algebras under intersection, $\sigma(\mathcal{C})$ is a $\sigma$-algebra. It contains $\mathcal{C}$, and it is the **smallest** such: if $\mathcal{A}$ is any $\sigma$-algebra with $\mathcal{C} \subseteq \mathcal{A}$, then $\sigma(\mathcal{C}) \subseteq \mathcal{A}$, directly from the definition as an intersection.

$\mathcal{C}$ is called a **generating set** for $\sigma(\mathcal{C})$, and $\mathcal{C}$ is a $\sigma$-algebra if and only if $\sigma(\mathcal{C}) = \mathcal{C}$.

---

# Categorical Definition

$\sigma(-)$ is a closure operator — and the left adjoint to the forgetful functor from $\sigma$-algebras to families of subsets. The defining property "$\sigma(\mathcal{C})$ is the smallest $\sigma$-algebra containing $\mathcal{C}$" is a universal property: for any $\sigma$-algebra $\mathcal{A}$, an inclusion $\mathcal{C} \hookrightarrow \mathcal{A}$ extends uniquely to $\sigma(\mathcal{C}) \hookrightarrow \mathcal{A}$. As a closure operator it is monotone ($\mathcal{C} \subseteq \mathcal{D} \Rightarrow \sigma(\mathcal{C}) \subseteq \sigma(\mathcal{D})$), extensive ($\mathcal{C} \subseteq \sigma(\mathcal{C})$), and idempotent ($\sigma(\sigma(\mathcal{C})) = \sigma(\mathcal{C})$) — the same three laws satisfied by topological closure, linear span, and subgroup generation.

---

# Relate to Other Fields / Compression

This is *literally* the same construction as the subgroup generated by a subset, the linear span of a set of vectors, or the topological closure of a set — "smallest substructure containing $\mathcal{C}$", obtained as an intersection of all substructures that contain it. The one feature peculiar to the $\sigma$-algebra case is that the construction is *radically* non-constructive: spans and subgroups can be built in one explicit pass (all finite linear combinations; all finite words), but $\sigma(\mathcal{C})$ genuinely needs transfinite iteration. This is why proving $A \in \sigma(\mathcal{C})$ is subtle and why tools like the [[Thm - Dynkin's π-λ Theorem|$\pi$–$\lambda$ theorem]] exist.

---

# Examples / Corollaries

For the empty family, $\sigma(\emptyset) = \{\emptyset, X\}$, the trivial $\sigma$-algebra. For a single set $A$, $\sigma(\{A\}) = \{\emptyset, A, A^c, X\}$. For a finite partition $X = \bigsqcup_{i=1}^N X_i$, the generated $\sigma$-algebra is the *finite* family of all unions of partition blocks — it has $2^N$ elements, and a function is measurable for it exactly when it is constant on each block.

The single most important instance: when $(X, \tau)$ is a topological space, $\mathcal{B}(X) = \sigma(\tau)$ is the [[Def - Borel σ-Algebra|Borel $\sigma$-algebra]], generated by the open sets.

The **standard proof technique** unlocked here: to show $\sigma(\mathcal{C}) \subseteq \mathcal{A}$ for some $\sigma$-algebra $\mathcal{A}$, it suffices to show $\mathcal{C} \subseteq \mathcal{A}$ — the rest is automatic. This is used constantly. For instance, to check a function $f$ is [[Def - Measurable Function|measurable]] one only checks $f^{-1}(C) \in \mathcal{A}$ for $C$ in a *generating* family, never for all Borel sets: the family $\{B : f^{-1}(B) \in \mathcal{A}\}$ is a $\sigma$-algebra, so containing the generators forces it to contain $\sigma(\text{generators})$.

Calibration: (i) $\sigma(\mathcal{C})$ for $\mathcal{C} = \{(a,b) : a < b\}$ on $\mathbb{R}$ is the Borel $\sigma$-algebra — the open intervals already generate it. (ii) If $\mathcal{C}$ is countable, is $\sigma(\mathcal{C})$ countable? No, in general — even a countable generating set produces an uncountable $\sigma$-algebra (the Borel sets of $\mathbb{R}$). (iii) Is $\sigma(\mathcal{C}_1 \cup \mathcal{C}_2) = \sigma(\mathcal{C}_1) \cup \sigma(\mathcal{C}_2)$? No — the union of two $\sigma$-algebras is rarely a $\sigma$-algebra; one must regenerate.
