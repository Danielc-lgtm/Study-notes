# Notation

Throughout, $X$ and $Y$ are **Banach manifolds** in the sense of [[Def - Banach Manifold and Smooth Maps between Banach Spaces|Banach manifolds]]: each is a Hausdorff topological space with an atlas of charts into (fixed, possibly infinite-dimensional) Banach spaces, whose transition maps are smooth in the Fréchet sense. For a point $x\in X$ we write $T_xX$ for the **tangent space** at $x$; when $X$ is modelled on the Banach space $E$, the tangent space $T_xX$ is canonically a Banach space isomorphic to $E$. A map $F\colon X\to Y$ is **smooth**, written $F\in C^\infty(X;Y)$, if it is smooth in every pair of charts; its **differential** at $x$ is the bounded linear map
$$d_xF\colon T_xX\longrightarrow T_{F(x)}Y,$$
read in charts as the ordinary Fréchet derivative. We write $\ker d_xF=\{v\in T_xX: d_xF(v)=0\}$ for its kernel, $\operatorname{im}d_xF=\{d_xF(v): v\in T_xX\}$ for its range (image), and $\operatorname{coker}d_xF=T_{F(x)}Y/\overline{\operatorname{im}d_xF}$ for its cokernel.

A bounded linear map $T\colon E\to G$ between Banach spaces is a [[Def - Fredholm Operator and Index|Fredholm operator]] if $\ker T$ is finite-dimensional, $\operatorname{im}T$ is closed in $G$, and $\operatorname{coker}T=G/\operatorname{im}T$ is finite-dimensional; its **index** is the integer
$$\operatorname{index}T:=\dim\ker T-\dim\operatorname{coker}T\ \in\ \mathbb{Z}.$$
(When the range is closed, the topological cokernel $G/\overline{\operatorname{im}T}$ and the algebraic cokernel $G/\operatorname{im}T$ coincide, so no ambiguity remains.) The full symbol registry for the chapter is on [[Gauge Theory X — Fredholm Maps, Transversality, and Degree]].

The single source for this page is Haydys, *Introduction to Gauge Theory*, Definition 161 and the remark preceding Theorem 162 (p. 52). There is no competing Bär convention here, so the page carries only the one standing convention below.

> [!warning] Convention: regularity of a Fredholm map
> We follow Haydys in stating everything for **smooth** ($C^\infty$) maps, and every result on this page is proved for smooth maps. This is more than is strictly needed downstream: Smale's transversality theorem (the [[Thm - Sard-Smale Theorem|Sard–Smale theorem]]) requires only that $F$ be of class $C^q$ with $q>\max(\operatorname{index}F,0)$, the finite differentiability being forced by the finite-dimensional Sard theorem applied to the local model. We record this weaker hypothesis because in gauge theory the natural maps between Sobolev completions are only finitely often differentiable; wherever a later page needs the sharp regularity it will invoke $C^q$ with $q>\max(\operatorname{index}F,0)$ rather than smoothness.

# Axiom Motivation

The whole of finite-dimensional differential topology rests on one mechanism: if $F\colon X\to Y$ is a smooth map between manifolds and $y\in Y$ is a **regular value** — meaning $d_xF$ is surjective at every $x\in F^{-1}(y)$ — then the preimage $F^{-1}(y)$ is a smooth submanifold of $X$ of dimension
$$\dim F^{-1}(y)=\dim X-\dim Y,$$
by the [[Thm - Regular Value Theorem on Manifolds|regular value theorem]]. The number $\dim X-\dim Y$ is the *virtual dimension* of the fibre: it is fixed by $F$ alone, before any regular value is chosen, and it survives every deformation of $F$. Gauge theory needs exactly this mechanism, but for maps between infinite-dimensional spaces — the configuration space of connections modulo gauge, the Sobolev completion of a space of sections, the domain of the Seiberg–Witten map. There the naive formula is meaningless: $\dim X$ and $\dim Y$ are both infinite, and $\infty-\infty$ names nothing. The task of this definition is to isolate the class of maps for which the *difference* $\dim X-\dim Y$ can be given a finite, deformation-invariant meaning even though the two dimensions themselves cannot.

The obstruction to copying the finite-dimensional theory verbatim is that a bounded linear map between infinite-dimensional Banach spaces can be badly behaved in ways no finite matrix can. Its kernel can be infinite-dimensional; its range can fail to be closed, so that "cokernel" has no stable meaning; it can be injective with dense image yet not surjective (the inclusion of a Sobolev space into $L^2$ is exactly this). The finite-dimensional regular value theorem used, implicitly, that a linear map $\mathbb{R}^m\to\mathbb{R}^n$ always has closed range and finite-dimensional kernel and cokernel — automatic in finite dimensions, and precisely what fails in infinite dimensions. A **Fredholm operator** is the linear-algebraic object that restores all three properties by fiat: finite-dimensional kernel, closed range, finite-dimensional cokernel. For such an operator the number
$$\operatorname{index}T=\dim\ker T-\dim\operatorname{coker}T$$
is a genuine integer, and it is the correct infinite-dimensional stand-in for $\dim X-\dim Y$: in finite dimensions, by the rank–nullity theorem, $\dim\ker T-\dim\operatorname{coker}T=(\dim E-\operatorname{rank}T)-(\dim G-\operatorname{rank}T)=\dim E-\dim G$ exactly, so the index *generalises* the dimension difference rather than replacing it with something new (this is verified in full in the first example below). The definition of a Fredholm map is then forced: it is a smooth map whose differential at every point is a Fredholm operator, so that the finite-dimensional mechanism runs pointwise with $\operatorname{index}d_xF$ playing the role of $\dim X-\dim Y$.

Consider what each of the three linear requirements is doing, by asking what breaks if it is dropped. **Drop finite-dimensionality of the kernel.** Then even at a regular value the fibre $F^{-1}(y)$, whose tangent space at a solution $x$ is $\ker d_xF$, would be infinite-dimensional, and the whole point — cutting an infinite-dimensional space down to a finite-dimensional moduli space — would be lost. The concrete symptom appears already for the linear map $d\colon C^\infty(S^1)\to C^\infty(S^1)$, $u\mapsto u'$, extended to Sobolev completions: its kernel is only the constants (one-dimensional, so this particular map is fine), but the differentiation-free map $T=0$ has kernel everything, an infinite-dimensional fibre with no finite invariant attached. Finite-dimensionality of the kernel is what makes "the tangent space of the solution set" a finite object. **Drop closedness of the range.** Then the local normal form on which everything depends collapses. The [[Thm - Kuranishi Model for a Fredholm Map|Kuranishi model]] writes $F$ near a zero as $F\circ\phi(x_0,x_1)=Tx_1+f(x_0,x_1)$ with $T\colon X_1\to Y_0$ a linear isomorphism onto the range $Y_0=\operatorname{im}d_pF$; this requires a topological complement $Y=Y_0\oplus Y_1$, and a subspace of a Banach space has a closed complement only if it is itself closed. Without closed range there is no splitting, no isomorphism $T$, and no reduction of $F^{-1}(0)$ to the finite-dimensional zero set of $f_0$. The exact counterexample is the non-example below: the inclusion of a Sobolev space into $L^2$ has dense, proper, hence non-closed range, and it is not Fredholm. **Drop finite-dimensionality of the cokernel.** Then $\dim\operatorname{coker}T$ is $+\infty$, the index is undefined, and the obstruction space to solving $F(x)=y$ — which in the nonlinear theory measures how far $y$ is from being a regular value — would be infinite-dimensional, so no finite perturbation could make $y$ regular. Each of the three conditions is therefore load-bearing, and together they are the minimal package under which the finite-dimensional fibre-dimension count survives.

One further design choice deserves comment: why demand the Fredholm property at *every* point, and why attach the index to the map rather than to a single differential. The finite-dimensional dimension difference is a global constant, the same over the whole domain; if we only asked that $d_xF$ be Fredholm at the points of one particular fibre, the resulting fibre-dimension would be a purely local number, and there would be no invariant of $F$ to deform. Requiring the Fredholm property everywhere makes $x\mapsto\operatorname{index}d_xF$ a function on all of $X$, and — this is the content of the well-definedness argument in the next section — that function is locally constant, hence constant on each connected component. Only then does "the index of the map" exist as a single integer per component, and only then is it a homotopy invariant strong enough to organise a degree theory and a dimension formula for moduli spaces. A reader who has internalised that the index is the renormalised $\dim X-\dim Y$, that the three linear conditions are exactly what make that renormalisation possible, and that global constancy is what turns a pointwise notion into an invariant of the map, could reconstruct this definition unaided.

# The Definition

Let $X$ and $Y$ be [[Def - Banach Manifold and Smooth Maps between Banach Spaces|Banach manifolds]].

A smooth map $F\in C^\infty(X;Y)$ is a **Fredholm map** if its differential
$$d_xF\colon T_xX\longrightarrow T_{F(x)}Y$$
is a [[Def - Fredholm Operator and Index|Fredholm operator]] for every point $x\in X$; that is, if for each $x$ the kernel $\ker d_xF$ is finite-dimensional, the range $\operatorname{im}d_xF$ is closed, and the cokernel $\operatorname{coker}d_xF=T_{F(x)}Y/\operatorname{im}d_xF$ is finite-dimensional.

For each $x\in X$ the integer
$$\operatorname{index}d_xF=\dim\ker d_xF-\dim\operatorname{coker}d_xF$$
is then defined. It is locally constant in $x$, and consequently constant on each connected component of $X$; when $X$ is connected the common value is the **index of the Fredholm map**, written $\operatorname{index}F$.

The following is the well-definedness verification that turns the pointwise integers $\operatorname{index}d_xF$ into a single invariant of $F$.

**Step 0 — the differential is an operator between Banach spaces, so "Fredholm operator" applies.** For $x\in X$, the tangent space $T_xX$ is a Banach space (isomorphic to the model space of $X$ at $x$) and $T_{F(x)}Y$ is a Banach space, by the definition of a [[Def - Banach Manifold and Smooth Maps between Banach Spaces|Banach manifold]]; and $d_xF$ is a bounded linear map between them because $F$ is smooth, so its chart representative is Fréchet differentiable with bounded derivative. Hence the three defining conditions of a [[Def - Fredholm Operator and Index|Fredholm operator]] are meaningful for $d_xF$, and $\operatorname{index}d_xF$ is a well-defined integer whenever they hold.

**Step 1 — $x\mapsto\operatorname{index}d_xF$ is locally constant.** Fix $x_0\in X$ and choose charts $\psi$ around $x_0$ and $\chi$ around $F(x_0)$, so that in these charts $F$ is represented by a smooth map $\widehat F$ between open subsets of the model Banach spaces $E$ (for $X$) and $G$ (for $Y$). The chart derivative $x\mapsto d\widehat F_{\psi(x)}\in\mathcal{L}(E,G)$ is continuous in the operator norm, because $\widehat F$ is $C^\infty$ (indeed $C^1$ suffices) and the map "second component of the $1$-jet" from $C^1$ maps to $\mathcal{L}(E,G)$ is continuous. Thus $x\mapsto d\widehat F_{\psi(x)}$ is a continuous path of bounded operators, each of which is Fredholm (it is $d_xF$ read in charts, and $F$ is a Fredholm map). We now invoke the stability theorem, restated at the point of use:

> By the [[Thm - Stability of the Fredholm Property under Small and Compact Perturbations|stability of the Fredholm property]] — part (i): the set $\operatorname{Fred}(E,G)$ of Fredholm operators is open in the space of bounded operators, and $\operatorname{index}\colon\operatorname{Fred}(E,G)\to\mathbb{Z}$ is locally constant, so in particular any continuous path of Fredholm operators has constant index — the function $x\mapsto\operatorname{index}d\widehat F_{\psi(x)}$ is constant on a neighbourhood of $\psi(x_0)$.

Transporting back through the charts, $x\mapsto\operatorname{index}d_xF$ is constant on a neighbourhood of $x_0$ in $X$. Since $x_0$ was arbitrary, the function is locally constant on $X$.

**Step 2 — a locally constant integer-valued function is constant on each connected component.** Let $C\subseteq X$ be a connected component and fix $n\in\mathbb{Z}$ in the range of $x\mapsto\operatorname{index}d_xF$ on $C$. The set $A=\{x\in C:\operatorname{index}d_xF=n\}$ is open in $C$ (by Step 1, each of its points has a whole neighbourhood inside $A$) and its complement $C\setminus A=\{x\in C:\operatorname{index}d_xF\neq n\}$ is also open (again by Step 1, applied at any point where the index takes a value other than $n$). Thus $A$ is a non-empty subset of the connected set $C$ that is both open and closed, whence $A=C$ (definition of connectedness: the only subsets that are simultaneously open and closed are $\varnothing$ and $C$). Therefore $\operatorname{index}d_xF=n$ for every $x\in C$.

**Conclusion.** The index is constant on each connected component of $X$, so for connected $X$ the single integer $\operatorname{index}F:=\operatorname{index}d_xF$ (any $x$) is well defined. This is precisely the property that makes the index an invariant of the map rather than of a chosen point, and it is used in exactly this form throughout the chapter — for the fibre-dimension count in the [[Thm - Regular Value and Transversality Theorems for Fredholm Maps|regular value theorem for Fredholm maps]], for the degree theory, and for the Seiberg–Witten dimension formula. $\blacksquare$

# Relate to Other Fields / Compression

The Fredholm index is the exported name, from analysis, of a single idea that reappears under many labels: a *renormalised difference of infinite dimensions*. In the finite-dimensional world it is nothing new — it is $\dim X-\dim Y$, as the rank–nullity computation shows — but in infinite dimensions it is the only piece of the dimension difference that survives, and it survives precisely because it is stable under the perturbations that destroy the individual dimensions. This is why the same integer governs three superficially unrelated theories. In **elliptic partial differential equations**, an elliptic operator on a closed manifold is Fredholm by the [[Thm - Elliptic Operators on Closed Manifolds are Fredholm|Fredholm property of elliptic operators]], and its index is computed topologically by the Atiyah–Singer index theorem; the index there measures "solutions minus obstructions" for the equation. In **topology**, the space $\operatorname{Fred}(H)$ of Fredholm operators on a separable Hilbert space is a classifying space for the functor $K^0$: a continuous family of Fredholm operators parametrised by a compact space $P$ has an index that lives not in $\mathbb{Z}$ but in the K-theory group $K^0(P)$, refining the integer index of a single operator to a virtual bundle $[\ker]-[\operatorname{coker}]$ (the finite-dimensional kernel and cokernel need not have locally constant dimension, but their formal difference is a well-defined bundle; this is developed in the chapter's [[Def - Determinant Line Bundle of a Family of Fredholm Operators|determinant line bundle]] pages). In **differential topology**, the index is the virtual dimension of a moduli space, and the [[Def - Mod-2 Degree of a Proper Fredholm Map|mod-2 degree]] and [[Def - Integer Degree of an Oriented Proper Fredholm Map|integer degree]] of a proper Fredholm map of index zero are the infinite-dimensional replacements for the Brouwer degree. That one integer serves all three is not a coincidence of terminology; it is the assertion that each theory is measuring the same renormalised dimension difference.

**True name.** Officially a Fredholm map is a smooth map whose every differential has finite-dimensional kernel, closed range, and finite-dimensional cokernel. Operationally it is a map that *looks, to first order at every point, like a linear isomorphism up to a finite-dimensional error* — the [[Thm - Kuranishi Model for a Fredholm Map|Kuranishi model]] makes this literal by writing $F$ near a zero as an honest isomorphism $T$ on a complement of the kernel plus a finite-dimensional correction $f_0\colon\ker d_pF\to\operatorname{coker}d_pF$. The index is the signed size of that finite-dimensional error, $\dim(\text{first-order underdetermination})-\dim(\text{first-order obstruction})$, and it is the only number attached to $F$ that no small or compact perturbation, and no homotopy through Fredholm maps, can change. When one needs to *use* a Fredholm map, this operational form — "an isomorphism plus a finite-rank slip, of net size the index" — is the working picture, and it is what the definition should call to mind.

# Examples / Corollaries

**Is an instance — every smooth map between finite-dimensional manifolds, with $\operatorname{index}F=\dim X-\dim Y$.** Let $X$ and $Y$ be finite-dimensional smooth manifolds (a special case of Banach manifolds, modelled on $\mathbb{R}^m$ and $\mathbb{R}^n$ with $m=\dim X$, $n=\dim Y$) and $F\colon X\to Y$ smooth. Fix $x\in X$ and set $T=d_xF\colon T_xX\to T_{F(x)}Y$, a linear map between the finite-dimensional spaces $\mathbb{R}^m$ and $\mathbb{R}^n$. We verify the three clauses. *Finite-dimensional kernel:* $\ker T$ is a subspace of the $m$-dimensional space $T_xX$, so $\dim\ker T\le m<\infty$. *Closed range:* every linear subspace of the finite-dimensional space $T_{F(x)}Y$ is closed (finite-dimensional subspaces of any normed space are closed, being complete hence closed), so $\operatorname{im}T$ is closed. *Finite-dimensional cokernel:* $\operatorname{coker}T=T_{F(x)}Y/\operatorname{im}T$ is a quotient of the $n$-dimensional space, so $\dim\operatorname{coker}T\le n<\infty$. Hence $T$ is a Fredholm operator, and this holds at every $x$, so $F$ is a Fredholm map. Its index is computed by the rank–nullity theorem: writing $r=\dim\operatorname{im}T=\operatorname{rank}T$,
$$\operatorname{index}d_xF=\dim\ker T-\dim\operatorname{coker}T=(m-r)-(n-r)=m-n$$
(first equality by the definition of the index; second because $\dim\ker T=m-r$ by rank–nullity applied to $T\colon\mathbb{R}^m\to\mathbb{R}^n$, and $\dim\operatorname{coker}T=\dim T_{F(x)}Y-\dim\operatorname{im}T=n-r$; the $r$'s cancel). The value $m-n$ is independent of $x$ and of $F$, confirming that on a connected $X$ the index equals $\dim X-\dim Y$, exactly the finite-dimensional virtual fibre-dimension. This is the sense in which the Fredholm index *is* the dimension difference, generalised.

**Is an instance — a semilinear elliptic map $u\mapsto Lu+N(u)$, with $\operatorname{index}F=\operatorname{index}L$.** Let $M$ be a closed Riemannian manifold, $E\to M$ a vector bundle, $L$ a linear elliptic differential operator of order $k$ acting on sections of $E$, and $N$ a nonlinear differential operator of order strictly less than $k$ (a "lower-order nonlinearity"). Passing to Sobolev completions makes
$$F\colon W^{k,2}(M;E)\longrightarrow L^2(M;E),\qquad F(u)=Lu+N(u),$$
a smooth map of Banach spaces (using the [[Thm - Sobolev Multiplication Theorem|Sobolev multiplication theorem]] to see that $N$ maps $W^{k,2}$ smoothly into $L^2$). Its differential at $u$ is $d_uF=L+dN_u$, where $dN_u$ is a linear differential operator of order $<k$. We verify the Fredholm property clause by clause via the linear theory rather than by hand. First, $L\colon W^{k,2}\to L^2$ is Fredholm by the [[Thm - Elliptic Operators on Closed Manifolds are Fredholm|Fredholm property of elliptic operators on a closed manifold]] (elliptic estimate plus [[Thm - Rellich Compactness Theorem|Rellich compactness]] give finite-dimensional kernel and closed range of finite codimension). Second, the lower-order term $dN_u\colon W^{k,2}\to L^2$ is a **compact** operator: it factors as an order-$<k$ differential operator $W^{k,2}\to W^{1,2}$ followed by the compact [[Thm - Rellich Compactness Theorem|Rellich]] inclusion $W^{1,2}\hookrightarrow L^2$ (a bounded operator composed with a compact one is compact). Third, by the [[Thm - Stability of the Fredholm Property under Small and Compact Perturbations|stability of the Fredholm property]] — part (ii): if $T$ is Fredholm and $K$ is compact then $T+K$ is Fredholm with $\operatorname{index}(T+K)=\operatorname{index}T$ — the differential $d_uF=L+dN_u$ is Fredholm with $\operatorname{index}d_uF=\operatorname{index}L$ at every $u$. Hence $F$ is a Fredholm map and $\operatorname{index}F=\operatorname{index}L$: the nonlinearity, being lower order, does not move the index. This is the mechanism behind every dimension formula in the subject — the moduli space dimension is read off the *linear* elliptic part alone. The full verification, including the smoothness of $F$ and the order bookkeeping, is carried out on the exercise page for this construction.

**Is an instance — the Seiberg–Witten map (chapter XI).** The map whose zero set is the Seiberg–Witten moduli space, sending a spinor–connection pair $(\psi,A)$ to the pair $\big(\slashed D_A\psi,\ F_A^+-\mu(\psi)-\eta\big)$ between suitable Sobolev completions, is a Fredholm map after passing to the Coulomb slice; its differential is a compact perturbation of the decoupled elliptic operator $\slashed D_A^+\oplus(d^++d^*)$, and its index — computed by the Atiyah–Singer index theorem and Hodge theory — is the virtual dimension of the moduli space. This is the payoff of the whole chapter and is treated in full on **the Seiberg–Witten pages of chapter XI**; it is named here only to show that the definition's target application is exactly a map of this shape.

**Is NOT an instance — the inclusion of a Sobolev space into $L^2$.** Let $\iota\colon W^{1,2}(S^1)\hookrightarrow L^2(S^1)$ be the inclusion, $\iota(u)=u$ (a bounded linear map, hence its own differential at every point: $d_u\iota=\iota$). We check that $\iota$ fails to be Fredholm, and identify which clause fails. *Kernel:* $\iota$ is injective, so $\ker\iota=\{0\}$ is finite-dimensional — this clause holds. *Range:* the range $\operatorname{im}\iota=W^{1,2}(S^1)$, viewed inside $L^2(S^1)$, is **dense** (it contains the smooth functions, which are dense in $L^2$) and **proper** (there exist $L^2$-functions that are not weakly differentiable). Concretely, the function
$$f(\theta)=\sum_{n\ge 2}\frac{1}{n\log n}\,e^{in\theta}$$
lies in $L^2(S^1)$ because $\sum_{n\ge2}(n\log n)^{-2}<\infty$, but not in $W^{1,2}(S^1)$ because $\sum_{n\ge2}n^2\cdot(n\log n)^{-2}=\sum_{n\ge2}(\log n)^{-2}=\infty$ diverges (the $W^{1,2}$-norm of $\sum c_ne^{in\theta}$ is $\sum(1+n^2)|c_n|^2$). A dense proper subspace of a Banach space is never closed: if $\operatorname{im}\iota$ were closed it would equal its closure $L^2(S^1)$, contradicting $f\in L^2\setminus\operatorname{im}\iota$. So $\operatorname{im}\iota$ is **not closed**, and the closed-range clause fails; therefore $\iota$ is not a Fredholm operator and $\iota$ is not a Fredholm map. The failure is exactly the one anticipated in the Axiom Motivation: a map with non-closed range admits no topological complement of its image, so the Kuranishi normal form cannot be written and no finite index can be attached. (One can see the same conclusion from compactness: $\iota$ is compact by the [[Thm - Rellich Compactness Theorem|Rellich compactness theorem]], and a compact operator between infinite-dimensional spaces cannot be Fredholm, since a Fredholm operator has closed range of finite codimension while a compact operator's range contains no closed infinite-dimensional subspace.)

**Corollary — a linear isomorphism of Banach spaces is a Fredholm map of index $0$.** If $T\colon X\to Y$ is a bounded linear isomorphism between Banach spaces, viewed as a smooth map, then $d_xT=T$ at every $x$; $\ker T=\{0\}$ and $\operatorname{coker}T=Y/\operatorname{im}T=Y/Y=\{0\}$, both trivially finite-dimensional, and $\operatorname{im}T=Y$ is closed. Hence $T$ is a Fredholm map with $\operatorname{index}T=0-0=0$. More generally any diffeomorphism of Banach manifolds is Fredholm of index $0$, since its differential is a linear isomorphism at every point.

**Corollary — the composite of Fredholm maps is Fredholm, with index the sum.** If $F\colon X\to Y$ and $G\colon Y\to Z$ are Fredholm maps, then $G\circ F$ is a Fredholm map with $\operatorname{index}(G\circ F)=\operatorname{index}G+\operatorname{index}F$ on each connected component. Indeed $d_x(G\circ F)=d_{F(x)}G\circ d_xF$ by the chain rule, and the composite of two [[Def - Fredholm Operator and Index|Fredholm operators]] is Fredholm with index the sum of the indices — this is the logarithmic additivity of the index, proved on the [[Def - Fredholm Operator and Index|Fredholm operator]] page. Composing pointwise and using constancy on components gives the stated formula.

**Calibration check.** Three quick verifications the reader can run from the page. (1) The constant map $F\colon X\to Y$, $F\equiv y_0$, between infinite-dimensional Banach spaces has $d_xF=0$, whose kernel is all of $T_xX$ (infinite-dimensional); so the zero map is *not* Fredholm and a constant map into an infinite-dimensional target is not a Fredholm map — confirming that the finite-dimensional kernel clause has real content. (2) For $F\colon\mathbb{R}^3\to\mathbb{R}^2$ any smooth map, $\operatorname{index}F=3-2=1$, so a regular fibre is a $1$-manifold, matching the classical count. (3) If $F$ is a Fredholm map with $\operatorname{index}F=0$ and $d_pF$ is injective at some $p$, then $d_pF$ is an isomorphism there: injectivity gives $\dim\ker d_pF=0$, and $\operatorname{index}=0$ then forces $\dim\operatorname{coker}d_pF=0$, so with closed range $d_pF$ is onto as well — the index-zero condition is what upgrades "injective differential" to "invertible differential", the exact fact the [[Def - Mod-2 Degree of a Proper Fredholm Map|degree theory]] rests on.

# Unlocked by This

> [!tip] Regular value and transversality theorems for Fredholm maps *(from Gauge Theory X)*
> With the Fredholm condition in hand, the [[Thm - Regular Value and Transversality Theorems for Fredholm Maps|regular value theorem for Fredholm maps]] states that if $0$ is a regular value of a Fredholm map $F$ then $F^{-1}(0)$ is a smooth manifold of dimension $\operatorname{index}F$ — the infinite-dimensional regular value theorem, with the index playing the role of $\dim X-\dim Y$.

> [!tip] The Kuranishi model *(from Gauge Theory X)*
> The [[Thm - Kuranishi Model for a Fredholm Map|Kuranishi model]] gives the local normal form that justifies the whole theory: near a zero, a Fredholm map is a linear isomorphism plus a finite-dimensional correction, reducing the local structure of $F^{-1}(0)$ to the zero set of a map between finite-dimensional spaces.

> [!tip] The Sard–Smale theorem *(from Gauge Theory X)*
> The [[Thm - Sard-Smale Theorem|Sard–Smale theorem]] — that the regular values of a Fredholm map form a residual, hence dense, set — is the theorem that makes the regular value theorem usable in practice, and it is precisely for Fredholm maps that Sard's theorem survives into infinite dimensions.

> [!tip] Degree theory for proper Fredholm maps *(from Gauge Theory X)*
> For a proper Fredholm map of index zero between connected Banach manifolds, counting the (finite) preimage of a regular value gives the [[Def - Mod-2 Degree of a Proper Fredholm Map|mod-2 degree]] and, with orientations, the [[Def - Integer Degree of an Oriented Proper Fredholm Map|integer degree]] — the infinite-dimensional Brouwer degree.
