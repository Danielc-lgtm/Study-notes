## §4.3 Sard's Theorem and Whitney Embedding — Exercises

This section's exercises explore the global consequences of [[Thm - Sard's Theorem|Sard's theorem]] — the fact that the set of critical values of any smooth map has measure zero — and the [[Thm - Whitney Embedding Theorem|Whitney embedding theorem]], which says every smooth $n$-manifold embeds in $\mathbb{R}^{2n+1}$. The exercises here are conceptually heavier than computational: Sard's theorem is non-constructive (it asserts existence of regular values without identifying them), and Whitney's theorem is a structural result whose proof relies on iterated application of Sard. The recurring themes are (a) genericity arguments — almost every value of a smooth map is regular, so structures depending on a regular value choice are robust; (b) the bridge from local structure (immersions, submersions) to global embeddings; and (c) the use of Sard to justify "perturb to general position" arguments. Note: this section is sparsely exercised in Lee's text because most concrete applications appear in later topics (Morse theory, transversality, cobordism); for this index, the canonical exercises are drawn from the topic's flagship examples — particularly the regular-level-set exercises from §4.2, which all implicitly use Sard's genericity to motivate why "regular values" are a sensible hypothesis to demand. The placeholder structure here reflects that the deep applications of Sard live in later topics.

- [[Ex - The Sphere as a Level Set]] (⭐) — Although primarily an exercise in the regular value theorem, this also exhibits Sard's content in microcosm: the unique critical value of $f(x) = |x|^2$ is $0$, a set of measure zero in $\mathbb{R}$, so every other value is regular. The sphere $f^{-1}(1)$ sits firmly in the "almost all regular values" regime. ([[Def - Regular and Critical Points]], [[Def - Set of Measure Zero on a Manifold]], [[Thm - Sard's Theorem]], [[Thm - Regular Value Theorem on Manifolds]])

- [[Ex - The Special Linear Group is a Submanifold of GL(n)|Ex - The Special Linear Group is a Submanifold of GL(n)]] (⭐⭐) — The critical values of $\det : \mathrm{GL}(n,\mathbb{R}) \to \mathbb{R}$ are: $\det$ is a submersion on $\mathrm{GL}(n,\mathbb{R})$ (its differential is everywhere nonzero by Jacobi's formula), so it has *no* critical points, hence no critical values. Every value of $\det$ on $\mathrm{GL}(n,\mathbb{R})$ is regular — confirming Sard "trivially" here, but more importantly, showing that all level sets $\det^{-1}(c)$ for $c \neq 0$ are submanifolds. ([[Def - Set of Measure Zero on a Manifold]], [[Thm - Sard's Theorem]], [[Thm - Regular Value Theorem on Manifolds]])

- [[Ex - The Orthogonal Group as a Regular Level Set]] (⭐⭐⭐) — A subtler Sard manifestation: the map $\Phi : \mathrm{Mat}_n \to \mathrm{Sym}_n$, $\Phi(A) = A^T A$, has critical values where $d\Phi_A$ fails to be surjective. The exercise shows $I$ is a regular value (every point of $\Phi^{-1}(I) = \mathrm{O}(n)$ is regular). But $0 = \Phi(0)$ is a critical value (the zero matrix is a critical point: $d\Phi_0 = 0$). Sard says critical values like $\Phi(\text{singular matrices})$ have measure zero, so almost every value of $\Phi$ is regular and gives a smooth submanifold. ([[Def - Regular and Critical Points]], [[Def - Set of Measure Zero on a Manifold]], [[Thm - Sard's Theorem]], [[Thm - Regular Value Theorem on Manifolds]])
