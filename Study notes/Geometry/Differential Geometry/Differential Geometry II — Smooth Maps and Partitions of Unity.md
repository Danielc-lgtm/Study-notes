# Notation Registry

Throughout this topic we adopt Lee's conventions: a "manifold" without further qualification is a smooth manifold (Hausdorff, second countable, locally Euclidean, equipped with a maximal smooth atlas), and a "chart" is a smooth chart compatible with that atlas. Real-valued smooth functions are written $f, g, h$; smooth maps between manifolds are written with capital letters $F, G, H$. The default codomain of an unspecified "function" is $\mathbb{R}$; the default codomain of an unspecified "map" is another manifold. We work over $\mathbb{R}$ throughout — all manifolds are real and all algebras of smooth functions are $\mathbb{R}$-algebras.

- $M, N, P$ — smooth manifolds, of dimensions $m, n, p$ respectively
- $(U, \varphi)$, $(V, \psi)$ — smooth charts: $\varphi : U \to \widetilde U \subseteq \mathbb{R}^m$ is a homeomorphism onto an open subset
- $\widehat f = f \circ \varphi^{-1}$ — the **coordinate representation** of a real-valued function $f$ in the chart $(U, \varphi)$
- $\widehat F = \psi \circ F \circ \varphi^{-1}$ — the coordinate representation of a map $F : M \to N$
- $C^\infty(M)$ — the $\mathbb{R}$-algebra of smooth functions $M \to \mathbb{R}$
- $C^\infty(M, N)$ — the set of smooth maps $M \to N$
- $\operatorname{Diff}(M)$ — the diffeomorphism group of $M$ under composition
- $\operatorname{supp}(f) = \overline{\{p \in M : f(p) \neq 0\}}$ — the **support** of $f$ (closure of the non-vanishing set)
- $f \in C^\infty_c(M)$ — $f$ is smooth and compactly supported
- $\{U_\alpha\}_{\alpha \in A}$ — an open cover of $M$, indexed by a set $A$
- $\{\psi_\alpha\}_{\alpha \in A}$ — a smooth partition of unity (occasionally $\{\rho_\alpha\}$; both letters are standard)
- $H \subseteq M$ — a generic (often closed) subset
- $\psi : \mathbb{R} \to \mathbb{R}$, $\psi(t) = e^{-1/t}$ for $t > 0$ and $\psi(t) = 0$ for $t \leq 0$ — the standard one-sided smooth bump germ; the building block for every cutoff we construct

# Motivation

Here is the entire topic in one sentence: a function on a manifold is smooth if it looks smooth in every chart, and any local smooth construction can be glued into a global one using a partition of unity. Those are the only two ideas. Everything else — diffeomorphisms, the algebra $C^\infty(M)$, smooth bump functions, the extension lemma, the existence of Riemannian metrics — follows from these two ideas applied carefully.

The first idea solves a definition problem. We have a smooth manifold from [[Differential Geometry I — Smooth Manifolds and Atlases]], which is a topological space carrying a *smooth structure* — a maximal atlas of charts whose transition maps are smooth in the Euclidean sense. We have no calculus on the manifold itself, only on its charts. To say a function $f : M \to \mathbb{R}$ is smooth, we have nothing to lean on except its appearance through a chart, $\widehat f = f \circ \varphi^{-1} : \widetilde U \to \mathbb{R}$, which is a function between Euclidean open sets where smoothness already means something. So we define $f$ to be smooth when every such $\widehat f$ is, and we check (one short calculation using the smoothness of transitions) that this does not depend on the chart. The same trick gives smooth maps $F : M \to N$ via two charts at once. *The pattern is: manifold-level concepts are defined by pulling back to charts, and the smooth-atlas axiom is what guarantees the definition is chart-independent.* This pattern recurs constantly — for tangent vectors, vector fields, differential forms, integrals — and §2.1 is where it is established for the easiest case, real-valued functions.

The second idea solves an existence problem. Almost every interesting global object on a manifold — a Riemannian metric, a volume form, a connection, a smooth function with prescribed local data — is easy to construct in *one* chart, where the manifold looks like Euclidean space and we can write down whatever we like. The obstacle is that different charts disagree on overlaps. We need a way to take a chart-by-chart family of local constructions and glue them into a single global construction that smoothly interpolates between the local pieces. The mechanism is a **partition of unity**: a family of smooth nonnegative functions $\{\psi_\alpha\}$, each supported in one chart $U_\alpha$, summing to $1$ pointwise on $M$. Given local objects $T_\alpha$ on each $U_\alpha$, the weighted average $T = \sum_\alpha \psi_\alpha T_\alpha$ is a global object that agrees with $T_\alpha$ where $\psi_\alpha = 1$ and smoothly blends between them otherwise. **A partition of unity is, in one sentence, a smoothly-varying choice of "which chart to use here".**

The existence of smooth partitions of unity on every smooth manifold is the central theorem of this topic. The proof reduces to two ingredients. First, manifolds are paracompact (this is forced by Hausdorff + second-countable, plus a topological theorem from [[Topology III — §8–12 Products, Metric Spaces, Locally Compact, Paracompact|Topology III]]), so every open cover has a locally finite refinement. Second, we can construct smooth **bump functions** on $\mathbb{R}^n$: real-valued smooth functions equal to $1$ on a prescribed ball and $0$ outside a slightly larger one. The bumps come from a single trick — the function $\psi(t) = e^{-1/t}$ for $t > 0$ and $\psi(t) = 0$ for $t \leq 0$, which is the simplest smooth function whose support is exactly the half-line $[0, \infty)$. Everything else is assembly. Pull the Euclidean bumps back through charts, weight by the locally finite cover, normalize.

The applications close the topic: bump functions for arbitrary closed sets, the smooth extension lemma (extending smooth functions from closed subsets), and — the application that motivates the whole theorem — the existence of a Riemannian metric on every smooth manifold. Each is the same construction with different ingredients: local-on-each-chart plus partition-of-unity yields global. This template is what makes manifold theory tractable.

A reader is assumed to have refreshed [[Differential Geometry I — Smooth Manifolds and Atlases|DG I]] (smooth manifolds, charts, smooth atlases) and to be comfortable with chart-changes. Familiarity with [[Topology III — §8–12 Products, Metric Spaces, Locally Compact, Paracompact|paracompactness]] and the topological [[Def - Partition of Unity|partition of unity]] is helpful but not required — the manifold version is the topological version plus the smoothness upgrade, and we recall what we need.

# Concept Map

## §2.1 Smooth Functions and Smooth Maps

- **[[Def - Smooth Function on a Manifold]]**
	- A function $f : M \to \mathbb{R}$ is **smooth** at $p \in M$ if there is a smooth chart $(U, \varphi)$ with $p \in U$ such that $f \circ \varphi^{-1} : \varphi(U) \to \mathbb{R}$ is smooth in the Euclidean sense at $\varphi(p)$, and **smooth on $M$** if smooth at every point. The smooth-atlas axiom forces this to be chart-independent: if it holds for one compatible chart at $p$, it holds for every one. This is the prototype manifold-level definition — define a concept by passing to charts and check it is intrinsic. The set of smooth functions on $M$ is denoted $C^\infty(M)$.

- **[[Def - Smooth Map between Manifolds]]**
	- A map $F : M \to N$ between smooth manifolds is **smooth** at $p \in M$ if there exist charts $(U, \varphi)$ on $M$ with $p \in U$ and $(V, \psi)$ on $N$ with $F(p) \in V$, such that $F(U) \subseteq V$ and the **coordinate representation** $\widehat F = \psi \circ F \circ \varphi^{-1} : \varphi(U) \to \psi(V)$ is smooth in the Euclidean sense at $\varphi(p)$. The containment $F(U) \subseteq V$ is part of the definition — it is what forces smooth maps to be continuous (otherwise the pre-image of the codomain chart might not even be open). The chart-independence follows from the smoothness of transition functions on both sides.

- **[[Thm - Smooth Maps are Continuous]]**
	- Every smooth map $F : M \to N$ is continuous. The proof is a one-liner: in a chart neighbourhood, $F|_U = \psi^{-1} \circ \widehat F \circ \varphi$ is a composition of continuous maps. The non-trivial input is the requirement $F(U) \subseteq V$ in the definition of smooth — without this we could not write $F|_U$ as a chart-composition. (Problem 2-1 of Lee constructs a map that satisfies "chart by chart smooth" without this requirement, and is not even continuous.) The theorem then yields the basic functorial properties: composition of smooth maps is smooth, projection from a product is smooth, the identity is smooth.

- **[[Ex - Composition of Smooth Maps is Smooth]]** (⭐)
	- Show that if $F : M \to N$ and $G : N \to P$ are smooth maps between smooth manifolds, then $G \circ F : M \to P$ is smooth. Drills the chart-pulling-back routine.

- **[[Ex - The Inclusion of an Open Submanifold is Smooth]]** (⭐)
	- Let $U \subseteq M$ be an open submanifold (open subset with the inherited smooth structure from [[Differential Geometry I — Smooth Manifolds and Atlases|DG I]]). Show that the inclusion $\iota : U \hookrightarrow M$ is smooth and a diffeomorphism onto its image.

- **[[Def - Diffeomorphism]]**
	- A **diffeomorphism** $F : M \to N$ is a smooth bijection whose inverse is also smooth. Two manifolds are **diffeomorphic** if a diffeomorphism between them exists; this is the equivalence relation under which smooth manifold theory is conducted. The set of diffeomorphisms $M \to M$ forms a group under composition, the **diffeomorphism group** $\operatorname{Diff}(M)$, which is enormous (for $M$ of positive dimension it is infinite-dimensional). Crucially, smooth bijection is *not* sufficient: the map $\mathbb{R} \to \mathbb{R}$, $x \mapsto x^3$ is a smooth bijection whose inverse $x \mapsto x^{1/3}$ is not smooth at $0$.

- **[[Def - The Smooth Functions Ring]]**
	- $C^\infty(M)$ is the set of smooth functions $M \to \mathbb{R}$, made into a **commutative ring with $1$** under pointwise operations $(f + g)(p) = f(p) + g(p)$ and $(fg)(p) = f(p)g(p)$, with $0$ the zero function and $1$ the constant function $1$. It is moreover a **commutative $\mathbb{R}$-algebra**: scalar multiplication $(\lambda f)(p) = \lambda f(p)$ makes $C^\infty(M)$ into a real vector space in which multiplication is bilinear. This ring/algebra structure is the entire algebraic engine of smooth manifold theory — tangent vectors will be derivations of $C^\infty(M)$, vector fields will be derivations as a module, and the entire smooth structure on $M$ can be recovered from $C^\infty(M)$ as an abstract $\mathbb{R}$-algebra (Lee Problem 2-10).

- **[[Def - Support of a Function]]**
	- The **support** of a function $f : M \to \mathbb{R}$ is $\operatorname{supp}(f) = \overline{\{p \in M : f(p) \neq 0\}}$, the topological closure of the non-vanishing set. A function is **compactly supported** if $\operatorname{supp}(f)$ is compact, and **supported in $U$** if $\operatorname{supp}(f) \subseteq U$. Note the closure: the support is not the set where $f$ is nonzero, but its closure. The closure matters because limit points of the non-vanishing set are points where $f$ vanishes but is "infinitesimally close" to not vanishing; for a continuous $f$, $\operatorname{supp}(f)$ is the smallest closed set outside of which $f$ vanishes identically.

> [!tip] Unlocked: Sheaf of Smooth Functions *(from Sheaf Theory)*
> The assignment $U \mapsto C^\infty(U)$ for each open $U \subseteq M$ is the **sheaf** $\mathcal{O}_M$ of smooth functions on $M$. Two functions agree on an open cover if and only if they agree globally, and any compatible family of local sections glues to a unique global section. This is one of the foundational examples of a sheaf — and the sheaf-theoretic point of view is what generalises smooth manifold theory to algebraic varieties and complex analytic spaces.

> [!tip] Unlocked: Ringed Space *(from Algebraic Geometry)*
> The pair $(M, C^\infty)$ — a topological space together with its sheaf of smooth functions — is a **ringed space**, and the smooth-map condition "$F^* C^\infty(N) \subseteq C^\infty(M)$" makes manifolds into a category of ringed spaces. The same picture with $C^\infty$ replaced by a sheaf of polynomial functions gives algebraic geometry; with holomorphic functions it gives complex geometry. Lee's Problem 2-10 is the recognition that *the smooth structure is recoverable from $C^\infty(M)$ alone*.

## §2.2 Partitions of Unity

- **[[Def - Bump Function and Smooth Cutoff]]**
	- A **smooth bump function for $A$ supported in $U$** (where $A \subseteq U \subseteq M$, $A$ closed, $U$ open) is a smooth $\psi : M \to [0, 1]$ with $\psi \equiv 1$ on $A$ and $\operatorname{supp}(\psi) \subseteq U$. On $\mathbb{R}^n$, the canonical example is built from the one-variable germ $\psi_0(t) = e^{-1/t}$ for $t > 0$, $0$ for $t \leq 0$: the function $h(t) = \psi_0(r_2 - t)/(\psi_0(r_2 - t) + \psi_0(t - r_1))$ is a smooth cutoff transitioning from $1$ on $(-\infty, r_1]$ to $0$ on $[r_2, \infty)$, and $H(x) = h(|x|)$ is a radial bump on $\mathbb{R}^n$. Bumps are the atomic ingredient: every partition of unity is a normalized family of bump functions.

- **[[Thm - Existence of Smooth Bump Functions]]**
	- For any closed $A \subseteq M$ and any open $U \supseteq A$, there exists a smooth bump function for $A$ supported in $U$. The construction uses a smooth partition of unity subordinate to $\{U, M \setminus A\}$ and takes the component supported in $U$. The theorem says smooth manifolds are remarkably "soft" — they support more functions than one might guess. By contrast, analytic manifolds *fail* this property: a real-analytic function that vanishes on an open set vanishes identically (analytic continuation), so no analytic bump exists. The non-rigidity of $C^\infty$ versus $C^\omega$ is what makes manifold theory work.

- **[[Ex - Constructing a Bump Function on Euclidean Space]]** (⭐⭐)
	- Construct, explicitly, a smooth function $\psi : \mathbb{R} \to [0, 1]$ that equals $1$ on $[-1, 1]$ and vanishes outside $[-2, 2]$, starting from $\psi_0(t) = e^{-1/t^2}$ for $t > 0$. The exercise drills the $e^{-1/t}$-trick: how to manufacture compact-support smoothness from a function whose every derivative vanishes at one endpoint.

- **[[Def - Support of a Function|Def — Support of a Function (recalled)]]**
	- (Used again here for partitions of unity.) See the §2.1 entry.

- **[[Def - Partition of Unity on a Manifold]]**
	- A **smooth partition of unity** on a smooth manifold $M$ subordinate to an open cover $\{U_\alpha\}_{\alpha \in A}$ is a family of smooth functions $\{\psi_\alpha\}_{\alpha \in A}$, $\psi_\alpha : M \to [0, 1]$, with (i) $\operatorname{supp}(\psi_\alpha) \subseteq U_\alpha$, (ii) the supports $\{\operatorname{supp}(\psi_\alpha)\}$ are locally finite (every point has a neighbourhood meeting only finitely many of them), and (iii) $\sum_\alpha \psi_\alpha(p) = 1$ for every $p \in M$ (a finite sum at each point by local finiteness). This is the [[Def - Partition of Unity|topological partition of unity]] with the additional requirement that each $\psi_\alpha$ is smooth — the upgrade is non-trivial because not every topological space supporting partitions of unity supports smooth ones.

- **[[Thm - Existence of Smooth Partitions of Unity]]**
	- Every open cover of a smooth manifold admits a subordinate smooth partition of unity. The proof reduces the cover to a countable locally finite refinement by regular coordinate balls (using Hausdorff + second-countable, which implies paracompactness via [[Thm - Locally Compact σ-Compact Hausdorff is Paracompact]]), constructs smooth bumps on each refinement element by pulling back the standard Euclidean bumps through charts, sums them, and normalizes. This is the workhorse of every "globalization" argument in differential geometry — the existence of Riemannian metrics, connections, volume forms, and global sections of vector bundles all reduce to this theorem.

- **[[Thm - Smooth Extension Lemma]]**
	- If $A \subseteq M$ is closed and $f : A \to \mathbb{R}^k$ is smooth (in the sense that it admits a smooth extension to a neighbourhood of each point), then for any open $U \supseteq A$, $f$ extends to a smooth function $\widetilde f : M \to \mathbb{R}^k$ with $\operatorname{supp}(\widetilde f) \subseteq U$. The proof is the partition-of-unity argument: cover $A$ by open sets on which $f$ extends, add $M \setminus A$, take a partition of unity, sum the local extensions weighted by the partition. The codomain $\mathbb{R}^k$ is essential — for codomain a general manifold, extension may fail topologically (the identity $S^1 \to S^1$ does not extend to a continuous $\mathbb{R}^2 \to S^1$).

- **[[Ex - Smooth Partition of Unity Subordinate to a Cover]]** (⭐⭐)
	- Given a smooth manifold $M$ and a finite open cover $\{U_1, \ldots, U_k\}$, construct an explicit smooth partition of unity subordinate to it. Drills the bump-and-normalize construction in the finite case where no Zorn-like refinement is needed.

- **[[Ex - A Continuous Function on a Compact Manifold Attains its Maximum]]** (⭐)
	- Show that any continuous function $f : M \to \mathbb{R}$ on a compact smooth manifold attains its maximum and minimum. A bookkeeping exercise that drills continuity + compactness; the smooth-map machinery makes the prerequisites for invoking this on smooth functions automatic.

> [!tip] Unlocked: Existence of Riemannian Metrics *(from Riemannian Geometry)*
> Every smooth manifold admits a **Riemannian metric** — a smoothly-varying inner product on each tangent space. The proof is the canonical partition-of-unity argument: take the standard Euclidean inner product in each chart, pull back to define a local metric on each $U_\alpha$, weight by a smooth partition of unity, sum. The sum of positive-definite symmetric bilinear forms is again positive-definite and symmetric, and the partition-of-unity weighting preserves smoothness. *Riemannian geometry exists* because partitions of unity exist. (Full development in **Riemannian Geometry**; the existence proof is sketched in [[Differential Geometry XII — Riemannian and Semi-Riemannian Manifolds|DG XII]].)

> [!tip] Unlocked: Sections of Vector Bundles *(from Differential Geometry)*
> Any smooth vector bundle $E \to M$ admits a global smooth section — and more generally, local sections can be extended/blended into global ones by partitions of unity. This is how **connections**, **Hermitian metrics**, and **bundle morphisms** are constructed in [[Differential Geometry VI — Vector Bundles and the Cotangent Bundle|DG VI]] and onward.

> [!tip] Unlocked: Distributions and Generalized Functions *(from PDE / Microlocal Analysis)*
> A **distribution** on $M$ is a continuous linear functional on the space of compactly-supported smooth functions $C^\infty_c(M)$. The fact that $C^\infty_c(M)$ is rich (it contains every smooth bump) is what makes distribution theory work on manifolds. **Pseudo-differential operators** are similarly defined via partition-of-unity decompositions: each chart hosts a local symbol, the global operator is $\sum_\alpha \psi_\alpha P_\alpha \psi_\alpha$.

# Sources and Targets

**Targets — what do we usually try to prove?**

The exercises and theorems of this topic chase a small repertoire of goals. The first is **verifying smoothness of a specific map** — showing that some explicitly given $F : M \to N$ (an inclusion, a projection, a quotient map, a stereographic projection) is smooth. The route is always the same: pick charts on both sides, write the coordinate representation, recognize it as a composition of smooth Euclidean maps. The second is **constructing a smooth function with prescribed properties** — a bump function equal to $1$ on a given closed set, an extension of a smooth function from a closed subset, a globally defined smooth function approximating some discontinuous data. These constructions almost always route through a partition of unity. The third is **identifying when two manifolds are diffeomorphic** — exhibiting a smooth bijection with smooth inverse, or showing none exists by a diffeomorphism invariant such as dimension. The fourth is **establishing algebraic properties of $C^\infty(M)$** — showing it is infinite-dimensional, showing the ring/algebra structure encodes the smooth structure, building tangent vectors from it. The fifth is **applying partitions of unity to globalize a local construction** — Riemannian metrics, connections, integrals of forms, all built by the same template. These five targets — verify smoothness, construct, diffeomorphism, $C^\infty$ algebra, globalize — recur because they are the modes in which manifold theory is conducted.

**Sources — what assumptions do we usually leverage?**

The recurring assumptions are equally stereotyped. **A coordinate chart at a point** is the richest source: every smoothness question becomes a smoothness question on a Euclidean open set, where ordinary multivariable calculus applies. **The existence of smooth bump functions on $\mathbb{R}^n$** — derived from the one-variable function $e^{-1/t^2}$ — is the seed from which all manifold-level bumps, partitions of unity, and extensions are built. **Paracompactness of the manifold** (Hausdorff + second-countable, via [[Thm - Locally Compact σ-Compact Hausdorff is Paracompact]]) lets us refine any open cover to a locally finite one; this is what gives the sum in a partition of unity its finiteness at each point. **The chain rule and chart-changes are smooth** — this is the smooth-atlas axiom, and it is what makes every chart-pulled-back definition independent of the chart chosen. **Compactness** of the manifold (or of a subset) often shortcuts arguments: on a compact manifold every continuous function is compactly supported, every open cover has a finite subcover, and several constructions need no partition-of-unity machinery at all. The routing is: from "manifold + chart at $p$" through "Euclidean smoothness at $\varphi(p)$" to "smoothness at $p$" (verification target); from "open cover" through "locally finite refinement + bumps" to "smooth partition of unity" (construction target); from "smooth structures on $M$ and $N$" through "smooth bijection + smooth inverse" to "diffeomorphism" (identification target); from "local data on each chart + smooth partition of unity" through "weighted sum" to "global smooth object" (globalization target).

# Legal Operations

The operations below cover essentially every move in §2.1–§2.2 problems. Each is self-contained.

1. **Pull back to charts to check smoothness.** Whenever a smoothness assertion appears (on a function, a map, or a derived object), write down a coordinate representation $\widehat f = f \circ \varphi^{-1}$ or $\widehat F = \psi \circ F \circ \varphi^{-1}$ and check Euclidean smoothness. The smooth-atlas axiom guarantees the answer does not depend on the chart, so any compatible chart you like will do. *Trigger:* any sentence containing the word "smooth". *Pattern:* the verifications "is the chart map $\varphi$ smooth as a manifold map?" or "is the inclusion smooth?" are answered by writing the coordinate representation and recognizing it as the identity or as a composition of polynomials/rationals/exponentials.

2. **Use chart containment $F(U) \subseteq V$ as part of the smoothness check.** Not just a technicality — without this containment, $\psi \circ F \circ \varphi^{-1}$ is undefined or only defined on a strange subset, and the resulting "smoothness" notion does not imply continuity. *Trigger:* when constructing a candidate chart pair for a smooth map, always shrink $U$ to ensure $F(U) \subseteq V$. *Pattern:* by continuity of $F$ (or by the requirement we want to establish), $F^{-1}(V)$ is open; replace $U$ by $U \cap F^{-1}(V)$, which is still a chart neighbourhood.

3. **Build smooth maps by composition.** The composition of smooth maps is smooth; the projection from a product manifold is smooth; the inclusion of an open submanifold is smooth; the identity is smooth. Many maps are constructed by composing these primitives. *Trigger:* a complicated map is built from simpler ingredients. *Pattern:* exhibit it as $G \circ F$ for smooth $F, G$ and invoke [[Ex - Composition of Smooth Maps is Smooth]].

4. **Construct smooth real-valued functions via the $e^{-1/t}$ germ.** The function $\psi(t) = e^{-1/t}$ for $t > 0$, $\psi(t) = 0$ for $t \leq 0$ is smooth, with every derivative at $0$ equal to $0$. From it, the **cutoff** $h(t) = \psi(r_2 - t)/[\psi(r_2 - t) + \psi(t - r_1)]$ is a smooth function transitioning from $1$ on $t \leq r_1$ to $0$ on $t \geq r_2$. From $h$, the **radial bump** $H(x) = h(|x|)$ on $\mathbb{R}^n$ is a smooth function equal to $1$ on a ball and $0$ outside a larger one. From $H$, pulled back through a chart, every bump function on every manifold is built. *Trigger:* you need a smooth function equal to $1$ here and $0$ there. *Pattern:* the $e^{-1/t}$-trick, scaled and translated.

5. **Apply the smooth partition of unity existence theorem to globalize.** Given an open cover $\{U_\alpha\}$ of a smooth manifold, [[Thm - Existence of Smooth Partitions of Unity]] yields a smooth $\{\psi_\alpha\}$ with $\operatorname{supp}(\psi_\alpha) \subseteq U_\alpha$, locally finite, summing to $1$. Whenever a local construction on each $U_\alpha$ produces an object $T_\alpha$, the sum $T = \sum_\alpha \psi_\alpha T_\alpha$ is a global object that "averages" the $T_\alpha$ with smoothly-varying weights. *Trigger:* a global object is requested and only local constructions are available. *Pattern:* "by partition of unity" — the most-used phrase in differential geometry.

6. **Apply the smooth extension lemma to extend from a closed set.** If $f$ is smooth on a closed $A \subseteq M$ (meaning $f$ extends smoothly to a neighbourhood of each point of $A$), then $f$ extends smoothly to all of $M$, with support inside any prescribed open $U \supseteq A$. *Trigger:* the problem asserts "$f$ is smooth on a closed set" or "extend $f$ to a global function". *Pattern:* invoke [[Thm - Smooth Extension Lemma]] directly; the construction inside the lemma is partition-of-unity-based.

7. **Use bump functions to localize / cut off.** Multiplying any smooth function $g$ by a bump function $\psi$ supported in a chart gives a smooth function $\psi g$ defined globally on $M$ (by extension by zero outside the bump's support), that agrees with $g$ on the bump's interior. This converts a globally-defined smooth function into one with controlled support, useful for proving $C^\infty(M)$ is large. *Trigger:* you need a smooth function with prescribed value on one set and identically zero elsewhere. *Pattern:* multiply by a bump.

8. **Verify a diffeomorphism by exhibiting smooth maps both ways.** To prove $F : M \to N$ is a diffeomorphism, exhibit a smooth $G : N \to M$ and check $G \circ F = \operatorname{id}_M$, $F \circ G = \operatorname{id}_N$. The smoothness of both is essential — smooth bijection is not enough (consider $x \mapsto x^3$). *Trigger:* a problem asks for diffeomorphism, not just isomorphism. *Pattern:* construct both maps explicitly and verify each composition.

9. **Use diffeomorphism invariance of dimension to rule out diffeomorphisms.** If $\dim M \neq \dim N$, no diffeomorphism $M \to N$ exists. The proof is one chart calculation: a diffeomorphism between manifolds restricts to a diffeomorphism between coordinate open sets in $\mathbb{R}^m$ and $\mathbb{R}^n$, and Brouwer's invariance of dimension forces $m = n$. *Trigger:* prove or refute the existence of a diffeomorphism. *Pattern:* compute dimensions; if they differ, the answer is "no".

10. **Recognize $C^\infty(M)$ structure to lift algebraic facts.** $C^\infty(M)$ is a commutative ring with $1$, hence an $\mathbb{R}$-algebra. Any constructions taking commutative rings as input (modules, ideals, ring homomorphisms) apply to $C^\infty(M)$ directly. Pullback by a smooth map $F : M \to N$ is the ring homomorphism $F^* : C^\infty(N) \to C^\infty(M)$, $g \mapsto g \circ F$. *Trigger:* a problem mentions $C^\infty(M)$ explicitly or involves its algebraic structure. *Pattern:* invoke ring-theory machinery directly.

**Illegal but tempting operations:**

> [!warning] 1. Concluding a smooth bijection is a diffeomorphism
> It is tempting to think that a smooth bijection between manifolds is automatically a diffeomorphism. It is not. The standard counterexample is $F : \mathbb{R} \to \mathbb{R}$, $F(x) = x^3$ — smooth, bijective, but $F^{-1}(y) = y^{1/3}$ is not differentiable at $0$. The additional condition that closes the gap is **the differential $dF_p$ is invertible at every point**: this turns the problem into a local application of the [[Thm - The Inverse Function Theorem|inverse function theorem]], which guarantees smooth local inverses. We will see this in [[Differential Geometry IV — Submersions, Immersions, Embeddings, and Submanifolds|DG IV]].

> [!warning] 2. Glueing smooth maps defined on closed subsets
> The topological gluing lemma says that if $\{C_\alpha\}$ is a closed cover and we have continuous maps $F_\alpha : C_\alpha \to N$ that agree on overlaps, then there is a continuous global $F : M \to N$ that restricts to each $F_\alpha$. The smooth analogue is **false**: the maps $f_+(x) = x$ on $[0, \infty)$ and $f_-(x) = -x$ on $(-\infty, 0]$ are smooth on their domains and agree at $0$, but the global function they define is $|x|$, which is not smooth. The smooth gluing lemma (Corollary 2.8 in Lee) requires the cover to be **open**, not closed; for closed covers, partitions of unity are the only safe tool.

> [!warning] 3. Treating analytic and smooth functions interchangeably
> Bump functions, smooth extensions, and partitions of unity all rely on the existence of smooth functions whose support is genuinely smaller than their full domain. **Analytic functions do not have this property**: an analytic function vanishing on a non-empty open set vanishes identically. There are no analytic bumps, no analytic partitions of unity, no analytic extension lemma. The looseness of $C^\infty$ — that derivatives at different points are independent — is essential. *The additional condition* that recovers some extension theorems for analytic functions involves dramatically tighter machinery (Cousin problems, $\bar\partial$-cohomology in the complex-analytic case).

> [!warning] 4. Forgetting the support closure
> The support is $\overline{\{p : f(p) \neq 0\}}$, the *closure* of the non-vanishing set, not the non-vanishing set itself. Forgetting the closure leads to subtle errors: a function may be $0$ on the boundary of an open set $U$ but still have $\operatorname{supp}(f) \supsetneq U$ if there are limit points of $\{f \neq 0\}$ that lie outside $U$. The closure is what makes support a *closed set*; without closure, the inclusion $\operatorname{supp}(\psi_\alpha) \subseteq U_\alpha$ in the partition-of-unity definition would lose its content.

# Problem-Solving Strategy

Almost every problem in this topic falls into one of five categories, each with a recognizable signature and a routine path to the answer.

**Verifying smoothness of an explicit map.** The signature is: you are given a specific $F : M \to N$ — an inclusion, a projection, a quotient map, a stereographic projection — and asked to show it is smooth. The routine is mechanical: pick a chart $(U, \varphi)$ containing the point $p$ of interest, pick a chart $(V, \psi)$ containing $F(p)$, shrink $U$ if needed so that $F(U) \subseteq V$, write $\widehat F = \psi \circ F \circ \varphi^{-1}$, and recognize it as a smooth function between Euclidean open sets. If the recognition is non-obvious, factor $\widehat F$ into smaller pieces — polynomials, rationals, exponentials, restrictions — each obviously smooth. The skill is in choosing helpful charts: stereographic charts make smoothness checks on spheres essentially trivial, while standard graph charts can make the same checks ugly. When in doubt, write out both choices and use the cleaner one.

**Constructing a smooth function with prescribed properties.** The signature is: you are asked to produce a smooth function with specified behaviour on a closed set, prescribed support, or interpolating local data. The routine begins with the question *can the data be encoded as a bump function?* If yes — equals $1$ on a closed set, $0$ outside an open set — apply [[Thm - Existence of Smooth Bump Functions]] directly. If the data is more complex — say, interpolating between several local prescriptions, or extending a smooth function from a closed subset — apply a smooth partition of unity subordinate to an appropriate cover. The decisive choice is *what to cover*: typically you cover $M$ by sets on which each local construction is defined, plus (when extending from a closed $A$) the complement $M \setminus A$ as a buffer. The cover is the architecture; the partition of unity does the gluing.

**Identifying diffeomorphisms.** The signature is: you are asked whether two manifolds are diffeomorphic. The first move is always to check dimensions — if they differ, no diffeomorphism exists. If they match, look for a diffeomorphism invariant beyond dimension: compactness, connectedness, orientability, Euler characteristic, fundamental group. If all known invariants match, attempt to construct an explicit diffeomorphism. The construction usually proceeds chart-by-chart: identify each manifold as a quotient or subset of $\mathbb{R}^n$, write down a smooth bijection between standard parametrizations, check that both directions are smooth in coordinates. If two charts have to be patched together, partition-of-unity arguments are sometimes needed in the construction — but for the standard model manifolds (spheres, tori, projective spaces) the diffeomorphism is usually given by a single formula.

**Establishing algebraic properties of $C^\infty(M)$.** The signature is: you are asked about the ring structure on $C^\infty(M)$ — its dimension as a vector space, whether the smooth structure is recoverable from it, whether $F^* : C^\infty(N) \to C^\infty(M)$ is a homomorphism. The routine: each $f \in C^\infty(M)$ can be cut off by a bump function to produce a function with arbitrary small support, so the bumps furnish you with as many linearly independent elements as you have disjoint open sets — which is countably infinite as soon as $\dim M \geq 1$. The ring homomorphism check $F^*(fg) = (F^*f)(F^*g)$ is a pointwise calculation: $F^*(fg)(p) = (fg)(F(p)) = f(F(p)) g(F(p)) = (F^*f)(p) (F^*g)(p)$. The deeper structural theorem — that $F$ is smooth iff $F^*$ maps $C^\infty(N)$ to $C^\infty(M)$ — gives a duality between smooth maps and algebra homomorphisms, the seed of the ringed-space viewpoint.

**Globalizing a local construction.** The signature is: you are given, on each member of an open cover, a local instance of some object (a Riemannian metric, a $1$-form, a vector field, a connection) and asked to produce a global instance. The routine is canonical: take a smooth partition of unity $\{\psi_\alpha\}$ subordinate to the cover, weight each local object by $\psi_\alpha$, sum. The output is well-defined and smooth because the sum is locally finite, and it satisfies whatever properties were preserved under convex combinations (positivity, symmetry, bilinearity, etc.). The only check is *which properties are preserved*: positive-definiteness is, smoothness is, but linear-independence is not. Construction problems are won at the moment you identify which properties survive the averaging.

A meta-strategy underlies all five: **everything in this chapter is "Euclidean smoothness + chart-pulling-back + partition-of-unity-gluing"**. The unifying question is "how does a manifold-level statement reduce to a chart-level statement, and how do chart-level constructions assemble into manifold-level ones?" Once that template is internalized, the chapter contains no new ideas — only applications of these two moves to different inputs.

# Most Reusable Properties

- **[[Thm - Existence of Smooth Partitions of Unity]]**: every open cover of a smooth manifold admits a subordinate smooth partition of unity. **Typical use:** the universal mechanism for converting local constructions into global ones. Whenever a problem can be solved chart-by-chart but you need a single global answer, partition-of-unity. The construction is invoked constantly throughout differential geometry: Riemannian metrics, connections, volume forms, line integrals, integration of differential forms, sections of bundles. The recognition trigger is the phrase "global smooth..." when only local data is available.

- **[[Thm - Existence of Smooth Bump Functions]]**: for any closed $A \subseteq M$ and open $U \supseteq A$, there is a smooth bump function for $A$ supported in $U$. **Typical use:** the atomic ingredient for all "construct a smooth function with prescribed support" problems. Combined with multiplication by an arbitrary smooth function, this lets you take any global function and produce a localized version of it with controlled support. The recognition trigger is needing a smooth function equal to $1$ on a specific set and $0$ outside another.

- **[[Thm - Smooth Extension Lemma]]**: smooth real-valued (or $\mathbb{R}^k$-valued) functions on a closed subset extend smoothly to the whole manifold, with prescribed support. **Typical use:** when the natural domain of a function is a closed set (a coordinate ball, a compact submanifold) and you need to treat it as a global function. The lemma converts "smooth here" into "smooth everywhere, zero far away", which is enough for all integration and differentiation tasks.

- **[[Thm - Smooth Maps are Continuous]]**: smooth $\Rightarrow$ continuous. **Typical use:** the bridge from differential to topological hypotheses. Whenever you need continuity of a smooth map — to apply a compactness argument, to talk about preimages of open sets, to invoke the gluing lemma — this is the free fact you cite. It also forces the chart-containment $F(U) \subseteq V$ to be available, which is otherwise tedious to verify.

- **The smooth structure is encoded in $C^\infty(M)$ (Lee Problem 2-10)**: a homeomorphism $F : M \to N$ is a diffeomorphism if and only if $F^* : C(N) \to C(M)$ restricts to an isomorphism $C^\infty(N) \to C^\infty(M)$. **Typical use:** the ringed-space viewpoint. When you want to think of "smoothness" as algebraic data, this is the result that licenses it. It generalizes to the recognition that smooth manifolds are a full subcategory of ringed spaces, and it is the bridge to algebraic geometry, where the algebra of "smooth functions" is replaced by an algebra of "polynomial functions" (and the resulting category is varieties / schemes).

# Bridges

1. **Topology III — manifold partitions of unity are the smooth upgrade of topological partitions of unity.** The topological version on a paracompact Hausdorff space, [[Def - Partition of Unity]] and [[Thm - Paracompact Has Partitions of Unity]], requires the weight functions to be continuous; the manifold version requires them to be smooth. The construction is parallel: paracompactness furnishes a locally finite refinement, normality (or the smooth analogue) furnishes bump functions on each cover element via Urysohn (or via the $e^{-1/t}$-trick), normalization produces the partition. The added difficulty for the smooth version is the explicit construction of $C^\infty$ Urysohn-style bumps from the one-variable germ $e^{-1/t}$ — there is no abstract analogue of Urysohn's lemma in the smooth category. So this topic is the topological theory plus one piece of *real analysis*: the construction of smooth functions with compact support, which is purely a $\mathbb{R}$-fact.

2. **Algebra — $C^\infty(M)$ is a commutative ring and an $\mathbb{R}$-algebra**, an instance of [[Def - Ring]] under pointwise addition and multiplication, with constants $\mathbb{R} \hookrightarrow C^\infty(M)$ as central subalgebra. Pullback along a smooth map $F : M \to N$ is the ring homomorphism $F^* : C^\infty(N) \to C^\infty(M)$, $g \mapsto g \circ F$ — a homomorphism in [[Def - Ring Homomorphism]] sending $1$ to $1$ and respecting addition and multiplication pointwise. Lee's Problem 2-10 states the further fact that the smooth structure on $M$ is *determined* by $C^\infty(M)$ as an abstract subalgebra of $C(M)$. This connects to ring theory in two directions: first, it makes the entire smooth category a category of $\mathbb{R}$-algebras (with morphisms going the other way), which is the algebra-geometry duality at the heart of algebraic geometry; second, tangent vectors and vector fields are about to be defined as *derivations* of this ring, an inherently algebraic notion.

3. **Multivariate Analysis — Euclidean smoothness is the seed.** Every smoothness statement on a manifold reduces to a smoothness statement on a Euclidean open set, where it means what it always meant: all partial derivatives exist and are continuous. The chain rule, the inverse function theorem, the implicit function theorem — all the multivariable calculus from [[Multivariate Analysis I — Differentiation in Several Variables|MA I]] is reused verbatim. The novelty of manifold-level smoothness is not what "smooth" means locally but the question *whether the local definitions glue consistently*. The smooth-atlas axiom ensures they do, so manifold smoothness is Euclidean smoothness plus chart-changes that are themselves smooth.

4. **Analysis on $\mathbb{R}^n$ — the function $e^{-1/t}$ is the entire technology.** The construction of smooth bump functions, smooth cutoffs, and smooth partitions of unity all reduce to one fact: the function $\psi(t) = e^{-1/t}$ for $t > 0$ and $0$ for $t \leq 0$ is smooth on $\mathbb{R}$ with $\psi^{(k)}(0) = 0$ for every $k$. Combining $\psi(r_2 - t)$ and $\psi(t - r_1)$ produces a smooth transition between $1$ and $0$; this transition pulled back through chart maps produces every bump on every manifold. The non-rigidity of $C^\infty$ — that derivatives at different points are independent, unlike analytic functions — is what makes this work; the analytic category lacks any analogue.

5. **Sheaf Theory — $C^\infty$ is the structure sheaf of a smooth manifold.** The assignment $U \mapsto C^\infty(U)$ is a **sheaf** on $M$: smooth functions are locally determined (a function defined on a cover that agrees on overlaps glues to a global function), and compatible local sections glue uniquely. This makes $(M, C^\infty)$ a *ringed space*, with smooth maps corresponding to morphisms of ringed spaces. The pattern *space + sheaf of admissible functions* generalizes well beyond smooth manifolds: with polynomial functions we get algebraic varieties, with holomorphic functions complex manifolds, with continuous functions topological spaces. Smooth manifold theory is one column of a table whose other columns are the major geometric categories of mathematics.

# Insights

**The unifying frame: chart-pulling-back and partition-of-unity-gluing.** Every operation in §2.1–§2.2 is one of two moves. *Move 1 (pull back to charts):* a manifold-level concept is defined by demanding that its coordinate representation, in any one chart, satisfies a Euclidean version of the concept; the smooth-atlas axiom guarantees this is chart-independent. This is how smoothness is defined, how the differential will be defined in [[Differential Geometry III — Tangent Vectors and the Differential|DG III]], how integration of forms will be defined in [[Differential Geometry IX — Orientation, Integration, and Stokes' Theorem|DG IX]]. *Move 2 (partition of unity):* a global object is built from a family of local objects by weighting with a smooth partition of unity and summing; the local-finiteness of the partition makes the sum well-defined, and the local fidelity of the partition makes the global object match the local objects where the bumps are equal to $1$. These two moves — definition by pullback, construction by partition of unity — are *all* of smooth manifold theory at the level of this chapter, and they remain the technique for the next ten chapters.

**The true name of smoothness is "smooth in every chart".** The formal definition demands the existence of *one* chart in which $\widehat f$ is smooth at $p$, but the smooth-atlas axiom upgrades this to *every* compatible chart. So when verifying smoothness, you may choose whichever chart makes the verification cleanest — stereographic, graph, polar, exponential. When *using* smoothness, you may assume the function looks smooth in any chart you encounter. This is the source of the recurring trigger-reaction pattern *"to check smoothness, pick a convenient chart"*: the answer does not depend on the choice, so spend time choosing well rather than computing through a bad choice.

**A trigger-reaction pattern: "global smooth object from local data" → partition of unity.** Whenever a problem asks for a smooth object on the entire manifold and you can construct it on each member of an open cover, the answer is partition of unity. The pattern repeats across the entire subject. To produce a Riemannian metric: standard Euclidean metric in each chart + partition. To produce a volume form: standard Euclidean volume form in each chart + partition. To produce a connection: standard flat connection in each chart + partition (with a small correction for affineness). The construction is canonical to the point of monotony — and yet it is the only known method for most of these existence theorems.

**Inheritance: smoothness inherits from $\mathbb{R}^n$.** Every property of smooth functions on $\mathbb{R}^n$ — the chain rule, the smoothness of compositions, the smoothness of $e^x$ and polynomials — lifts to the manifold via charts. There is no separate "manifold calculus"; there is only Euclidean calculus seen through charts. This inheritance is the answer to the deep question "where does smoothness on a manifold come from?": it comes from $\mathbb{R}^n$, and the manifold provides only the gluing instructions.

**The $e^{-1/t}$-trick is one of mathematics' great workarounds.** Real-analytic functions are too rigid for cut-offs (they vanish identically as soon as they vanish on an open set). Polynomials and rational functions are too restrictive (their supports are not compact). The $C^\infty$-but-not-analytic function $e^{-1/t}$ resolves the tension by being smooth everywhere and zero on a half-line, with all derivatives at the endpoint also zero. This single function, scaled and translated, generates every smooth cutoff on every smooth manifold — and the entire local-to-global machinery of differential geometry rests on its existence. It is a small piece of $\mathbb{R}$-analysis with disproportionate consequences for global geometry.

**A second trigger-reaction pattern: "I need a smooth function but only continuous machinery is available" → bump function plus extension lemma.** When the natural construction produces only a continuous function (Urysohn, gluing on closed sets, pointwise limits), the smooth version is obtained by routing through a bump-function construction. Urysohn's lemma is upgraded to smooth Urysohn (the bump function existence theorem); the topological gluing lemma is upgraded to smooth gluing on *open* covers (partition of unity); the Tietze extension theorem is upgraded to the smooth extension lemma. Each topological tool has a smooth analogue obtained by replacing continuous bumps with smooth ones, and the smooth bumps come from the $e^{-1/t}$-trick.

**Where the smoothness comes from in $C^\infty(M)$**: every smooth function on $M$ is, on each chart, a smooth function on a Euclidean open set, *extended by a partition of unity to the whole manifold*. So $C^\infty(M)$ is "Euclidean $C^\infty$ pieces, glued by partitions of unity, into a global $\mathbb{R}$-algebra". This decomposition is the operational definition of $C^\infty(M)$ — and it is the recipe by which any "nice" subalgebra of $C(M)$ might be a candidate for an exotic smooth structure (Problem 2-10 explores this).
