# Problem Statement

Compute the [[Def - Closure, Interior, and Boundary|closure]] $\overline{\mathbb{Q}}$ of the rationals as a subset of $\mathbb{R}$, in each of the following topologies:

(a) The **standard topology** on $\mathbb{R}$ (the metric topology induced by $|x - y|$).

(b) The **discrete topology** on $\mathbb{R}$ (every subset is open).

(c) The **cofinite topology** on $\mathbb{R}$ (a set is open iff it is empty or its complement is finite).

(d) The **Sorgenfrey topology** (lower-limit topology) on $\mathbb{R}$, generated by the basis $\{[a, b) : a < b\}$.

In each case, give a short argument that reads the answer off the topology.

**Recall:**

The [[Thm - Characterizations of the Closure|closure characterization theorem]]: the closure $\overline{A}$ is the smallest closed set containing $A$, equivalently the intersection of all closed sets containing $A$. A point $x \in X$ is in $\overline{A}$ iff every open set containing $x$ meets $A$ (equivalently, every basis element containing $x$ meets $A$). The set $A \subseteq X$ is [[Def - Dense Subset|dense]] iff $\overline{A} = X$.

The rationals $\mathbb{Q}$ are countable and dense in standard $\mathbb{R}$ — between any two reals there is a rational. They are *not* a finite set (countable but infinite).

# Convergent Strategy

**Problem class.** Compute a topological invariant — the closure of a specific subset — across four different topologies on the same set. The exercise calibrates how much the closure depends on the topology versus the underlying set; in each case the closure is a near-immediate consequence of the topology's structure.

**Assumption pattern.** Each topology offers a different characterization that makes the closure-of-$\mathbb{Q}$ computation almost a one-liner:
- (a) Standard: every real is a limit of rationals (density of $\mathbb{Q}$ in $\mathbb{R}$).
- (b) Discrete: every singleton is closed, so every set is closed.
- (c) Cofinite: closed sets are finite or all of $\mathbb{R}$; $\mathbb{Q}$ is infinite.
- (d) Sorgenfrey: every basis element $[a, b)$ contains a rational.

**Theorem routing.** In each case use the [[Thm - Characterizations of the Closure|characterization of closure]]: $x \in \overline{A}$ iff every open neighbourhood of $x$ meets $A$. In (a) and (d), this reduces to "every basis element about any real meets $\mathbb{Q}$"; in (b), every singleton is open and $\overline{A}$ is automatically the smallest closed set containing $A$, which equals $A$ itself since every set is closed; in (c), the closed sets are determined explicitly and the smallest closed superset of an infinite set is $\mathbb{R}$.

**Key decision point.** The takeaway is conceptual: $\overline{\mathbb{Q}}$ depends *entirely on the topology* and not on the algebraic structure of $\mathbb{Q}$. The answers are $\mathbb{R}$, $\mathbb{Q}$, $\mathbb{R}$, $\mathbb{R}$ in cases (a)–(d) respectively — and each follows by a different mechanism.

# Legal Operations Used

This solution deploys the following operations from [[Topology I — §1–3 Metric and Topological Spaces#Legal Operations|the topic page's Legal Operations]]:

1. **Use the open-neighbourhood characterization of closure.** $x \in \overline{A}$ iff every open set containing $x$ meets $A$.

2. **Reduce the open-set check to a basis check.** A point is in the closure iff every basis element containing it meets $A$ (since every open set contains a basis element about each of its points).

3. **Read off the closed sets directly from the topology.** Discrete: every set is closed. Cofinite: closed sets are finite or $\mathbb{R}$. Sorgenfrey: clopen basis ([[Ex - The half-open interval topology on the real line|see the half-open exercise]]).

4. **Use density of $\mathbb{Q}$ in standard $\mathbb{R}$.** Every open interval contains a rational — this is the [[Def - Dense Subset|definition of ℚ being dense]] in standard $\mathbb{R}$, and it transfers to the Sorgenfrey topology because $[a, b) \supseteq (a, b)$.

# Hints

> [!note]- Hint 1
> In any topology, $\overline{A}$ is the smallest closed set containing $A$. If $A$ is *itself* closed, $\overline{A} = A$; if $A$ has only $X$ as a closed superset, $\overline{A} = X$.

> [!note]- Hint 2
> In the discrete topology, every set is *both* open and closed. So $\overline{A} = A$ for any $A$.

> [!note]- Hint 3
> In the cofinite topology, the closed sets are exactly the finite sets together with $\mathbb{R}$ — see [[Ex - The cofinite topology]]. What is the smallest closed superset of an infinite set?

> [!note]- Hint 4
> In the Sorgenfrey topology, the basic open sets are $[a, b)$. For a real $x$, the basic open sets containing $x$ are exactly $[a, b)$ with $a \leq x < b$. The smallest such is $[x, x + \varepsilon)$ for $\varepsilon > 0$. Does this contain a rational?

# Solution

The same subset $\mathbb{Q} \subseteq \mathbb{R}$ has four different closures in the four topologies, each reflecting a structural feature of the topology.

**(a) Standard topology: $\overline{\mathbb{Q}} = \mathbb{R}$.**

Every real $x$ is the limit of a sequence of rationals (the density of $\mathbb{Q}$ in $\mathbb{R}$). Equivalently, every open interval $(x - \varepsilon, x + \varepsilon)$ meets $\mathbb{Q}$.

> [!note]- Derivation
> Fix $x \in \mathbb{R}$. We show every open set containing $x$ meets $\mathbb{Q}$. By the [[Def - Basis and Subbasis for a Topology|basis criterion]], it suffices to check basis elements: every open set containing $x$ contains some interval $(x - \varepsilon, x + \varepsilon)$.
>
> Take any $\varepsilon > 0$. We need to find a rational $q$ with $|q - x| < \varepsilon$. Choose $n$ with $1/n < \varepsilon$ (Archimedean property). Then there is an integer $m$ with $m/n \leq x < (m+1)/n$ (by the floor function). Both $m/n$ and $(m+1)/n$ are rationals within $1/n < \varepsilon$ of $x$. So $(x - \varepsilon, x + \varepsilon)$ contains a rational.
>
> By [[Thm - Characterizations of the Closure|the closure characterization]], $x \in \overline{\mathbb{Q}}$. Since $x$ was arbitrary, $\overline{\mathbb{Q}} = \mathbb{R}$. So $\mathbb{Q}$ is [[Def - Dense Subset|dense]] in standard $\mathbb{R}$.

**(b) Discrete topology: $\overline{\mathbb{Q}} = \mathbb{Q}$.**

In the discrete topology, *every* subset of $\mathbb{R}$ is both open and closed. So $\mathbb{Q}$ is closed, and $\overline{\mathbb{Q}} = \mathbb{Q}$.

> [!note]- Derivation
> In the discrete topology $\tau = \mathcal{P}(\mathbb{R})$, every subset of $\mathbb{R}$ is open. The complement of any subset is also a subset, hence open, hence its complement is closed: every subset is closed.
>
> The closure $\overline{A}$ is the smallest closed set containing $A$. Since $A$ itself is closed, $\overline{A} = A$. Applied with $A = \mathbb{Q}$: $\overline{\mathbb{Q}} = \mathbb{Q}$.
>
> Equivalently: for any $x \notin \mathbb{Q}$, $\{x\}$ is open in the discrete topology, and $\{x\} \cap \mathbb{Q} = \emptyset$ — so the open set $\{x\}$ around $x$ does not meet $\mathbb{Q}$, hence $x \notin \overline{\mathbb{Q}}$.

**(c) Cofinite topology: $\overline{\mathbb{Q}} = \mathbb{R}$.**

In the cofinite topology, the closed sets are exactly the finite sets and $\mathbb{R}$ itself ([[Ex - The cofinite topology]]). $\mathbb{Q}$ is *infinite*, so the smallest closed superset of $\mathbb{Q}$ is $\mathbb{R}$.

> [!note]- Derivation
> From [[Ex - The cofinite topology]]: the closed sets in the cofinite topology on $\mathbb{R}$ are exactly the finite subsets together with $\mathbb{R}$.
>
> $\overline{\mathbb{Q}}$ is the intersection of all closed sets containing $\mathbb{Q}$. Since $\mathbb{Q}$ is infinite, no finite closed set contains $\mathbb{Q}$. The only closed set containing $\mathbb{Q}$ is $\mathbb{R}$ itself. So $\overline{\mathbb{Q}} = \mathbb{R}$.
>
> Equivalently, by the open-neighbourhood characterization: every nonempty open $U$ in the cofinite topology has finite complement, so $U \cap \mathbb{Q}$ is $\mathbb{Q}$ minus a finite set, which is nonempty (since $\mathbb{Q}$ is infinite). Hence every open neighbourhood of every $x \in \mathbb{R}$ meets $\mathbb{Q}$, putting $x$ in $\overline{\mathbb{Q}}$.

**(d) Sorgenfrey topology: $\overline{\mathbb{Q}} = \mathbb{R}$.**

Every basis element $[a, b)$ contains a rational (the standard topology gives this for $(a, b) \subseteq [a, b)$). Hence every Sorgenfrey-open set about any point meets $\mathbb{Q}$.

> [!note]- Derivation
> Fix $x \in \mathbb{R}$. Every Sorgenfrey-open set containing $x$ contains some basis element $[a, b)$ with $a \leq x < b$. In particular, for any $\varepsilon > 0$, $[x, x + \varepsilon) \subseteq [a, b)$ is a basis element about $x$.
>
> Now $[x, x + \varepsilon)$ contains the standard open interval $(x, x + \varepsilon)$, which is nonempty and contains a rational by the density of $\mathbb{Q}$ in standard $\mathbb{R}$ (case (a)). So $[x, x + \varepsilon) \cap \mathbb{Q} \neq \emptyset$.
>
> Every Sorgenfrey-open set about $x$ contains such an $[x, x + \varepsilon)$ and hence meets $\mathbb{Q}$. So $x \in \overline{\mathbb{Q}}$, and $\overline{\mathbb{Q}} = \mathbb{R}$ in the Sorgenfrey topology.

> [!note]- Complete formal solution
> **(a) Standard.** Every $\mathbb{R}$-open set about $x \in \mathbb{R}$ contains some $(x - \varepsilon, x + \varepsilon)$, which contains a rational (Archimedean property). So $\overline{\mathbb{Q}} = \mathbb{R}$. **(b) Discrete.** Every subset is closed, so $\overline{\mathbb{Q}} = \mathbb{Q}$. **(c) Cofinite.** Closed sets are finite or $\mathbb{R}$; $\mathbb{Q}$ is infinite, so the smallest closed superset is $\mathbb{R}$. $\overline{\mathbb{Q}} = \mathbb{R}$. **(d) Sorgenfrey.** Every basic open $[a, b)$ containing $x$ contains $(x, x + \varepsilon) \cap \mathbb{Q} \neq \emptyset$, so $\overline{\mathbb{Q}} = \mathbb{R}$. $\blacksquare$
>
> **Summary table.**
>
> | Topology | $\overline{\mathbb{Q}}$ | Mechanism |
> |---|---|---|
> | Standard | $\mathbb{R}$ | $\mathbb{Q}$ is dense by Archimedean property |
> | Discrete | $\mathbb{Q}$ | every set is closed |
> | Cofinite | $\mathbb{R}$ | closed = finite or $\mathbb{R}$; $\mathbb{Q}$ infinite |
> | Sorgenfrey | $\mathbb{R}$ | every $[a, b)$ contains a rational |

# Key Takeaways

**Closure is a *topological* operation — it depends entirely on which sets are open, not on the algebraic structure of the set or its underlying ordering.** The four topologies on $\mathbb{R}$ give four genuinely different closures of $\mathbb{Q}$: the same subset is dense in three of them and equal to itself in the fourth. The discrete topology destroys all density, the cofinite topology promotes every infinite set to density, and the standard and Sorgenfrey topologies are "fine enough to see individual points" but "coarse enough to be approached by rationals". The general trigger to develop: when a closure or density question arises, *do not reach for algebraic facts about the set first*; reach for the topology's characterization of closure or its list of closed sets, and read off the answer.

**The "smallest closed set containing $A$" definition is operationally weak — the *neighbourhood-meets-$A$* characterization is what you actually compute with.** The intersection-of-closed-sets formulation is the cleanest *definition*, but to test whether a specific point $x$ is in $\overline{A}$, the practical method is to check: does every open neighbourhood of $x$ meet $A$? This is what [[Thm - Characterizations of the Closure|the closure characterization theorem]] provides, and it is almost always the right tool for membership questions. Moreover, in a [[Def - First and Second Countable|first countable]] (in particular, metric) space, this characterization upgrades to "there is a sequence in $A$ converging to $x$", which is even more concrete and is what most analysis arguments use. The lesson: a closure containment statement is usually proved by writing down a *sequence* (in first-countable spaces) or by exhibiting a meet of $A$ with every neighbourhood basis element (in general).

**The three "rich enough" topologies (standard, cofinite, Sorgenfrey) all have $\overline{\mathbb{Q}} = \mathbb{R}$ — for three completely different reasons.** Standard topology: basis elements are intervals, and Archimedean density does the work. Cofinite: basis elements have finite complement, and any infinite set survives the removal of finitely many points. Sorgenfrey: basis elements $[a, b)$ contain $(a, b)$, which contains a rational. The common phenomenon is that *every nonempty open set meets $\mathbb{Q}$*; this is the [[Def - Dense Subset|definition of density]] and is equivalent to $\overline{\mathbb{Q}} = X$. The lesson: density is a topology-by-topology check of whether basis elements always meet the candidate dense set. In the discrete topology, singletons $\{x\}$ for $x \notin \mathbb{Q}$ are nonempty open sets missing $\mathbb{Q}$, breaking density.

**The discrete topology is the *unique* topology in which no proper subset is dense — every set equals its own closure.** This makes the discrete topology *anti-approximation-friendly*: the dense-subset strategy in analysis ("prove it for a dense class, pass to the limit") has no traction in a discrete space, because there is nothing to approximate from. The companion observation is that the discrete topology has no convergent sequences other than eventually constant ones, since the singleton $\{x\}$ is open. The general structural picture: the more open sets a topology has, the more it can *separate* points, but the less it allows approximation of one point by another. Standard $\mathbb{R}$ sits in the sweet spot: enough open sets to be Hausdorff (every two distinct points have disjoint neighbourhoods, see [[Ex - The cofinite topology]]), but not so many that approximation breaks down. This sweet spot — Hausdorff plus first countable plus separable — is essentially the *metric space* regime, and is what makes most of analysis work.
