# Problem Statement

Let $X$ be any set, and define the **discrete metric**
$$d(x, y) = \begin{cases} 0 & \text{if } x = y, \\ 1 & \text{if } x \neq y.\end{cases}$$

1. Verify that $d$ is a [[Def - Metric Space|metric]] on $X$.
2. Show that every singleton $\{x\}$ is an open set, and conclude that *every* subset of $X$ is open — the [[Def - Topological Space|topology]] generated by $d$ is the **discrete topology** $\tau = \mathcal{P}(X)$.
3. Show that *every* function $f : (X, d) \to (Y, \rho)$ to any other metric (or topological) space is continuous.
4. Show that a sequence $(x_n)$ in $X$ is Cauchy under $d$ if and only if it is eventually constant, and conclude that $(X, d)$ is complete.
5. Show that if $X$ is uncountable, then $(X, d)$ is [[Def - First and Second Countable|first countable]] but not second countable.

**Recall:**

The objects in play are the metric axioms, the open-ball construction of the metric topology, the open-set definition of continuity, and the countability axioms.

![[Def - Metric Space#The Definition]]

A subset $U \subseteq X$ is [[Def - Open and Closed Sets in a Metric Space|open]] iff for every $x \in U$ there exists $\varepsilon > 0$ with $B_\varepsilon(x) \subseteq U$. A function $f : (X, d) \to (Y, \rho)$ is [[Def - Continuous Map|continuous]] iff $f^{-1}(V)$ is open in $X$ for every open $V \subseteq Y$. A [[Def - Topological Space|topology]] $\tau \subseteq \mathcal{P}(X)$ is **discrete** if $\tau = \mathcal{P}(X)$. A space is [[Def - First and Second Countable|first countable]] if every point has a countable neighbourhood basis, and **second countable** if the whole topology has a countable basis.

# Convergent Strategy

**Problem class.** Verifying that a specific candidate is a metric and reading off the topology it generates. This is the smallest non-trivial example of a metric, and almost every general theorem about metric spaces has an instructive specialization here.

**Assumption pattern.** The metric takes only two values, $0$ and $1$. Every quantitative statement collapses to a *case split* on $x = y$ versus $x \neq y$, so all axiom checks are finite.

**Theorem routing.** The metric axioms are verified by a four-way case analysis on the triangle inequality. The topology is computed by observing that any radius $\varepsilon < 1$ gives $B_\varepsilon(x) = \{x\}$, so every singleton is open, so every set (being a union of singletons) is open. Continuity is automatic: if every subset of the source is open, the preimage of *any* set is open. Cauchy-implies-eventually-constant comes from "$d < 1$ forces equality". First countability uses $\{B_{1/2}(x)\} = \{\{x\}\}$ as a one-element neighbourhood basis. Second countability fails because *any* basis must contain every singleton — and there are uncountably many singletons.

**Key decision point.** The crucial structural observation is that the only metric values are $0$ and $1$, which forces *both* the topology to be discrete and the Cauchy condition to collapse to "eventually equal". Almost every property of the discrete space follows from this single numerical fact.

# Legal Operations Used

This solution deploys the following operations from [[Topology I — §1–3 Metric and Topological Spaces#Legal Operations|the topic page's Legal Operations]]:

1. **Case-split the triangle inequality on equalities.** With only two metric values, each axiom check reduces to checking the inequality on every pattern of equality and inequality among the three points.

2. **Read off the topology from the open balls.** $B_\varepsilon(x) = \{x\}$ for $\varepsilon \leq 1$ and $B_\varepsilon(x) = X$ for $\varepsilon > 1$ — these two cases describe every open ball, and every open set is a union of open balls.

3. **Use the trivial-source-topology continuity criterion.** If the source space has discrete topology, every map out of it is continuous, because the preimage of any set is a subset of the source, hence open.

4. **Use $\{B_{1/2}(x)\}$ as a one-element neighbourhood basis.** Since $B_{1/2}(x) = \{x\}$ is the smallest neighbourhood of $x$, every neighbourhood contains it, so this single-element family is a neighbourhood basis.

5. **Apply the cardinality lower bound on a basis.** A basis must include a basis element about every point, and in the discrete topology the only open set containing $x$ that is contained in $\{x\}$ is $\{x\}$ itself. So every basis must include every singleton — hence has cardinality at least $|X|$.

# Solution

The discrete metric is the simplest non-trivial example in the subject and shows how a tiny piece of distance data can produce a topology with extreme separation properties.

**Step 1: $d$ is a metric.**

Each axiom is checked by case split, since $d$ takes only the values $0$ and $1$.

> [!note]- Derivation
> *Nonnegativity and positivity.* By definition $d(x, y) \in \{0, 1\}$ with $d(x, y) = 0$ iff $x = y$, so both nonnegativity and positivity hold.
>
> *Symmetry.* The condition "$x = y$" is symmetric in $x, y$, so $d(x, y) = d(y, x)$.
>
> *Triangle inequality.* We check $d(x, z) \leq d(x, y) + d(y, z)$ in cases:
> - *All equal.* Both sides are $0$.
> - *$x = y \neq z$.* LHS = $d(x, z) = 1$, RHS = $0 + 1 = 1$. ✓
> - *$x \neq y = z$.* LHS = $d(x, z) = 1$, RHS = $1 + 0 = 1$. ✓
> - *$x = z \neq y$.* LHS = $d(x, z) = 0$, RHS = $1 + 1 = 2$. ✓
> - *All distinct.* LHS = $1$, RHS = $1 + 1 = 2$. ✓
> So the triangle inequality holds in every case.

**Step 2: Every subset is open.**

For $\varepsilon = 1/2$, the open ball $B_{1/2}(x) = \{y : d(x,y) < 1/2\} = \{x\}$, since the only $y$ with $d(x,y) < 1/2$ is $y = x$. So every singleton is open, and every subset $A \subseteq X$ is a union of singletons $A = \bigcup_{x \in A} \{x\}$, hence open.

> [!note]- Derivation
> Recall a set $U \subseteq X$ is [[Def - Open and Closed Sets in a Metric Space|open]] iff for every $x \in U$ there is $\varepsilon > 0$ with $B_\varepsilon(x) \subseteq U$. For the singleton $\{x\}$: with $\varepsilon = 1/2$, $B_{1/2}(x) = \{x\} \subseteq \{x\}$. So $\{x\}$ is open.
>
> For arbitrary $A \subseteq X$: $A = \bigcup_{x \in A} \{x\}$ is a union of open sets, hence open by the topology axioms ([[Def - Topological Space|arbitrary unions of opens are open]]).
>
> Hence $\tau_d = \mathcal{P}(X)$, the [[Def - Topological Space|discrete topology]].

**Step 3: Every function from $X$ is continuous.**

If every subset of $X$ is open, then for any function $f : X \to Y$ and any open $V \subseteq Y$, the preimage $f^{-1}(V) \subseteq X$ is open (because every subset of $X$ is open).

> [!note]- Derivation
> $f : (X, d) \to (Y, \rho)$ is [[Def - Continuous Map|continuous]] iff $f^{-1}(V) \in \tau_X$ for every $V \in \tau_Y$. With $\tau_X = \mathcal{P}(X)$, $f^{-1}(V)$ is a subset of $X$, hence in $\mathcal{P}(X) = \tau_X$. So $f$ is continuous regardless of what $f$ or $Y$ are.
>
> This is a *trigger-reaction* worth internalizing: a *finer* topology on the source space makes more functions continuous. Discrete is the finest possible topology, so it makes *every* function continuous out of it. Dually, the *indiscrete* topology $\tau = \{\emptyset, X\}$ is the coarsest and makes every function continuous *into* it.

**Step 4: Cauchy = eventually constant; completeness.**

A sequence $(x_n)$ is Cauchy under $d$ iff for every $\varepsilon > 0$ there is $N$ with $d(x_n, x_m) < \varepsilon$ for $n, m \geq N$. Apply this to $\varepsilon = 1/2$: there is $N$ with $d(x_n, x_m) < 1/2$ for $n, m \geq N$. But $d$ takes only the values $0$ and $1$, so $d(x_n, x_m) < 1/2$ forces $d(x_n, x_m) = 0$, i.e. $x_n = x_m$. Hence $(x_n)$ is eventually constant — and an eventually constant sequence converges to its eventual value. So every Cauchy sequence converges, and $(X, d)$ is **complete**.

> [!note]- Derivation
> *Forward direction.* Suppose $(x_n)$ is Cauchy. Take $\varepsilon = 1/2$. There exists $N$ such that for all $n, m \geq N$, $d(x_n, x_m) < 1/2$. Since $d(x_n, x_m) \in \{0, 1\}$, the inequality forces $d(x_n, x_m) = 0$, hence $x_n = x_m$. So all terms from $N$ onward equal $x_N$ — the sequence is eventually constant.
>
> *Reverse direction.* If $(x_n)$ is eventually constant, say equal to $x_N$ for $n \geq N$, then for any $\varepsilon > 0$ and any $n, m \geq N$, $d(x_n, x_m) = d(x_N, x_N) = 0 < \varepsilon$.
>
> *Completeness.* An eventually constant sequence converges (to its eventual value): for $\varepsilon > 0$ and $n \geq N$, $d(x_n, x_N) = 0 < \varepsilon$. So every Cauchy sequence in $(X, d)$ converges, and the space is complete by definition.

**Step 5: First countable always, second countable only when $X$ is countable.**

At each point $x$, the single-element family $\{\{x\}\}$ is a neighbourhood basis (in fact $\{x\}$ is the *smallest* open set containing $x$). So $X$ is first countable. But a *global* basis $\mathcal{B}$ for the discrete topology must contain every singleton — for each $x$, some $B \in \mathcal{B}$ with $x \in B \subseteq \{x\}$ forces $B = \{x\}$. So $|\mathcal{B}| \geq |X|$. If $X$ is uncountable, no countable basis exists.

> [!note]- Derivation
> *First countable.* Fix $x \in X$. The collection $\mathcal{B}_x = \{\{x\}\}$ is a neighbourhood basis at $x$: every neighbourhood of $x$ contains an open set containing $x$, which contains $\{x\}$. This basis has one element, so $X$ is [[Def - First and Second Countable|first countable]].
>
> *Second countability fails when $X$ is uncountable.* Suppose $\mathcal{B}$ is a basis for $\tau_d = \mathcal{P}(X)$. For each $x \in X$, the singleton $\{x\}$ is open, so by the definition of a basis there must exist $B_x \in \mathcal{B}$ with $x \in B_x \subseteq \{x\}$. This forces $B_x = \{x\}$. So $\{\{x\} : x \in X\} \subseteq \mathcal{B}$, giving $|\mathcal{B}| \geq |X|$. If $|X|$ is uncountable, no countable $\mathcal{B}$ works.
>
> (Conversely, if $X$ is countable then $\{\{x\} : x \in X\}$ itself is a countable basis, and the discrete topology is second countable.)

> [!note]- Complete formal solution
> **(1)** $d$ takes values in $\{0, 1\}$ with $d(x,y) = 0 \iff x = y$, is symmetric in $x, y$, and satisfies the triangle inequality (case-check). **(2)** $B_{1/2}(x) = \{x\}$, so every singleton is open; every set is a union of singletons. **(3)** If every subset of $X$ is open, every preimage is open, so every function out of $X$ is continuous. **(4)** Choosing $\varepsilon = 1/2$ in the Cauchy condition forces $d(x_n, x_m) = 0$, i.e. $x_n = x_m$, so the sequence is eventually constant and converges; completeness follows. **(5)** $\{\{x\}\}$ is a one-element neighbourhood basis at $x$ (first countable); any basis must contain every singleton (second countable iff $X$ countable). $\blacksquare$

# Key Takeaways

**The discrete topology is the *finest* topology on $X$ — and the finest topology makes every map *out* of $X$ continuous, dually, the *coarsest* topology (indiscrete) makes every map *into* $X$ continuous.** This is the structural picture of how topology fineness interacts with continuity. Fineness adds open sets; adding open sets adds preimage conditions to "$f$ is continuous"; adding conditions on the source preimages makes continuity *easier* to satisfy on the source side; adding conditions on the target preimages makes continuity *harder* to satisfy on the source side. The discrete topology — having the most open sets — has the most relaxed source-side condition (every preimage works) and the most stringent target-side condition (every preimage must be open). This is the same monotonicity principle that, in functional analysis, makes the weak topology useful: the weak topology on a Banach space is *coarser* than the norm topology, so more sets are compact in the weak topology, which is why the [[Thm - Continuity via Bases and Neighbourhood Bases|Banach–Alaoglu theorem]] gives more compactness than norm-compactness alone.

**The single-fact engine of the discrete metric is "$d < 1$ forces $d = 0$".** This is the source of every interesting property: open balls of radius $< 1$ are singletons, so the topology is discrete; Cauchy sequences with $d < 1$ must have $d = 0$, so they are eventually constant; completeness is automatic because eventually constant sequences converge. Whenever a property of a metric space is being verified, look for the *quantization* of the metric: are there only finitely many possible distance values? If so, the analysis collapses to a finite case analysis. The integer-distance metric on $\mathbb{Z}$ ($d(m, n) = |m - n|$), the $p$-adic metric on $\mathbb{Q}$, the Hamming metric on $\{0, 1\}^n$ — each is "discrete-like" in some respect and inherits properties from this same single fact.

**First countability is automatic for metric spaces; second countability is a *separability* condition in disguise.** Every point in a metric space has a countable neighbourhood basis $\{B_{1/n}(x)\}_{n \geq 1}$, so metric spaces are *always* first countable. Second countability — having a countable basis for the *whole* topology — is equivalent (in metric spaces) to *separability* (existence of a countable dense subset): if $\{x_n\}$ is dense, $\{B_{1/m}(x_n) : m, n \in \mathbb{N}\}$ is a countable basis; conversely, picking one point from each basis element gives a countable dense set. The discrete space on an uncountable set is the *prototypical* counterexample to separability: every point is isolated, so a dense set must contain every point, which is uncountable. This shows that not every "metric" gives a "nice" topology — and that the gap between metric and Euclidean structure is largely the second-countability gap.

**Completeness is *not* a topological invariant — it depends on the metric, not just the topology.** The discrete metric on $\mathbb{R}$ is complete (every Cauchy sequence is eventually constant); the standard Euclidean metric on $\mathbb{R}$ is complete (the completeness axiom of the reals); the metric $d(x, y) = |\arctan x - \arctan y|$ on $\mathbb{R}$ is *not* complete (the sequence $x_n = n$ is Cauchy because $\arctan n \to \pi/2$ but does not converge in $\mathbb{R}$). All three metrics give the same set $\mathbb{R}$, but the first and third generate *different* topologies, and the second and third generate the *same* topology with different completeness behaviour. This is why completeness is studied as a property of a metric space rather than of the underlying topological space, and why "completion" of a metric space is a metric concept, not a topological one. The topology only sees which sets are open; the metric sees how far apart points are.
