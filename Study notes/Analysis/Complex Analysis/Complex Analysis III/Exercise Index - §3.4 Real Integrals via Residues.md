## §3.4 Real Integrals via Residues — Exercises

The exercises of §3.4 drill the residue calculus as a computational tool for real integrals. Each exercise practices a different contour-closure trick: large semicircles for rational integrands, unit-circle substitution for trigonometric integrals over a period, Jordan's lemma with $e^{iz}$ for oscillatory integrals, keyhole/sector contours for integrals involving branch cuts, and the $\pi \cot(\pi z)$ technique for sums over integers. The unifying recipe is "extend to the complex plane, close a contour where the extra piece vanishes, apply the residue theorem."

- [[Ex - Evaluating an integral via residues]] (⭐⭐) — The standard real-integral-via-semicircle technique ([[Thm - Residue Theorem]], [[Thm - Real Rational Integrals via Residues]], [[Thm - Computing Residues]]).
- [[Ex - A trigonometric integral via residues]] (⭐⭐) — Unit-circle substitution for a trigonometric integral ([[Thm - Trigonometric Integrals via Residues]], [[Thm - Residue Theorem]], [[Thm - Computing Residues]]).
- [[Ex - Fourier integral via Jordan's lemma]] (⭐⭐⭐) — Closure with $e^{iz}$ and Jordan's lemma ([[Thm - Jordan's Lemma]], [[Thm - Residue Theorem]], [[Thm - Computing Residues]]).
- [[Ex - Keyhole contour for log integrals]] (⭐⭐⭐) — Sector and keyhole contours for integrals with branch cuts ([[Thm - Residue Theorem]], [[Def - Branch of the Logarithm]], [[Thm - Existence of Log and Square Root on Simply Connected Domains]]).
- [[Ex - Sum a series via residues]] (⭐⭐⭐) — Series summation by contour integration of $\pi\cot(\pi z) g(z)$ ([[Thm - Residue Theorem]], [[Thm - Computing Residues]]).
